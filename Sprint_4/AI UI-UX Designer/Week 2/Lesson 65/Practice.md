# Практичні завдання до Уроку 65: Формування та оцінювання варіантів дизайнерських рішень за допомогою AI

## Мета практики
Опанувати швидке прототипування альтернативних UI-рішень за допомогою генеративного AI, проведення евристичного аналізу інтерфейсів за **10 евристиками Якоба Нільсена** та порівняння конверсійних гіпотез (A/B testing hypotheses).

---

### Завдання 1. Експертна евристична оцінка інтерфейсу за Нільсеном (Базовий рівень)

#### Опис завдання:
Проаналізуйте інтерфейс форми реєстрації за трьома евристиками Якоба Нільсена та зафіксуйте можливі порушення й рекомендації щодо їх усунення.

#### Евристики для аналізу:
1. **Visibility of system status (Видимість стану системи)**: Чи показує індикатор складності пароля в реальному часі, чи виникає лоадер при відправці форми?
2. **Error prevention (Запобігання помилкам)**: Чи блокується випадкове введення недозволених символів у телефонному полі?
3. **Recognition rather than recall (Впізнавання краще, ніж пригадування)**: Чи видно підказки щодо вимог до пароля прямо під полем, чи вони виникають лише після помилки?

---

### Завдання 2. AI-генерація гіпотез для A/B тестування головного екрана (Прикладний рівень)

#### Опис завдання:
Сформулюйте для AI запит на генерацію 3 кардинально різних концепцій першого екрана (Hero Section) для SaaS-платформи онлайн-освіти з метою підвищення конверсії в клік по кнопці «Почати безкоштовно».

#### Промпт для AI:
> «Створи 3 концептуально різні версії Hero Section для EdTech платформи курсів з AI:
> - **Варіант A (Social Proof focus)**: акцент на відгуках випускників, логотипах компаній-роботодавців та рейтингу 4.9/5.
> - **Варіант B (Product Demo focus)**: інтерактивний інтерактивний віджет/прев'ю уроку прямо на першому екрані.
> - **Варіант C (Outcome & Value focus)**: акцент на зарплаті після закінчення та гарантії працевлаштування.
> Для кожного варіанту опиши: Заголовок (H1), Підзаголовок (Subhead), Текст кнопки (CTA) та візуальний блок праворуч.»

---

### Завдання 3. AI-аудит доступності інтерфейсу (Accessibility WCAG 2.2) (Робота з AI)

#### Опис завдання:
Попросіть AI проаналізувати поєднання кольорів тексту та фону на відповідність стандарту WCAG AA (коефіцієнт контрастності мінімум 4.5:1 для звичайного тексту).
