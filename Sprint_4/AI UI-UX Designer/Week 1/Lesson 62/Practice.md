# Практичні завдання до Уроку 62: Роль фахівця з UI-UX-дизайну, який використовує AI у роботі

## Мета практики
Опанувати інтеграцію сучасних AI-інструментів (Midjourney, Figma AI, Uizard, ChatGPT, Claude) у повсякденний пайплайн дизайнера цифрових продуктів: від мудбордингу до підготовки UI-кітів та дизайн-систем.

---

### Завдання 1. Побудова карти дизайн-процесу з точками впровадження AI (Базовий рівень)

#### Опис завдання:
Складіть матрицю етапів класичного процесу дизайну (Double Diamond) та підберіть для кожного етапу спеціалізований AI-інструмент та очікуваний артефакт.

#### Зразок таблиці артефактів:
| Етап Double Diamond | AI-інструмент | Завдання дизайнера | Фінальний артефакт |
| :--- | :--- | :--- | :--- |
| **1. Discover (Дослідження)** | ChatGPT / Claude + Perplexity | Аналіз болей користувачів та відгуків конкурентів | User Persona, Empathy Map |
| **2. Define (Визначення)** | FigJam AI / Miro Assist | Кластеризація ідей та формування CJM | Customer Journey Map, Проблемні точки |
| **3. Develop (Розробка ідей)** | Midjourney / Relume / v0.dev | Генерація візуальних напрямків, прототипів | Moodboard, Варіанти UI-лейаутів |
| **4. Deliver (Впровадження)** | Figma Plugins (Magician, Automator) | Наповнення текстами, підбір іконок, перевірка контрасту | Готовий Figma макет, UI Kit |

---

### Завдання 2. AI-генерація профілю персони користувача (User Persona) (Прикладний рівень)

#### Опис завдання:
Складіть детальний промпт до AI для генерації реалістичної User Persona для додатку оренди електросамокатів у місті-мільйоннику.

#### Промпт для AI:
> «Створи детальний профіль User Persona для мобільного додатку міського мікротранспорту (електросамокати та байкшерінг). Включи:
> 1) Демографічний портрет (вік, професія, дохід).
> 2) Цілі та мотивація (чому обирає самокат замість таксі чи метро).
> 3) Головні больові точки та бар'єри (розряджений акумулятор, складність паркування, погода, безпека руху).
> 4) Технологічний стек (якими додатками користується щодня).
> 5) Цитата користувача, що описує його головний інсайт.»

---

### Завдання 3. Оцінка швидкості створення дизайн-концепту (Робота з AI)

#### Опис завдання:
Згенеруйте за допомогою AI текстову концепцію головного екрана додатку інвестицій для початківців: блоки, CTA-кнопки, колірні акценти та мікрокопірайтинг.
