# Контрольні запитання до Уроку 60.2: Умовні конструкції

### Питання 1: Як у Python позначаються блоки коду всередині конструкції `if`?
A) Фігурними дужками `{ ... }`
B) Ключовими словами `begin ... end`
C) Відступами (4 пробіли)
D) Круглими дужками `( ... )`
**Правильна відповідь:** C
**Пояснення:** Python використовує відступи (indentation) для визначення блоків коду.

### Питання 2: Який оператор використовується для перевірки рівності двох значень?
A) `=`
B) `==`
C) `===`
D) `eq`
**Правильна відповідь:** B
**Пояснення:** Одинарне `=` — це присвоєння значення, а подвійне `==` — перевірка рівності.

### Питання 3: Що виведе наступний код:
```python
code = 201
if code == 200:
    print("OK")
elif code == 201:
    print("Created")
else:
    print("Other")
```
A) `OK`
B) `Created`
C) `Other`
D) Нічого
**Правильна відповідь:** B
**Пояснення:** Умова `code == 201` є істинною, тому виконується відповідний блок `elif`.

### Питання 4: Який результат поверне вираз `(True and False) or True`?
A) `False`
B) `True`
C) `None`
D) `Error`
**Правильна відповідь:** B
**Пояснення:** `True and False` дає `False`, а `False or True` повертає `True`.

### Питання 5: Як перевірити, що слово "error" присутнє в тексті відповіді `msg = "Fatal error occurred"`?
A) `if msg.has("error"):`
B) `if "error" in msg:`
C) `if msg.contains("error"):`
D) `if "error" == msg:`
**Правильна відповідь:** B
**Пояснення:** Оператор `in` є стандартним способом перевірки підрядка в Python.

### Питання 6: Чому не можна замінювати `assert` простим `if-else` з `print()` у тестах?
A) `if-else` працює повільніше
B) Якщо умова `if` не виконається, PyTest все одно вважатиме тест успішним (Passed)
C) Python забороняє використовувати `print` у тестах
D) `assert` видаляє тимчасові файли
**Правильна відповідь:** B
**Пояснення:** PyTest фіксує падіння тесту лише при виникненні винятку (наприклад, `AssertionError`).

### Питання 7: Що поверне вираз `not (5 > 10)`?
A) `False`
B) `True`
C) `None`
D) `5`
**Правильна відповідь:** B
**Пояснення:** `5 > 10` є `False`, а `not False` повертає `True`.

### Питання 8: Що означає конструкція `elif`?
A) Скорочення від `else if` (перевірка альтернативної умови)
B) Нескінченний цикл
C) Завершення виконання програми
D) Оголошення функції
**Правильна відповідь:** A
**Пояснення:** `elif` є скороченням від `else if` у синтаксисі Python.

### Питання 9: Що виведе код:
```python
is_visible = False
if not is_visible:
    print("Element is hidden")
```
A) Нічого
B) `Element is hidden`
C) Помилку
D) `False`
**Правильна відповідь:** B
**Пояснення:** `not False` обчислюється в `True`, тому тіло `if` виконується.

### Питання 10: Який оператор перевіряє нерівність двох змінних?
A) `<>`
B) `!=`
C) `!==`
D) `not =`
**Правильна відповідь:** B
**Пояснення:** У Python оператор нерівності записується як `!=`.

### Питання 11: Що станеться, якщо жодна з умов `if` та `elif` не є істинною, а блоку `else` немає?
A) Викине помилку
B) Програма просто піде далі без виконання тіла умовного блоку
C) Програма перезапуститься
D) Виконається перша умова
**Правильна відповідь:** B
**Пояснення:** Якщо жодна умова не справдилася і `else` відсутній, виконання продовжується з наступного рядка.

### Питання 12: Як перевірити, що число `status` знаходиться в діапазоні від 200 до 299 включно?
A) `if 200 <= status <= 299:`
B) `if status between 200 and 299:`
C) `if status in range(200, 299):`
D) `if status >= 200 & status <= 299:`
**Правильна відповідь:** A
**Пояснення:** Python підтримує зручні подвійні нерівності: `200 <= status <= 299`.

### Питання 13: Який результат виразу `"admin" in ["user", "guest", "admin"]`?
A) `False`
B) `True`
C) `2`
D) `None`
**Правильна відповідь:** B
**Пояснення:** Елемент `"admin"` є у списку, тому оператор `in` поверне `True`.

### Питання 14: Що робить тернарний оператор у Python: `result = "Pass" if score >= 80 else "Fail"`?
A) Створює цикл на 80 ітерацій
B) Присвоює "Pass" якщо score >= 80, інакше присвоює "Fail"
C) Завжди повертає "Pass"
D) Викидає виняток при score < 80
**Правильна відповідь:** B
**Пояснення:** Це компактний спосіб запису умовного виразу в один рядок.

### Питання 15: Що виведе вираз `bool(None)`?
A) `True`
B) `False`
C) `None`
D) Помилку
**Правильна відповідь:** B
**Пояснення:** `None` у булевому контексті завжди оцінюється як `False`.

### Питання 16: Що виведе код:
```python
browser = "chrome"
if browser == "chrome" or browser == "firefox":
    print("Supported")
```
A) `Supported`
B) Нічого
C) `False`
D) Помилку
**Правильна відповідь:** A
**Пояснення:** Перша умова `browser == "chrome"` є істинною, тому вираз повертає `True`.

### Питання 17: Як перевірити, що змінна `response` не є порожньою (`None`)?
A) `if response is not None:`
B) `if response != null:`
C) `if not response.empty():`
D) `if response !== undefined:`
**Правильна відповідь:** A
**Пояснення:** Перевірка ідентичності з `None` у Python ідіоматично виконується через `is not None`.
