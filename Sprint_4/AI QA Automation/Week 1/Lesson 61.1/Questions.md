# Контрольні запитання до Уроку 61.1: Змінні та типи даних

### Питання 1: Як у Python оголошується змінна зі значенням текстового рядка?
A) `string url = "https://site.com"`
B) `url := "https://site.com"`
C) `url = "https://site.com"`
D) `var url = "https://site.com"`
**Правильна відповідь:** C
**Пояснення:** У Python використовується динамічна типізація, тому ім'я типу вказувати не потрібно: `змінна = значення`.

### Питання 2: Який тип даних поверне вираз `type(200)`?
A) `<class 'str'>`
B) `<class 'int'>`
C) `<class 'float'>`
D) `<class 'bool'>`
**Правильна відповідь:** B
**Пояснення:** Число 200 без десяткової частини є цілим числом (`int`).

### Питання 3: Який тип даних матиме змінна `price = 99.95`?
A) `int`
B) `str`
C) `float`
D) `decimal`
**Правильна відповідь:** C
**Пояснення:** Числа з десятковою крапкою належать до типу `float`.

### Питання 4: Що виведе код `print(type(True))`?
A) `<class 'bool'>`
B) `<class 'str'>`
C) `<class 'int'>`
D) `<class 'NoneType'>`
**Правильна відповідь:** A
**Пояснення:** `True` та `False` — це булеві літерали типу `bool`.

### Питання 5: Як правильно записати f-рядок для вставки змінної `user_id = 5` у посилання?
A) `f"https://api.com/users/{user_id}"`
B) `"https://api.com/users/" + {user_id}`
C) `f"https://api.com/users/$user_id"`
D) `string("https://api.com/users/%user_id")`
**Правильна відповідь:** A
**Пояснення:** Перед рядком ставиться літера `f`, а ім'я змінної береться у фігурні дужки `{user_id}`.

### Питання 6: Який результат виконання виразу `int("404")`?
A) `"404"`
B) `404.0`
C) `404`
D) Помилка TypeError
**Правильна відповідь:** C
**Пояснення:** Функція `int()` перетворює рядок із цифрами на ціле число `404`.

### Питання 7: Що станеться при спробі виконати `int("hello")`?
A) Поверне `0`
B) Поверне `None`
C) Викине виняток `ValueError`
D) Поверне `NaN`
**Правильна відповідь:** C
**Пояснення:** Рядок, що містить нечислові символи, неможливо перетворити на ціле число.

### Питання 8: Що робить ключове слово `assert condition, "Error message"`?
A) Створює нову змінну
B) Перевіряє істинність condition; якщо умова False — тест падає з повідомленням
C) Зупиняє виконання коду на 5 секунд
D) Виводить текст у консоль незалежно від умови
**Правильна відповідь:** B
**Пояснення:** `assert` є базовим інструментом перевірок у Python та PyTest.

### Питання 9: Яке значення матиме змінна `is_empty = len("") == 0`?
A) `0`
B) `False`
C) `True`
D) `None`
**Правильна відповідь:** C
**Пояснення:** Довжина порожнього рядка дорівнює 0, тому вираз `0 == 0` повертає `True`.

### Питання 10: Який тип даних буде у результаті операції `10 / 2` у Python 3?
A) `int` (5)
B) `float` (5.0)
C) `str` ("5")
D) `bool` (True)
**Правильна відповідь:** B
**Пояснення:** Звичайне ділення `/` у Python завжди повертає число типу `float` (5.0).

### Питання 11: Як дізнатися довжину рядка `token = "abc123xyz"`?
A) `token.length()`
B) `count(token)`
C) `len(token)`
D) `size(token)`
**Правильна відповідь:** C
**Пояснення:** Вбудована функція `len()` повертає кількість символів у рядку або елементів у колекції.

### Питання 12: Що поверне `str(500)`?
A) Число 500
B) Рядок `"500"`
C) Список `[500]`
D) Булеве значення `True`
**Правильна відповідь:** B
**Пояснення:** `str()` конвертує будь-який об'єкт у рядковий тип.

### Питання 13: Чи є у Python різниця між одинарними `'text'` та подвійними `"text"` лапками?
A) Одинарні для одного символу, подвійні для слів
B) Різниці немає, обидва варіанти створюють об'єкт типу `str`
C) Одинарні лапки не підтримують кирилицю
D) Подвійні лапки створюють незмінні рядки
**Правильна відповідь:** B
**Пояснення:** У Python одинарні та подвійні лапки абсолютно еквівалентні.

### Питання 14: Який результат порівняння `"200" == 200` у Python?
A) `True` (автоматичне приведення типів)
B) `False` (сувора типізація: рядок не дорівнює числу)
C) Викине помилку `TypeError`
D) `None`
**Правильна відповідь:** B
**Пояснення:** Python має сувору типізацію і не приводить типи автоматично при порівнянні `==`.

### Питання 15: Як записати коментар в один рядок у коді Python?
A) `// Це коментар`
B) `/* Це коментар */`
C) `# Це коментар`
D) `-- Це коментар`
**Правильна відповідь:** C
**Пояснення:** Символ `#` позначає однорядковий коментар у Python.

### Питання 16: Що виведе `print("Test" + "Passed")`?
A) `Test Passed`
B) `TestPassed`
C) Помилку
D) `Test+Passed`
**Правильна відповідь:** B
**Пояснення:** Оператор `+` між рядками виконує конкатенацію (склеювання) без додавання пробілів.

### Питання 17: Яка назва змінної є некоректною у Python?
A) `user_name`
B) `test_status_2`
C) `2nd_user`
D) `_is_active`
**Правильна відповідь:** C
**Пояснення:** Імена змінних у Python не можуть починатися з цифри.

### Питання 18: Що таке динамічна типізація?
A) Необхідність вказувати типи вручну
B) Автоматичне визначення типу змінної під час виконання програми за її значенням
C) Заборона зміни значення змінної після її створення
D) Можливість запускати код тільки в хмарі
**Правильна відповідь:** B
**Пояснення:** Динамічна типізація означає, що тип прив'язується до значення в пам'яті під час виконання.

### Питання 19: Що виведе `bool("")` (порожній рядок)?
A) `True`
B) `False`
C) `None`
D) Помилку
**Правильна відповідь:** B
**Пояснення:** Порожні рядки, число 0 та порожні структури приводяться до булевого `False`.
