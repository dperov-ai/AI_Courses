# Контрольні запитання до Уроку 60.3: Цикли

### Питання 1: Який цикл використовується для перебору елементів у списку `[1, 2, 3]`?
A) `for item in [1, 2, 3]:`
B) `while item in [1, 2, 3]:`
C) `loop [1, 2, 3]:`
D) `repeat [1, 2, 3]:`
**Правильна відповідь:** A
**Пояснення:** Цикл `for ... in ...` є стандартним способом ітерації по послідовностях у Python.

### Питання 2: Що робить функція `range(1, 5)`?
A) Генерує числа від 1 до 5 включно (1, 2, 3, 4, 5)
B) Генерує послідовність чисел 1, 2, 3, 4 (до 5 не включно)
C) Створює випадкове число від 1 до 5
D) Повертає список з двох чисел [1, 5]
**Правильна відповідь:** B
**Пояснення:** Правий край у `range(start, stop)` завжди не включається.

### Питання 3: Що робить оператор `break` усередині циклу?
A) Пропускає поточну ітерацію і переходить до наступної
B) Негайно завершує виконання всього циклу
C) Викидає помилку
D) Перезапускає цикл спочатку
**Правильна відповідь:** B
**Пояснення:** `break` здійснює достроковий вихід із тіла циклу.

### Питання 4: Що робить оператор `continue` усередині циклу?
A) Негайно зупиняє всю програму
B) Завершує поточну ітерацію та переходить до наступної
C) Повертає значення з функції
D) Створює нескінченний цикл
**Правильна відповідь:** B
**Пояснення:** `continue` пропускає залишок коду в поточному колі циклу.

### Питання 5: Що виведе наступний код:
```python
for i in range(3):
    print(i, end=" ")
```
A) `1 2 3`
B) `0 1 2`
C) `0 1 2 3`
D) `3`
**Правильна відповідь:** B
**Пояснення:** За замовчуванням `range(n)` починає генерацію з `0`.

### Питання 6: Для чого в автотестах найчастіше використовують цикл `while`?
A) Для розрахунку математичних матриць
B) Для очікування готовності ресурсу (Polling / Wait condition) з обмеженням за кількістю спроб
C) Для малювання графіків
D) Замість оператора assert
**Правильна відповідь:** B
**Пояснення:** `while` ідеально підходить для перевірки стану системи, коли кількість повторень наперед невідома.

### Питання 7: Що поверне функція `enumerate(["a", "b"])`?
A) Пари: `(0, "a")`, `(1, "b")`
B) Список `["a", "b"]`
C) Число 2
D) Помилку
**Правильна відповідь:** A
**Пояснення:** `enumerate()` повертає кортежі з індексом та значенням кожного елемента.

### Питання 8: Що станеться, якщо умова в циклі `while True:` ніколи не змінить своє значення і не містить `break`?
A) Цикл завершиться через 10 секунд
B) Виникне нескінченний цикл (Infinite Loop), програма зависне
C) Python автоматично закриє програму
D) Програма видасть помилку пам'яті через 1 секунду
**Правильна відповідь:** B
**Пояснення:** Завжди потрібна умова виходу або лічильник таймауту для запобігання зацикленню.

### Питання 9: Що робить наступний вираз: `[x * 2 for x in [1, 2, 3]]`?
A) Створює список `[2, 4, 6]`
B) Множить список на 2 `[1, 2, 3, 1, 2, 3]`
C) Повертає число 6
D) Повертає `True`
**Правильна відповідь:** A
**Пояснення:** Це List Comprehension, який множить кожен елемент на 2.

### Питання 10: Скільки разів виконається тіло циклу:
```python
count = 0
while count < 3:
    count += 1
```
A) 2 рази
B) 3 рази
C) 4 рази
D) Нескінченно
**Правильна відповідь:** B
**Пояснення:** Цикл виконається для count = 0, 1, 2 (всього 3 рази).

### Питання 11: Як безпечно перервати цикл очікування за таймаутом?
A) Додати лічильник спроб `attempts += 1` та перевірку `if attempts >= max_attempts: break`
B) Видалити цикл
C) Запустити два цикли одночасно
D) Збільшити оперативну пам'ять
**Правильна відповідь:** A
**Пояснення:** Обмеження кількості спроб гарантує, що тест завершиться за фіксований час.

### Питання 12: Чи можна перебирати символи текстового рядка за допомогою циклу `for char in "QA":`?
A) Ні, рядки не можна перебирати
B) Так, на першому кроці char="Q", на другому char="A"
C) Тільки якщо рядок перетворено на масив чисел
D) Тільки в Python 2
**Правильна відповідь:** B
**Пояснення:** Рядок у Python є ітерованою послідовністю символів.

### Питання 13: Що виведе код:
```python
for num in [1, 2, 3, 4, 5]:
    if num == 3:
        continue
    if num == 4:
        break
    print(num, end=" ")
```
A) `1 2 3`
B) `1 2`
C) `1 2 4 5`
D) `1 2 3 4`
**Правильна відповідь:** B
**Пояснення:** Для 1 і 2 надрукує `1 2`. Для 3 спрацює `continue` (пропуск). Для 4 спрацює `break` (вихід).

### Питання 14: Як відфільтрувати список статусів, залишивши тільки ті, що дорівнюють 200: `statuses = [200, 404, 200, 500]`?
A) `[s for s in statuses if s == 200]`
B) `statuses.filter(200)`
C) `statuses == 200`
D) `[if s == 200 for s in statuses]`
**Правильна відповідь:** A
**Пояснення:** Синтаксис List Comprehension з умовою фільтрації: `[item for item in list if condition]`.

### Питання 15: Що поверне `len([i for i in range(10)])`?
A) 9
B) 10
C) 11
D) 0
**Правильна відповідь:** B
**Пояснення:** Послідовність містить 10 чисел (від 0 до 9).

### Питання 16: Яка функція дозволяє робити штучну затримку в секундах всередині циклу?
A) `wait(1)`
B) `time.sleep(1)`
C) `pause(1)`
D) `delay(1)`
**Правильна відповідь:** B
**Пояснення:** Модуль `time` та функція `time.sleep(seconds)` призупиняють виконання потоку.

### Питання 17: Яка конструкція виконується в Python, якщо цикл завершився природно (без спрацьовування `break`)?
A) `finally:`
B) `else:` після блоку циклу
C) `catch:`
D) `default:`
**Правильна відповідь:** B
**Пояснення:** Python підтримує унікальну конструкцію `for ... else:`, де блок `else` виконується, якщо не було `break`.
