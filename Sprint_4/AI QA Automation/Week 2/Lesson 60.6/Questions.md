# Контрольні запитання до Уроку 60.6: Класи та об’єкти

### Питання 1: Що таке клас у Python?
A) Функція без параметрів
B) Шаблон (креслення) для створення об'єктів з однаковими атрибутами та методами
C) Текстовий файл зі списком тестів
D) Модуль для роботи з базою даних
**Правильна відповідь:** B
**Пояснення:** Клас визначає структуру та поведінку майбутніх об'єктів (екземплярів).

### Питання 2: Яке призначення спеціального методу `__init__`?
A) Видалення об'єкта з пам'яті
B) Ініціалізація атрибутів об'єкта під час його створення (Конструктор)
C) Запуск автоматичних тестів
D) Підключення до інтернету
**Правильна відповідь:** B
**Пояснення:** `__init__` автоматично викликається при створенні нового екземпляра класу.

### Питання 3: Що означає перший параметр `self` у методах класу?
A) Посилання на поточний екземпляр класу, для якого викликається метод
B) Ключове слово для створення циклу
C) Ім'я поточного користувача операційної системи
D) Глобальна змінна Python
**Правильна відповідь:** A
**Пояснення:** Через `self` методи отримують доступ до атрибутів та інших методів конкретного об'єкта.

### Питання 4: У чому полягає суть патерну Page Object Model (POM)?
A) Розділення локаторів та дій на сторінці від коду самих тестових перевірок
B) Запуск тестів у 10 потоків
C) Збереження скріншотів у форматі PNG
D) Генерація документації у PDF
**Правильна відповідь:** A
**Пояснення:** POM інкапсулює селектори та логіку взаємодії зі сторінкою в окремі класи.

### Питання 5: Як створити об'єкт `login_page` класу `LoginPage`?
A) `login_page = new LoginPage(driver)`
B) `login_page = LoginPage(driver)`
C) `create LoginPage login_page`
D) `login_page := LoginPage.init()`
**Правильна відповідь:** B
**Пояснення:** У Python створення екземпляра здійснюється викликом імені класу з аргументами конструктора.

### Питання 6: Що таке атрибут об'єкта (наприклад, `self.timeout = 10`)?
A) Змінна, що належить конкретному екземпляру класу і зберігає його стан
B) Назва файлу скрипта
C) Системний виняток
D) Бібліотека тестів
**Правильна відповідь:** A
**Пояснення:** Атрибути зберігають індивідуальні дані об'єкта.

### Питання 7: Що таке успадкування (Inheritance) у класах?
A) Механізм, що дозволяє класу-нащадку отримувати всі методи та атрибути батьківського класу
B) Видалення коду після виконання
C) Створення копії файлу на диску
D) Шифрування паролів
**Правильна відповідь:** A
**Пояснення:** Успадкування дозволяє перевикористовувати спільний функціонал (наприклад, з `BasePage`).

### Питання 8: Як оголосити клас `CartPage`, що успадковує `BasePage`?
A) `class CartPage(BasePage):`
B) `class CartPage extends BasePage:`
C) `class CartPage implements BasePage:`
D) `class CartPage : BasePage`
**Правильна відповідь:** A
**Пояснення:** У Python ім'я батьківського класу вказується у круглих дужках після імені класу.

### Питання 9: Чому зміна локатора кнопки в Page Object автоматично оновлює всі 50 тестів, що її використовують?
A) Локатор визначено в одному місці (всередині класу сторінки)
B) Python самостійно знаходить селектори на сторінці
C) Тести запускаються через хмару
D) Це робить операційна система
**Правильна відповідь:** A
**Пояснення:** Це головна цінність інкапсуляції селекторів у патерні POM.

### Питання 10: Що таке метод класу?
A) Функція, яка визначена всередині класу та оперує даними об'єкта через `self`
B) Глобальна змінна
C) Текст коментаря
D) Назва веб-браузера
**Правильна відповідь:** A
**Пояснення:** Методи описують поведінку та дії об'єкта.

### Питання 11: Як викликати метод `open()` для створеного об'єкта `page = LoginPage(driver)`?
A) `page.open()`
B) `open(page)`
C) `LoginPage::open(page)`
D) `call page.open`
**Правильна відповідь:** A
**Пояснення:** Виклик методу здійснюється через крапку: `об'єкт.метод()`.

### Питання 12: Чи можна створити кілька різних об'єктів одного і того ж класу?
A) Ні, тільки один
B) Так, кожен об'єкт матиме свій власний незалежний стан у пам'яті
C) Тільки в багатопоточному режимі
D) Тільки в Python 3.12
**Правильна відповідь:** B
**Пояснення:** Можна створювати необмежену кількість екземплярів одного класу.

### Питання 13: Що робить функція `super().__init__(driver)` у класі-нащадку?
A) Викликає конструктор батьківського класу для коректної ініціалізації
B) Закриває браузер
C) Очищує пам'ять
D) Викидає помилку
**Правильна відповідь:** A
**Пояснення:** `super()` надає доступ до методів батьківського класу.

### Питання 14: Як позначаються приватні (внутрішні) методи або атрибути в Python за конвенцією PEP 8?
A) З одним або двома символами підкреслення на початку: `_locator` або `__secret`
B) Ключовим словом `private`
C) Великими літерами
D) Вони не підтримуються
**Правильна відповідь:** A
**Пояснення:** Символ `_` сигналізує розробникам, що атрибут призначений для внутрішнього використання класом.

### Питання 15: Чому не рекомендується додавати оператори `assert` всередину методів Page Object?
A) Page Object повинен лише надавати доступ до елементів та дій, а перевірки мають бути в тілі тесту
B) Page Object не підтримує assert
C) Це заборонено мовою Python
D) Це сповільнює тест у 10 разів
**Правильна відповідь:** A
**Пояснення:** Найкраща практика: Page Objects повертають стан/дані, а тестовий сценарій містить `assert`.

### Питання 16: Що виведе вираз `isinstance(login_page, BasePage)` якщо `LoginPage` успадковує `BasePage`?
A) `True`
B) `False`
C) `None`
D) `TypeError`
**Правильна відповідь:** A
**Пояснення:** `isinstance()` перевіряє, чи є об'єкт екземпляром вказаного класу або його батьківського класу.

### Питання 17: Яка головна перевага використання класів для представлення конфігураційного середовища (`Config`)?
A) Централізоване зберігання налаштувань (URL, таймаути, креди) зі зручним автодоповненням в IDE
B) Зменшення розміру коду в 100 разів
C) Автоматичне проходження тестів
D) Можливість запускати тести без Python
**Правильна відповідь:** A
**Пояснення:** Класи конфігурації структурують налаштування проекту та забезпечують автокомпліт у редакторі.
