# Контрольні запитання до Уроку 61.4: Функції

### Питання 1: Яке ключове слово використовується для створення функції у Python?
A) `function`
B) `def`
C) `fn`
D) `create`
**Правильна відповідь:** B
**Пояснення:** У Python функції оголошуються ключовим словом `def` (скорочення від define).

### Питання 2: Що робить інструкція `return` всередині функції?
A) Перезапускає функцію
B) Завершує виконання функції та повертає результат у точку виклику
C) Виводить текст у консоль
D) Викидає виняток
**Правильна відповідь:** B
**Пояснення:** `return` повертає значення та негайно завершує роботу функції.

### Питання 3: Що поверне функція, якщо в її тілі немає оператора `return`?
A) `0`
B) `False`
C) `None`
D) Помилку
**Правильна відповідь:** C
**Пояснення:** Якщо `return` не вказано явно, функція в Python повертає об'єкт `None`.

### Питання 4: Як задати значення параметра за замовчуванням?
A) `def login(timeout := 10):`
B) `def login(timeout = 10):`
C) `def login(default timeout 10):`
D) `def login(timeout: default=10):`
**Правильна відповідь:** B
**Пояснення:** Значення за замовчуванням задається через знак `=` у списку параметрів.

### Питання 5: У чому полягає головна перевага принципу DRY в автотестах?
A) Тести швидше компілюються
B) Зменшується дублювання коду, зміни вносяться в одному місці (Helper / Page Object)
C) Тести не потребують завантаження драйвера
D) Збільшується розмір логів
**Правильна відповідь:** B
**Пояснення:** DRY мінімізує дублювання однакових дій між різними тестовими сценаріями.

### Питання 6: Що виведе код:
```python
def add(a, b=5):
    return a + b
print(add(3))
```
A) `8`
B) `3`
C) `5`
D) Помилку
**Правильна відповідь:** A
**Пояснення:** `a` отримує значення 3, `b` береться за замовчуванням як 5, результат `3 + 5 = 8`.

### Питання 7: Що таке Docstring у функції?
A) Спеціальний рядок документації в потрійних лапках на початку функції
B) Назва файлу тесту
C) Тип повернення помилки
D) Команда для терміналу
**Правильна відповідь:** A
**Пояснення:** Docstring описує призначення функції, її параметри та поведінку.

### Питання 8: Що станеться при виклику `login()` для функції `def login(user, password):` без аргументів?
A) Аргументи стануть `None`
B) Викине помилку `TypeError: missing required positional arguments`
C) Функція поверне `True`
D) Функція не виконається без помилки
**Правильна відповідь:** B
**Пояснення:** Обов'язкові позиційні аргументи повинні передаватися при кожному виклику.

### Питання 9: Що таке іменовані аргументи (Keyword Arguments)?
A) Аргументи, що передаються із зазначенням імені параметра: `login(user="ivan", password="123")`
B) Аргументи, що містять тільки великі літери
C) Глобальні змінні
D) Змінні без значень
**Правильна відповідь:** A
**Пояснення:** Іменовані аргументи підвищують читабельність коду та дозволяють передавати параметри в довільному порядку.

### Питання 10: Чи може функція в Python повертати кілька значень одночасно?
A) Ні, тільки одне число
B) Так, повертаючи їх через кому у вигляді кортежу (tuple): `return status, body`
C) Тільки через глобальну змінну
D) Тільки в асинхронних функціях
**Правильна відповідь:** B
**Пояснення:** `return a, b` упаковує значення в кортеж `(a, b)`.

### Питання 11: Що станеться з кодом після виклику `return` всередині функції?
A) Він виконається двічі
B) Він буде проігнорований (не виконається)
C) Викине помилку
D) Виконається у фоновому потоці
**Правильна відповідь:** B
**Пояснення:** Інструкція `return` негайно передає керування назад у викликаючий код.

### Питання 12: Що таке анотації типів (Type Hints): `def get_user(id: int) -> str:`?
A) Сувора заборона передавати інші типи на рівні компілятора
B) Підказки для розробника та лінтерів щодо очікуваних типів даних
C) Команди для операційної системи
D) Спосіб шифрування коду
**Правильна відповідь:** B
**Пояснення:** Type Hints полегшують читання коду та допомагають IDE знаходити помилки.

### Питання 13: Чи має функція доступ до глобальних змінних?
A) Так, функція може зчитувати змінні, оголошені поза її межами
B) Ніколи
C) Тільки після імпорту модуля math
D) Тільки якщо функція називається main
**Правильна відповідь:** A
**Пояснення:** Функції мають доступ до зовнішньої (глобальної) області видимості на читання.

### Питання 14: Що робить допоміжна функція `generate_random_email()`?
A) Видаляє старі листи
B) Створює унікальну тестову поштову адресу для реєстрації нового користувача
C) Блокує поштовий сервер
D) Відправляє спам
**Правильна відповідь:** B
**Пояснення:** Це класичний Helper для ізоляції тестових даних у кожному тесті.

### Питання 15: Що буде результатом виклику `print(log_step("Click"))` якщо функція не має `return`?
A) Виведе повідомлення і поверне `None`
B) Помилка
C) `0`
D) `False`
**Правильна відповідь:** A
**Пояснення:** Функція виконає свій `print()`, а зовнішній `print()` надрукує значення `None`.

### Питання 16: Як передати довільну кількість аргументів у функцію?
A) Використовуючи оператор `*args`
B) За допомогою оператора `all_args`
C) Через кому 100 разів
D) Це неможливо
**Правильна відповідь:** A
**Пояснення:** `*args` дозволяє приймати змінну кількість позиційних аргументів у вигляді кортежу.

### Питання 17: Чому важливо давати функціям зрозумілі дієслівні назви (`click_submit_button`, `calculate_total`)?
A) Щоб код тестів читався як зрозуміла документація до продукту
B) Це вимога операційної системи
C) Без цього тести не запускаються в CI
D) Щоб збільшити розмір файлу
**Правильна відповідь:** A
**Пояснення:** Читабельність тестів є критичною для швидкої локалізації багів усією командою.
