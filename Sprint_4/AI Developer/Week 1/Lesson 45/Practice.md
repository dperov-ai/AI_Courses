### Завдання 1. Система перевірки прав доступу до сервісу (Базовий рівень)

#### Опис завдання:
Створіть логіку авторизації та маршрутизації користувача залежно від його ролі (`admin`, `manager`, `guest`), статусу підтвердження email та активності облікового запису.

#### Інструкція:
1. Задайте змінні: `role`, `is_email_verified`, `is_banned`.
2. Реалізуйте перевірки:
   - Якщо `is_banned == True` -> вивести «Доступ заблоковано! Зверніться до підтримки».
   - Якщо email не підтверджено -> вивести «Будь ласка, підтвердіть вашу електронну пошту».
   - Залежно від ролі вивести відповідну панель: Admin Dashboard, Manager Workspace або Guest Catalog.

#### Зразок розв'язку:
```python
role = "manager"
is_email_verified = True
is_banned = False

if is_banned:
    print("❌ Помилка: Ваш акаунт заблоковано.")
elif not is_email_verified:
    print("⚠️ Увага: Підтвердіть вашу електронну пошту для продовження.")
else:
    if role == "admin":
        print("🔓 Доступ дозволено: Відкрито панель адміністратора [Admin Dashboard].")
    elif role == "manager":
        print("🔓 Доступ дозволено: Відкрито робочий простір менеджера [Manager Workspace].")
    elif role == "guest":
        print("👀 Доступ дозволено: Відкрито каталог для перегляду [Guest Catalog].")
    else:
        print("❓ Невідома роль користувача.")
```

### Завдання 2. Класифікатор статусу транзакції банку (Прикладний рівень)

#### Опис завдання:
Напишіть систему прийняття рішень щодо фінансової транзакції на основі суми, країни операції та підозрілості активності (Fraud Prevention).

#### Правила:
- Сума <= 0 -> помилка валідації.
- Сума > 50,000 грн або операція з ризикової країни -> відправити на ручну верифікацію (Manual Review).
- Сума > 10,000 грн -> вимагати додаткове 2FA-підтвердження.
- В інших випадках -> автоматичне схвалення (Approved).

#### Зразок розв'язку:
```python
amount = 15000.0
country = "UA"
is_flagged_ip = False
high_risk_countries = ["XX", "YY", "ZZ"]

if amount <= 0:
    status = "REJECTED_INVALID_AMOUNT"
elif amount > 50000 or country in high_risk_countries or is_flagged_ip:
    status = "MANUAL_REVIEW_REQUIRED"
elif amount > 10000:
    status = "REQUIRE_2FA_CONFIRMATION"
else:
    status = "AUTO_APPROVED"

print(f"Сума: {amount} грн | Країна: {country} | Статус транзакції: {status}")
```
