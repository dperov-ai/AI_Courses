### Завдання 1. Пакетна обробка та фільтрація даних (Базовий рівень)

#### Опис завдання:
Маємо список ідентифікаторів завдань (Task IDs) та їхніх статусів виконання. Потрібно перебрати всі завдання, порахувати кількість успішних і провалених, а також зупинити обробку у разі виявлення критичного збою `CRITICAL_ERROR`.

#### Інструкція:
1. Задайте список статусів: `["SUCCESS", "SUCCESS", "FAILED", "SUCCESS", "CRITICAL_ERROR", "SUCCESS"]`.
2. За допомогою циклу `for` обробіть кожен статус.
3. Якщо статус `FAILED` — збільшіть лічильник невдалих спроб і продовжуйте (`continue`).
4. Якщо статус `CRITICAL_ERROR` — перервіть обробку за допомогою `break`.

#### Зразок розв'язку:
```python
task_statuses = ["SUCCESS", "SUCCESS", "FAILED", "SUCCESS", "CRITICAL_ERROR", "SUCCESS"]

success_count = 0
failed_count = 0

for index, status in enumerate(task_statuses, start=1):
    print(f"Обробка завдання #{index}: статус {status}")
    
    if status == "CRITICAL_ERROR":
        print("🚨 Виявлено критичну помилку! Аварійна зупинка циклу.")
        break
    elif status == "FAILED":
        failed_count += 1
        print("⚠️ Завдання зазнало невдачі, переходимо до наступного.")
        continue
    elif status == "SUCCESS":
        success_count += 1

print("-" * 30)
print(f"Успішно завершено: {success_count}")
print(f"Завершено з помилкою: {failed_count}")
```

### Завдання 2. Симуляція механізму повторних спроб (Retry Mechanism з циклом while) (Прикладний рівень)

#### Опис завдання:
Реалізуйте цикл `while`, що симулює опитування API-сервісу з обмеженою кількістю спроб (наприклад, максимум 5 спроб) та затримкою або симуляцією отримання відповіді.

#### Зразок розв'язку:
```python
max_retries = 5
current_attempt = 0
is_service_ready = False

while current_attempt < max_retries and not is_service_ready:
    current_attempt += 1
    print(f"Спроба #{current_attempt}: Опитування зовнішнього сервісу...")
    
    # Симулюємо, що на 3-й спробі сервіс стає доступним
    if current_attempt == 3:
        is_service_ready = True
        print("✅ Сервіс успішно відповів!")
    else:
        print("⏳ Сервіс зайнятий, очікування...")

if not is_service_ready:
    print("❌ Вичерпано ліміт спроб. Сервіс недоступний.")
else:
    print(f"🎉 З'єднання встановлено з {current_attempt}-ї спроби.")
```
