## Мета практики
Отримати практичне розуміння того, як вихідний код трансформується у виконання, навчитися запускати скрипти в середовищі Python, аналізувати різницю між кодом та помилками інтерпретації, а також використовувати AI для первинного пояснення поведінки програми.

### Завдання 1. Перший запуск та аналіз процесу інтерпретації (Базовий рівень)

#### Опис завдання:
Створіть свій перший Python-скрипт `first_program.py`, що виводить системну інформацію про версію платформи та виконує базові математичні обчислення.

#### Інструкція:
1. Створіть файл `first_program.py`.
2. Напишіть код, який імпортує модуль `sys` та виводить версію Python, а також обчислює площу прямокутника зі сторонами $a = 12$ та $b = 8$.
3. Запустіть програму через термінал командою: `python first_program.py`.

#### Зразок коду та розв'язку:
```python
import sys

print("--- Інформація про середовище виконання ---")
print(f"Версія Python: {sys.version}")
print(f"Платформа: {sys.platform}")

# Базові обчислення
length = 12
width = 8
area = length * width

print(f"Площа прямокутника зі сторонами {length} та {width} дорівнює: {area}")
```

#### Очікуваний результат у консолі:
```text
--- Інформація про середовище виконання ---
Версія Python: 3.x.x (...)
Платформа: win32 (або linux / darwin)
Площа прямокутника зі сторонами 12 та 8 дорівнює: 96
```

### Завдання 2. Дослідження компіляції в байткод та виправлення синтаксичної помилки (Прикладний рівень)

#### Опис завдання:
Змоделюйте помилку етапу синтаксичного аналізу (Syntax Error) та помилку часу виконання (Runtime Error). Поспостерігайте, як інтерпретатор Python поводиться в обох випадках.

#### Інструкція:
1. Створіть файл `errors_demo.py` з кодом, що містить синтаксичну помилку (наприклад, незакриту дужку або відсутню двокрапку).
2. Запустіть скрипт і зафіксуйте текст повідомлення Traceback.
3. Виправте синтаксичну помилку, але додайте ділення на нуль, щоб перевірити Runtime Error.
4. Проаналізуйте, на якому рядку зупинилося виконання.

#### Зразок коду з виправленням:
```python
# Демонстрація контрольованого виконання
print("Крок 1: Програма почала роботу")

a = 10
b = 2  # Спробуйте змінити на 0 для відтворення ZeroDivisionError

if b != 0:
    result = a / b
    print(f"Крок 2: Результат ділення = {result}")
else:
    print("Крок 2: Помилка — ділення на нуль неможливе!")

print("Крок 3: Програма успішно завершилася")
```
