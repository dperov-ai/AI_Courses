### Завдання 1. Калькулятор замовлення інтернет-магазину (Базовий рівень)

#### Опис завдання:
Створіть програму розрахунку підсумкової вартості замовлення клієнта з урахуванням кількості товару, ціни за одиницю, податку та персональної знижки.

#### Інструкція:
1. Оголосіть змінні:
   - `item_name` (рядок): `"Бездротові навушники"`
   - `unit_price` (дійсне число): `1499.50`
   - `quantity` (ціле число): `3`
   - `discount_rate` (дійсне число): `0.10` (10% знижки)
   - `is_free_shipping` (булеве значення): `True`
2. Обчисліть проміжну суму, суму знижки та фінальну суму до сплати.
3. Виведіть охайний чек за допомогою f-strings.

#### Зразок розв'язку:
```python
item_name: str = "Бездротові навушники"
unit_price: float = 1499.50
quantity: int = 3
discount_rate: float = 0.10
is_free_shipping: bool = True

subtotal = unit_price * quantity
discount_amount = subtotal * discount_rate
total_price = subtotal - discount_amount

print("=" * 40)
print(f"Товар: {item_name}")
print(f"Ціна за од.: {unit_price:.2f} грн | К-сть: {quantity}")
print(f"Сума без знижки: {subtotal:.2f} грн")
print(f"Знижка ({int(discount_rate * 100)}%): -{discount_amount:.2f} грн")
print(f"До сплати: {total_price:.2f} грн")
print(f"Безкоштовна доставка: {'Так' if is_free_shipping else 'Ні'}")
print("=" * 40)
```

### Завдання 2. Безпечне приведення типів та парсинг введених даних (Прикладний рівень)

#### Опис завдання:
Напишіть скрипт, який отримує рядкові значення (як це зазвичай буває при читанні з конфігураційних файлів або HTTP-запитів) та безпечно конвертує їх у відповідні типи `int`, `float`, `bool`.

#### Інструкція:
1. Задайте змінні: `raw_age = "28"`, `raw_balance = "3450.75"`, `raw_is_active = "true"`.
2. Виконайте приведення типів. Для булевого значення врахуйте, що `bool("false")` повертає `True`, тому використовуйте перевірку рівності рядків: `raw_is_active.lower() == "true"`.
3. Виведіть тип кожної змінної за допомогою функції `type()`.

#### Зразок розв'язку:
```python
raw_age = "28"
raw_balance = "3450.75"
raw_is_active = "True"

# Конвертація
user_age = int(raw_age)
user_balance = float(raw_balance)
user_is_active = raw_is_active.strip().lower() in ("true", "1", "yes")

print(f"user_age: {user_age} -> {type(user_age)}")
print(f"user_balance: {user_balance} -> {type(user_balance)}")
print(f"user_is_active: {user_is_active} -> {type(user_is_active)}")
```
