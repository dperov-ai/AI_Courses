### Завдання 1. Агрегація та аналіз журналу користувачів (Базовий рівень)

#### Опис завдання:
Маємо список словників із даними користувачів. Потрібно знайти всіх активних користувачів, обчислити середній баланс та зібрати унікальний набір міст за допомогою `set`.

#### Інструкція:
1. Створіть структуру даних `users`.
2. За допомогою спискового включення відфільтруйте активних користувачів.
3. Використайте `set` для знаходження списку унікальних міст.

#### Зразок розв'язку:
```python
users = [
    {"id": 1, "name": "Олена", "city": "Київ", "balance": 4500.0, "is_active": True},
    {"id": 2, "name": "Максим", "city": "Львів", "balance": 1200.0, "is_active": False},
    {"id": 3, "name": "Ірина", "city": "Київ", "balance": 8900.0, "is_active": True},
    {"id": 4, "name": "Дмитро", "city": "Одеса", "balance": 3100.0, "is_active": True},
    {"id": 5, "name": "Анна", "city": "Львів", "balance": 6200.0, "is_active": True},
]

# 1. Фільтрація активних користувачів
active_users = [u for u in users if u["is_active"]]

# 2. Розрахунок середнього балансу активних
total_balance = sum(u["balance"] for u in active_users)
avg_balance = total_balance / len(active_users) if active_users else 0.0

# 3. Унікальні міста
unique_cities = {u["city"] for u in users}

print(f"Кількість активних користувачів: {len(active_users)}")
print(f"Середній баланс активних клієнтів: {avg_balance:.2f} грн")
print(f"Географія клієнтів (унікальні міста): {unique_cities}")
```

### Завдання 2. Групування транзакцій за категоріями за допомогою словника (Прикладний рівень)

#### Опис завдання:
Згрупуйте список витрат за категоріями (`'Food'`, `'Transport'`, `'Utilities'`) та підрахуйте загальну суму по кожній категорії.

#### Зразок розв'язку:
```python
expenses = [
    {"category": "Food", "amount": 250.0},
    {"category": "Transport", "amount": 50.0},
    {"category": "Food", "amount": 420.0},
    {"category": "Utilities", "amount": 1200.0},
    {"category": "Food", "amount": 180.0},
    {"category": "Transport", "amount": 150.0},
]

category_totals: dict[str, float] = {}

for item in expenses:
    cat = item["category"]
    amt = item["amount"]
    category_totals[cat] = category_totals.get(cat, 0.0) + amt

print("Підсумкові витрати за категоріями:")
for cat, total in sorted(category_totals.items(), key=lambda x: x[1], reverse=True):
    print(f" - {cat}: {total:.2f} грн")
```
