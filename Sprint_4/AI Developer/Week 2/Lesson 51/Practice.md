### Завдання 1. Трасування виконання та прогнозування виводу (Code Tracing) (Базовий рівень)

#### Опис завдання:
Прочитайте наданий фрагмент коду «очима» без попереднього запуску в терміналі. Складіть таблицю трасування значень змінних та спрогнозуйте фінальний вивід програми.

#### Код для аналізу:
```python
def process_data(items: list[int]) -> list[int]:
    result = []
    multiplier = 2
    for num in items:
        if num % 2 == 0:
            val = num * multiplier
            result.append(val)
        else:
            val = num + 1
            if val > 5:
                result.append(val)
    return result

data = [1, 2, 3, 4, 5, 6]
output = process_data(data)
print("Фінальний результат:", output)
```

#### Інструкція:
1. Заповніть таблицю для кожного елемента списку `data`:
   - Ітерація 1: `num = 1` -> непарне -> `val = 2` -> `val > 5` (False) -> не додається.
   - Ітерація 2: `num = 2` -> парне -> `val = 4` -> додається `[4]`.
   - Ітерація 3: `num = 3` -> непарне -> `val = 4` -> `val > 5` (False).
   - Ітерація 4: `num = 4` -> парне -> `val = 8` -> додається `[4, 8]`.
   - Ітерація 5: `num = 5` -> непарне -> `val = 6` -> `val > 5` (True) -> додається `[4, 8, 6]`.
   - Ітерація 6: `num = 6` -> парне -> `val = 12` -> додається `[4, 8, 6, 12]`.
2. Запустіть код у Python та звірте свій прогноз із фактичним результатом.

### Завдання 2. Code Review та виправлення прихованого багу (Прикладний рівень)

#### Опис завдання:
У наведеному коді авторизації є 2 типові помилки: зсув індексу (IndexError при порожньому списку) та небезпечна мутація аргументу за замовчуванням. Знайдіть їх та виправте.

#### Проблемний код:
```python
# Початковий код з помилками
def register_user(username, roles=[]):  # Помилка 1: mutable default argument
    roles.append("USER")
    return {"name": username, "roles": roles}

# При виклику для різних користувачів ролі будуть накопичуватися у спільному списку!
user1 = register_user("Alice")
user2 = register_user("Bob")
print(user1)  # Має містити лише 1 роль, але отримає дві!
print(user2)
```

#### Виправлений варіант:
```python
def register_user(username: str, roles: list[str] | None = None) -> dict:
    if roles is None:
        roles = []
    # Створюємо копію або новий список для ізоляції
    user_roles = list(roles)
    user_roles.append("USER")
    return {"name": username, "roles": user_roles}

user1 = register_user("Alice")
user2 = register_user("Bob")
print("User 1:", user1)
print("User 2:", user2)
```
