# Практичні завдання до Уроку 54: Генерація checklist, test cases та exploratory testing ideas

## Мета практики
Опанувати швидку генерацію структурованих чеклістів, детальних тест-кейсів та креативних ідей для дослідницького тестування (Exploratory Testing Charters) за допомогою AI.

---

### Завдання 1. Побудова чекліста валідації форми зміни пароля (Базовий рівень)

#### Опис завдання:
Створіть компактний та дієвий чекліст для тестування форми «Зміна пароля» (Current Password, New Password, Confirm New Password).

#### Зразок чекліста:
```markdown
### Чекліст: Форма зміни пароля
- [ ] **Позитивні сценарії**:
  - [ ] Успішна зміна з дотриманням політики складності (мінімум 8 символів, велика літера, спецсимвол, цифра).
  - [ ] Автоматичне розлогінювання на всіх інших пристроях після зміни.
  - [ ] Надсилання email-повідомлення про успішну зміну пароля.
- [ ] **Негативні та валідаційні перевірки**:
  - [ ] Введення невірного поточного пароля.
  - [ ] Неспівпадіння полів "New Password" та "Confirm New Password".
  - [ ] Використання попередніх 3-х старих паролів (якщо діє політика історії паролів).
  - [ ] Введення пароля, що складається лише з пробілів.
- [ ] **UI/UX та безпека**:
  - [ ] Маскування символів зірочками та функція "Показати/приховати пароль" (іконка ока).
  - [ ] Блокування форми після 5 невдалих спроб введення старого пароля (Brute-force protection).
  - [ ] Заборона автозаповнення та вставки (Copy-Paste) у чутливих полях, якщо вимагається специфікацією.
```

### Завдання 2. AI-генерація Exploratory Testing Charter за моделлю Джеймса Баха (Прикладний рівень)

#### Опис завдання:
Складіть чартер (Charter) для сесії дослідницького тестування функціоналу фільтрації товарів у великому каталозі із застосуванням AI.

#### Промпт для AI:
> «Створи Exploratory Testing Charter (Місія, Зона дослідження, Евристики тестування, Цільові ризики, Тривалість 45 хв) для модуля пошуку та фільтрації товарів за ціною, брендом і наявністю на складі. Додай 5 нестандартних ідей для перевірки (stress-testing фільтрів, швидкі кліки, спецсимволи в пошуку, повернення назад у браузері).»
