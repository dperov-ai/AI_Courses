### Завдання 1. Програмна генерація синтетичних користувачів через Python Faker (Базовий рівень)

#### Опис завдання:
Напишіть скрипт для генерації 5 синтетичних профілів українських користувачів з унікальними даними для заповнення форми реєстрації.

#### Зразок розв'язку:
```python
import random
import uuid

# Простий генератор тестових даних без зовнішніх залежностей
first_names = ["Олександр", "Марія", "Андрій", "Оксана", "Дмитро", "Юлія"]
last_names = ["Ковальчук", "Шевченко", "Бондаренко", "Ткаченко", "Кравченко"]
cities = ["Київ", "Львів", "Одеса", "Харків", "Дніпро"]

def generate_test_user(index: int) -> dict:
    fname = random.choice(first_names)
    lname = random.choice(last_names)
    unique_id = uuid.uuid4().hex[:6]
    return {
        "id": index,
        "first_name": fname,
        "last_name": lname,
        "email": f"{fname.lower()}.{lname.lower()}_{unique_id}@testqa.com",
        "phone": f"+38050{random.randint(1000000, 9999999)}",
        "city": random.choice(cities),
        "age": random.randint(18, 65),
        "is_subscribed": random.choice([True, False])
    }

test_dataset = [generate_test_user(i) for i in range(1, 6)]

import json
print(json.dumps(test_dataset, ensure_ascii=False, indent=2))
```

### Завдання 2. AI-генерація граничних та екстремальних значень (Boundary & Malicious Data) (Прикладний рівень)

#### Опис завдання:
Сформулюйте промпт до AI для генерації масиву специфічних тестових даних для поля «Ім'я користувача» (First Name) для перевірки надійності системи.

#### Промпт для AI:
> «Згенеруй JSON-масив з 10 екстремальними тестовими даними для поля 'First Name' форми реєстрації:
> 1) Мінімальна довжина (1 символ).
> 2) Максимальна довжина (255 символів).
> 3) Рядок з апострофом (наприклад, О'Коннор, Лук'ян).
> 4) Подвійне ім'я з дефісом (Анна-Марія).
> 5) Ім'я з діакритичними знаками та ієрогліфами (UTF-8).
> 6) SQL Injection рядок (`' OR '1'='1`).
> 7) XSS payload (`<script>alert(1)</script>`).
> 8) Рядок з емодзі (🇺🇦 QA).
> 9) Лише пробіли (`   `).
> 10) Спецсимволи та табуляції.»
