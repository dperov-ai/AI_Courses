## Мета практики
Опанувати практичну інтеграцію AI-інструментів у щоденний робочий процес інженера з контролю якості (QA Engineer), навчитися безпечно працювати з конфіденційними даними (Data Privacy & Sanitization) та вимірювати прискорення підготовки тестових артефактів.

### Завдання 1. Санітизація та знеособлення чутливих даних перед відправкою в AI (Базовий рівень)

#### Опис завдання:
Перед передачею опису бага або логів у публічну LLM необхідно приховати персональні дані (PII), токени та IP-адреси. Напишіть скрипт або набір регулярних виразів для знеособлення тексту логу.

#### Вхідний фрагмент логу:
```text
2026-09-14 10:15:22 ERROR [auth_service] Failed login for user_email='taras.shevchenko@company.ua', IP='192.168.1.105', API_TOKEN='sk-live-9923847293847192', Card='4111-2222-3333-4444'
```

#### Зразок розв'язку на Python:
```python
import re

raw_log = "2026-09-14 10:15:22 ERROR [auth_service] Failed login for user_email='taras.shevchenko@company.ua', IP='192.168.1.105', API_TOKEN='sk-live-9923847293847192', Card='4111-2222-3333-4444'"

# Маскування пошти
sanitized = re.sub(r"[\w\.-]+@[\w\.-]+", "[ANONYMIZED_EMAIL]", raw_log)
# Маскування токенів
sanitized = re.sub(r"sk-live-[a-zA-Z0-9]+", "[HIDDEN_TOKEN]", sanitized)
# Маскування IP
sanitized = re.sub(r"\b(?:\d{1,3}\.){3}\d{1,3}\b", "[ANONYMIZED_IP]", sanitized)
# Маскування номерів карток
sanitized = re.sub(r"\b\d{4}-\d{4}-\d{4}-\d{4}\b", "[HIDDEN_CARD]", sanitized)

print("Оригінальний лог:
", raw_log)
print("
Безпечний лог для AI:
", sanitized)
```

### Завдання 2. AI-асистована генерація структурованого баг-репорту (Прикладний рівень)

#### Опис завдання:
На основі неструктурованого опису проблеми від клієнта сформулюйте запит до AI для генерації стандартизованого баг-репорту у форматі Jira (Title, Environment, Steps to Reproduce, Expected vs Actual, Severity/Priority).

#### Сирі вхідні дані:
> «У мене на телефоні Xiaomi в мобільному додатку коли натискаю кнопку Купити в кошику, екран стає білим і нічого не відбувається, але гроші з картки не списуються. Це сталося сьогодні вранці при спробі замовити кавоварку.»

#### Промпт для AI:
> «Перетвори цей користувацький відгук у професійний Jira Bug Report за стандартом: 1) Зрозумілий Summary. 2) Severity/Priority з обґрунтуванням. 3) Preconditions та Environment. 4) Покрокові Steps to Reproduce. 5) Actual Result та Expected Result. 6) Додаткові рекомендації для тестувальника, які логи зняти.»
