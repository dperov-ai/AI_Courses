# Практичні завдання до Уроку 71: Пошук першоджерел

## Мета практики
Опанувати інструменти та алгоритми виходу на першоджерела: аналіз репозиторіїв відкритого коду (Commit History / RFCs / Whitepapers), роботу з патентними базами (Google Patents) та реєстрами стандартів (ISO, W3C, IETF RFC).

---

### Завдання 1. Пошук офіційного стандарту протоколу (Базовий рівень)

#### Опис завдання:
Знайдіть оригінальний документ стандарту IETF RFC для протоколу **HTTP/2** та **OAuth 2.0 Authorization Framework**.

#### Інструкція та розв'язок:
1. Пошук у репозиторії RFC Editor (`rfc-editor.org`).
2. Визначити номери документів:
   - OAuth 2.0: **RFC 6749** (The OAuth 2.0 Authorization Framework).
   - HTTP/2: **RFC 7540** (Hypertext Transfer Protocol Version 2), оновлений в **RFC 9113**.
3. Зафіксувати дату публікації, авторів та статус (Standards Track).

---

### Завдання 2. Дослідження репозиторію відкритого коду для з'ясування причин архітектурного рішення (Прикладний рівень)

#### Опис завдання:
За допомогою GitHub знайти перший коміт або pull request, у якому було реалізовано певну ключову зміну у відкритій бібліотеці, та прочитати коментарі розробників.

#### Алгоритм:
1. Використати `git blame` або вкладку Pull Requests у GitHub репозиторії.
2. Прочитати обговорення (Discussion thread) щодо вибору алгоритму або причини відмови від попередньої реалізації.
3. Оформити висновок у вигляді цитати автора для технічного звіту.

---

### Завдання 3. AI-пошук патентних та академічних першоджерел (Робота з AI)

#### Опис завдання:
Сформулюйте запит до AI для знаходження оригінальних патентів або фундаментальних робіт у сфері комп'ютерного зору (наприклад, алгоритм YOLO).

#### Промпт для AI:
> «Знайди першоджерело для сімейства моделей YOLO (You Only Look Once): 1) Точна назва першої наукової статті. 2) Авторський колектив (Joseph Redmon et al.). 3) Рік та конференція публікації (CVPR). 4) Головна інновація, яка відрізняла YOLO від R-CNN.»
