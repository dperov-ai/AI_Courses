# Формулювання research question: методологія наукового та технічного пошуку, критерії FINER, декомпозиція гіпотез та заземлення промптів

Будь-яке глибоке дослідження — чи то аналіз ринку штучного інтелекту, підготовка технічної White Paper, порівняння хмарних архітектур чи академічний огляд — починається не з пошуку в Google і не з написання тексту.

Воно починається з **точного формулювання дослідницького питання (Research Question / RQ)**.

Якщо ви поставите мовній моделі або пошуковій системі розмите, загальне запитання на кшталт: *«Які перспективи штучного інтелекту в медицині?»*, ви гарантовано отримаєте водянисту, банальну та поверхову відповідь із загальновідомих кліше. 

Якщо ж ви сформулюєте точне дослідницьке питання: *«Які порівняльні показники чутливості (Sensitivity) та специфічності (Specificity) демонструють моделі комп'ютерного зору при ранній діагностиці меланоми за даними клінічних випробувань 2023-2025 років порівняно з лікарями-дерматологами вищої категорії?»* — ви отримаєте глибокий, фактологічний та цінний аналітичний зріз.

У цьому поглибленому посібнику ми розглянемо:

* анатомію бездоганного дослідницького питання: від широкої теми до точного фокусу;
* міжнародний науковий фреймворк **FINER** (Feasible, Interesting, Novel, Ethical, Relevant);
* структури декомпозиції запитань: **PICO** (для прикладних досліджень) та **SPIDER** (для якісного аналізу);
* декомпозицію генерального питання на систему суб-питань (Sub-Questions / Hierarchy of Inquiry);
* формулювання перевірюваних науково-технічних гіпотез ($H_0$ vs $H_1$);
* використання AI як інтелектуального спаринг-партнера для звуження та критики теми дослідження.

| 3. ВИЗНАЧЕННЯ ПРОБЛЕМИ (Problem Definition):                              |

## 2. Критерії якості дослідницького питання: Фреймворк FINER

Перед тим як запускати збір матеріалів, пропустіть ваше питання через чек-лист **FINER**:

```
+───────────────────────────────────────────────────────────────────────────+
|                         КРИТЕРІЇ ЯКОСТІ FINER                             |
+──────────────────────────+────────────────────────────────────────────────+
| F - FEASIBLE (Здійсненне)| Чи реально знайти дані, ресурси та час для     |
|                          | відповіді на це питання?                       |
+──────────────────────────+────────────────────────────────────────────────+
| I - INTERESTING (Цікаве) | Чи представляє питання інтерес для інженерної  |
|                          | спільноти та цільової аудиторії звіту?         |
+──────────────────────────+────────────────────────────────────────────────+
| N - NOVEL (Новизна)      | Чи дає воно нові інсайти або узагальнює свіжі  |
|                          | дані, а не повторює підручники 2018 року?      |
+──────────────────────────+────────────────────────────────────────────────+
| E - ETHICAL (Етичне)     | Чи не порушує дослідження конфіденційність,    |
|                          | безпеку даних та авторські права?              |
+──────────────────────────+────────────────────────────────────────────────+
| R - RELEVANT (Релевантне)| Чи допоможе відповідь прийняти конкретне бізнес|
|                          | або технологічне рішення?                      |
+──────────────────────────+────────────────────────────────────────────────+
```

## 3. Фреймворк PICO для прикладних досліджень

Фреймворк **PICO** допомагає розкласти складне питання на 4 вимірювані координати:

* **P (Population / Problem):** Проблема або цільова система (наприклад: *Високонавантажені мікросервіси на Go*).
* **I (Intervention):** Досліджувана технологія / підхід (наприклад: *Впровадження gRPC та Protocol Buffers*).
* **C (Comparison):** Альтернатива для порівняння (наприклад: *Класичний REST API на базі JSON over HTTP/2*).
* **O (Outcome):** Вимірюваний результат (наприклад: *Зниження затримок latency на 99-му процентилі та споживання CPU*).

## 4. Промпт для валідації та звуження теми за допомогою AI

```markdown
Ти — провідний науковий консультант та Senior Technical Writer.
Я планую провести дослідження на тему: "[Вставте початкову сиру тему]".

ТВОЯ ЗАДАЧА:
1. Проаналізуй цю тему на наявність розмитості, банальності та відсутності фокусу.
2. Запропонуй 3 варіанти строгого, глибокого та сфокусованого Research Question за стандартом FINER / PICO.
3. Для кожного варіанта сформулюй:
   - Основне дослідницьке питання.
   - 3 підпорядковані суб-питання (Sub-Questions).
   - Головну нульову ($H_0$) та альтернативну ($H_1$) гіпотези.
   - Перелік ключових метрик або емпіричних даних, які потрібні для доказу.
```

## Резюме уроку

1. Якість дослідження **на 80% визначається якістю початкового Research Question**.
2. Уникайте загальних тем: звужуйте фокус від широкої області до **конкретної проблеми, технології та вимірюваного результату**.
3. Використовуйте наукові фреймворки **FINER** (для оцінки якості) та **PICO** (для порівняльного аналізу).
4. Залучайте AI для **критики теми, декомпозиції на суб-питання та формулювання гіпотез**.
