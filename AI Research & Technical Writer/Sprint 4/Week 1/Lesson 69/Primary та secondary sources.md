# Primary та secondary sources: первинні vs вторинні джерела, аналіз походження інформації та боротьба з «зіпсованим телефоном»

У сучасному інтернеті існує колосальна проблема: **каскадне переписування інформації (The Copy-Paste Echo Chamber)**.

Одна новинна агенція публікує гучний заголовок: *«Штучний інтелект навчився читати думки людини з точністю 95%»*. Десятки блогів роблять рерайт цієї новини, додаючи ще більше емоційного клікбейту. Сотні користувачів цитують блоги в соцмережах. Якщо дослідник довіряє цим вторинним і третинним джерелам, він створює псевдонауковий звіт, заснований на міфах.

Коли ж професійний Technical Writer знаходить **первинне наукове джерело (Primary Source)** — оригінальну рецензовану статтю вчених з нейровізуалізації — він виявляє: точність 95% стосувалася розпізнавання лише 2 простих літер на екрані за умов використання громіздкого медичного МРТ-сканера вартістю $3,000,000 на вибірці з 3 пацієнтів.

**Розуміння різниці між первинними (Primary), вторинними (Secondary) та третинними (Tertiary) джерелами** — це головна роздільна лінія між аматором і професійним дослідником.

У цьому поглибленому посібнику ми розглянемо:

* класифікацію джерел: Первинні (Primary), Вторинні (Secondary) та Третинні (Tertiary);
* феномен «зіпсованого телефону» в медіа та спотворення вихідних даних;
* методологію розкопування першоджерела за слідами посилань (Backward Source Tracing);
* коли цитування вторинних джерел (мета-аналізів та систематичних оглядів) є виправданим;
* використання штучного інтелекту для виявлення спотворень та перевірки фактів за оригінальним текстом.

## 1. Три рівні походження інформації

```
+───────────────────────────────────────────────────────────────────────────+
|                        ТРИ РІВНІ ДЖЕРЕЛ ІНФОРМАЦІЇ                        |
+──────────────────────────+──────────────────────────+─────────────────────+
| ТИП ДЖЕРЕЛА              | ЩО ЦЕ ТАКЕ               | ПРИКЛАДИ            |
+──────────────────────────+──────────────────────────+─────────────────────+
| 1. ПЕРВИННІ ДЖЕРЕЛА      | Сирі дані, оригінальні   | - Наукова стаття на |
| (Primary Sources)        | експерименти, вихідний   |   arXiv / Nature.   |
|                          | код, офіційні закони,    | - Офіційний реліз   |
|                          | стенограми, фінансові    |   API вендора.      |
|                          | звіти компаній (10-K).   | - Текст закону.     |
+──────────────────────────+──────────────────────────+─────────────────────+
| 2. ВТОРИННІ ДЖЕРЕЛА      | Аналіз, інтерпретація,   | - Галузевий звіт    |
| (Secondary Sources)      | синтез, критика або      |   Gartner / IDC.    |
|                          | систематичний огляд      | - Оглядова стаття   |
|                          | первинних матеріалів.    |   (Meta-analysis).  |
|                          |                          | - Технічна книга.   |
+──────────────────────────+──────────────────────────+─────────────────────+
| 3. ТРЕТИННІ ДЖЕРЕЛА      | Агрегатори та стислі     | - Статті Вікіпедії. |
| (Tertiary Sources)       | компендіуми знань.       | - Словники, енцик-  |
|                          |                          |   лопедії, довідники|
+──────────────────────────+──────────────────────────+─────────────────────+
```

## 2. Анатомія спотворення інформації: Як народжуються міфи

```
  [ 1. ПЕРВИННЕ ДЖЕРЕЛО (Original Paper) ]:
  "У 12% пацієнтів спостерігалося тимчасове почервоніння шкіри при дозі 500 мг"
                         │
                         ▼ (Рерайт у популярному медичному блозі)
  [ 2. ВТОРИННЕ ДЖЕРЕЛО (Tech Blog) ]:
  "Нові ліки викликають алергічні реакції у значної частини тестованих"
                         │
                         ▼ (Клікбейтний репост у Twitter / Telegram)
  [ 3. ТРЕТИННЕ ДЖЕРЕЛО (Social Media) ]:
  "УВАГА! Новий препарат визнано токсичним та небезпечним для життя!"
```

> **Золотий закон ресьорчера:**  
> Якщо твердження містить сенсаційну цифру, відсоток чи звинувачення — **заборонено посилатися на блог чи новинний сайт**. Ви зобов'язані дійти до оригінального PDF-звіту чи наукової статті!

## 3. Методика зворотного пошуку першоджерела (Source Tracing)

```
[ Стаття в блозі стверджує факт X ]
                  │
                  ▼ (Крок 1: Знайти гіперпосилання в тексті)
[ Посилання веде на новинний сайт TechCrunch ]
                  │
                  ▼ (Крок 2: Знайти, на що посилається TechCrunch)
[ Посилання на прес-реліз компанії OpenAI ]
                  │
                  ▼ (Крок 3: Знайти посилання на технічний звіт)
[ ОРИГІНАЛЬНИЙ TECHNICAL REPORT НА ARXIV.ORG ] ──► ФАКТ ПІДТВЕРДЖЕНО АБО СПРОСТОВАНО!
```

## 4. Промпт для виявлення розбіжностей між першоджерелом та статтею

```markdown
Ти — провідний фактчекер та аналітик першоджерел.
Я завантажив два тексти:
1. ОРИГІНАЛЬНА НАУКОВА СТАТТЯ (Primary Source).
2. СТАТТЯ У ЗМІ (Secondary Source), яка описує це дослідження.

ТВОЯ ЗАДАЧА:
1. Знайди всі фактичні розбіжності та перебільшення, яких припустилися журналісти.
2. Склади таблицю звірки:
   | Твердження зі ЗМІ | Що НАСПРАВДІ написано в першоджерелі | Ступінь спотворення (Низький / Критичний / Маніпуляція) |
3. Зроби експертний висновок: чи можна довіряти статті зі ЗМІ як джерелу.
```

## Резюме уроку

1. **Первинні джерела** містять оригінальні дані без сторонніх спотворень; **вторинні** — дають узагальнений контекст; **третинні** — слугують відправною точкою.
2. Ніколи не посилайтеся на новини чи соцмережі при цитуванні наукових, юридичних чи фінансових фактів.
3. Застосовуйте **методику зворотного пошуку (Source Tracing)** до тих пір, поки не дійдете до оригінального документа.
4. Використовуйте AI для **автоматичного зіставлення журналістських заяв із реальними даними технічних звітів**.
