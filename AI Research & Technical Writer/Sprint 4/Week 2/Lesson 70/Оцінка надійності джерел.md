# Оцінка надійності джерел: тест CRAAP, індекс Хірша (h-index), рецензування (Peer-Review) та виявлення хижацьких журналів

В епоху інформаційного шуму та масової генерації контенту штучним інтелектом знайти інформацію стало занадто просто. Справжнє мистецтво полягає в тому, щоб **відсіяти недостовірні, упереджені, замовні та псевдонаукові матеріали**.

Якщо технічний письменник чи аналітик включить у звіт дані зі статті, опублікованої у так званому «хижацькому журналі» (Predatory Journal) або спонсорованої зацікавленою корпорацією без розкриття конфлікту інтересів — увесь авторитет дослідження, компанії та автора буде зруйновано.

**Оцінка надійності джерел (Source Credibility Assessment)** — це системна наукова методологія критичного аудиту авторів, видавництв, фінансування, методології досліджень та академічних метрик цитування.

У цьому поглибленому посібнику ми розглянемо:

* класичний науковий тест **CRAAP** (Currency, Relevance, Authority, Accuracy, Purpose);
* академічні метрики авторитетності: Імпакт-фактор журналу (Impact Factor), Квартилі (Q1-Q4 за Scopus/Web of Science) та індекс Хірша вченого ($h$-index);
* інститут рецензування: Односліпе (Single-Blind), Двосліпе (Double-Blind) та Відкрите рецензування (Open Peer-Review);
* феномен «хижацьких журналів» (Predatory Publishers / Beall's List) та купівлі наукових публікацій;
* виявлення конфлікту інтересів (Conflicts of Interest) та прихованого корпоративного лобізму;
* автоматизований аудит джерел за допомогою AI.

## 1. Науковий тест CRAAP: Золотий стандарт перевірки джерел

```
+───────────────────────────────────────────────────────────────────────────+
|                             МАТРИЦЯ ТЕСТУ CRAAP                           |
+──────────────────────────+────────────────────────────────────────────────+
| C - CURRENCY (Актуальн.) | Коли була опублікована інформація? Чи не заста-|
|                          | ріли ці дані для динамічної IT-галузі?         |
+──────────────────────────+────────────────────────────────────────────────+
| R - RELEVANCE (Релевант.)| Наскільки глибоко матеріал відповідає темі?    |
|                          | Чи це поверхневий огляд для широкої публіки?   |
+──────────────────────────+────────────────────────────────────────────────+
| A - AUTHORITY (Авторитет)| Хто автор? Яка його академічна чи інженерна    |
|                          | афіліація? Чи є цитування у фаховій спільноті? |
+──────────────────────────+────────────────────────────────────────────────+
| A - ACCURACY (Точність)  | Чи підтверджені заяви посиланнями на сирі дані?|
|                          | Чи пройшла стаття рецензування (Peer-Review)?  |
+──────────────────────────+────────────────────────────────────────────────+
| P - PURPOSE (Мета)       | Яка мета публікації: безкорисливий науковий    |
|                          | пошук чи продаж продукту, реклама чи пропаганда|
+──────────────────────────+────────────────────────────────────────────────+
```

## 2. Академічні метрики: Як розрізнити провідного вченого від аматора

```
+───────────────────────────────────────────────────────────────────────────+
|                         СИСТЕМА НАУКОВИХ МЕТРИК                           |
+──────────────────────────+────────────────────────────────────────────────+
| 1. ІНДЕКС ХІРША (h-index)| Вчений має індекс h, якщо h його статей        |
|                          | процитовані не менше h разів кожна.            |
|                          | • h > 20: зрілий авторитетний дослідник.       |
|                          | • h > 40: світовий лідер галузі.               |
+──────────────────────────+────────────────────────────────────────────────+
| 2. КВАРТИЛІ ЖУРНАЛІВ     | Рейтинг журналів за базою Scopus / Web of Sci: |
| (Q1, Q2, Q3, Q4)         | • Q1 (Топ 25%): Найвищий авторитет (Nature).   |
|                          | • Q4 (Нижні 25%): Слабкі видання.              |
+──────────────────────────+────────────────────────────────────────────────+
| 3. ПЕРЕВІРКА ЗА BEALL'S  | Список видавництв, які публікують будь-які     |
| LIST                     | статті за гроші без реального рецензування.    |
+──────────────────────────+────────────────────────────────────────────────+
```

## 3. Інститут рецензування (Peer-Review Process)

Чому рецензована стаття у 100 разів надійніша за пост у блозі?

```
[ Автор пише статтю ]
          │
          ▼
[ Відправка до журналу Q1 ]
          │
          ▼ (Редактор відправляє 3 незалежним анонімним експертам)
[ 3 СЛІПІ РЕЦЕНЗЕНТИ (Peer Reviewers) ]:
- Перевіряють математичні розрахунки.
- Шукають методологічні помилки та маніпуляції вибіркою.
- Вимагають повторення експериментів.
          │
          ├── ВІДХИЛЕНО (Reject): 80% статей відсіюються як неякісні!
          └── СХВАЛЕНО (Accept) ──► ПУБЛІКАЦІЯ У НАУКОВОМУ ЖУРНАЛІ (100% Довіра)
```

## 4. Промпт для AI-аудиту надійності джерела за тестом CRAAP

```markdown
Ти — провідний експерт із наукометрії та верифікації фактів.
Проаналізуй надану статтю та її метадані (автори, видання, спонсори).

Проведи аудит за 5 критеріями тесту CRAAP:
1. CURRENCY: Оціни актуальність даних (чи не застаріли порівняння технологій?).
2. AUTHORITY: Перевір авторитетність авторів та видання (чи це рецензований журнал Q1/Q2, препринт чи маркетинговий блог?).
3. ACCURACY: Чи наведені посилання на репозиторії коду, датасети та похибки вимірювань?
4. PURPOSE & BIAS: Чи є ознаки конфлікту інтересів (наприклад, стаття порівнює бази даних, але проспонсорована вендором однієї з них)?
5. ФІНАЛЬНИЙ СКОРИНГ: Постав оцінку надійності від 1 до 100 з вердиктом: «Рекомендовано як надійне джерело» / «Потребує перехресної верифікації» / «Недостовірне».
```

## Резюме уроку

1. Тест **CRAAP** — універсальний інструмент оцінки актуальності, авторитетності та неупередженості інформації.
2. Орієнтуйтеся на **рецензовані видання вищих квартилів (Q1/Q2) та перевіряйте h-index авторів**.
3. Остерігайтеся **«хижацьких журналів»** та завжди перевіряйте наявність комерційного конфлікту інтересів.
4. Використовуйте AI для **швидкого аналізу методології та виявлення прихованої упередженості авторів**.
