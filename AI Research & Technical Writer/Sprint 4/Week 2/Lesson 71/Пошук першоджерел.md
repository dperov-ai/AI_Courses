# Пошук першоджерел: розкопування цитат, патентні бази, реєстри регуляторів та робота з DOI

Справжня аналітична робота часто нагадує детективне розслідування.

Коли в інтернеті з'являється твердження: *«Згідно з новим законом ЄС, використання AI для найму співробітників заборонено»*, некваліфікований автор просто перекаже цей рядок своїми словами. Професійний Technical Writer знайде **офіційний реєстр Європейського Союзу, відкриє повний текст EU AI Act (Регламент 2024/1689), знайде статтю 6 та Додаток III і прочитає першоджерело**.

Виявиться: системи AI для найму не заборонені, а класифіковані як «системи високого ризику» (High-Risk AI Systems), що вимагають обов'язкового аудиту даних, захисту від упередженості та реєстрації в базі даних ЄС.

**Пошук першоджерел (Primary Source Mining)** — це навичка швидкого виходу на фундаментальні офіційні артефакти: закони, патенти, фінансові звіти біржових регуляторів (SEC), вихідні репозиторії та наукові ідентифікатори **DOI**.

У цьому поглибленому посібнику ми розглянемо:

* роботу з цифровими ідентифікаторами об'єктів (**DOI — Digital Object Identifier**) та сервісами CrossRef;
* картографію патентних баз даних: Google Patents, USPTO (США), EPO Espacenet (Європа), WIPO;
* офіційні державні та біржові реєстри: SEC EDGAR (звіти 10-K / 10-Q для публічних компаній), EUR-Lex (законодавство ЄС);
* розкопування технічних стандартів: ISO, IEEE, IETF RFC (стандарти інтернет-протоколів), W3C;
* методику верифікації вихідного коду (Source Code Provenance) через Git-історію та репозиторії.

---

## 1. Цифрові ідентифікатори DOI та розкопування статей

**DOI (Digital Object Identifier)** — це постійний унікальний цифровий паспорт наукової статті чи звіту, який ніколи не змінюється, навіть якщо сайт видавництва переїхав:

```
  СТРУКТУРА DOI:
  
  https://doi.org/10.1145/3318464.3389700
  │                │       │
  ▼                ▼       ▼
[ Префікс doi ] [ Префікс] [ Суфікс статті ]
                [ видавця] (Унікальний ID статті в системі)
```

### Як знайти першоджерело за 3 секунди:
Якщо ви маєте рядок DOI `10.1038/s41586-023-06291-2`, просто додайте `https://doi.org/` попереду — браузер миттєво перенаправить вас на офіційну сторінку оригінальної публікації в журналі *Nature*.

---

## 2. Картографія патентних баз даних (Patent Mining)

Патенти містять найбільш детальний технічний опис алгоритмів та архітектур, який компанії часто не публікують у звичайних статтях:

```
+───────────────────────────────────────────────────────────────────────────+
|                         ГОЛОВНІ ПАТЕНТНІ БАЗИ ДАНИХ                       |
+──────────────────────────+────────────────────────────────────────────────+
| 1. GOOGLE PATENTS        | Зручний світовий пошуковик по патентах США,    |
| (patents.google.com)     | Китаю, Європи, Японії з машинним перекладом.   |
+──────────────────────────+────────────────────────────────────────────────+
| 2. USPTO                 | Офіційне патентне відомство США (першоджерело  |
| (uspto.gov)              | для технологічних гігантів Apple, Google, Meta)|
+──────────────────────────+────────────────────────────────────────────────+
| 3. WIPO PATENTSCOPE      | Міжнародна організація інтелектуальної         |
| (patentscope.wipo.int)   | власності (глобальні заявки за договором PCT). |
+──────────────────────────+────────────────────────────────────────────────+
```

## 3. Фінансові та корпоративні першоджерела: База SEC EDGAR

Якщо ви пишете аналітику про бізнес публічної IT-компанії (Microsoft, Nvidia, Amazon), **єдиним юридично достовірним першоджерелом є звіти біржової комісії США (SEC)**:

* **Form 10-K:** Річний офіційний аудійований звіт (реальний виторг, витрати на сервери, судові ризики).
* **Form 10-Q:** Квартальний фінансовий звіт.
* **Form 8-K:** Екстрене сповіщення про форс-мажорні події або зміну CEO.

> *Пошук:* База **sec.gov/edgar** доступна абсолютно безкоштовно для будь-якого дослідника у світі.

## 4. Промпт для вилучення фактів із регуляторного першоджерела

```markdown
Ти — провідний юридичний аналітик та Technical Writer.
Я завантажив офіційний текст регуляторного акту (PDF-документ з офіційного реєстру EUR-Lex / SEC).

ТВОЯ ЗАДАЧА:
1. Знайди точні статті та параграфи, які регулюють питання: "[Вставте тему запиту]".
2. Процитуй оригінальний текст норми дослівно мовою оригіналу в лапках [«...»] із зазначенням номера статті та сторінки.
3. Надай точний переклад та роз'яснення простими словами: що це вимагає від інженерів на практиці.
4. Вкажи перелік винятків із цього правила.
```

---

## Резюме уроку

1. Справжній аналіз базується на **офіційних реєстрах, текстах законів, патентах та стандартах**.
2. **DOI (doi.org)** — найнадійніший інструмент прямої навігації до наукових першоджерел.
3. Використовуйте **Google Patents** для аналізу технічних алгоритмів корпорацій та **SEC EDGAR** для перевірки фінансових показників.
4. Завжди цитуйте **точний номер статті закону, патентний номер або пункт технічного регламенту (RFC)**.
