# Функції та параметри: декомпозиція складності, чисті функції, замикання, рекурсія та Scope

Програмування монолітним кодом на тисячі рядків безперервного тексту — найшвидший спосіб створити непідтримуваний, неможливий для тестування і крихкий хаос.

Головним будівельним блоком будь-якої архітектури є **функція** — іменований ізольований фрагмент коду, призначений для виконання однієї конкретної задачі. Функції реалізують фундаментальний інженерний принцип **DRY (Don't Repeat Yourself)**, дозволяють декомпозувати складну систему на прості незалежні модулі, повторно використовувати логіку та проводити модульне тестування (Unit Testing).

У цьому поглибленому посібнику ми розберемо:

* анатомію функції: оголошення, сигнатура, аргументи vs параметри, значення повернення (`return`);
* типи параметрів: позиційні, іменовані (Keyword), значення за замовчуванням (Default Args) та змінні списки аргументів (`*args`, `**kwargs`);
* області видимості змінних (Variable Scope: Local, Enclosing, Global, Built-in — правило LEGB);
* парадигму функціонального програмування: Чисті функції (Pure Functions), відсутність Side Effects та ідемпотентність;
* функції першого класу (First-Class Citizens), анонімні лямбда-функції та замикання (Closures);
* рекурсію: базовий випадок, глибина викликів, Call Stack та хвостова рекурсія (Tail Call Optimization).

## 1. Анатомія функції та передача параметрів

```
             СИГНАТУРА ФУНКЦІЇ (FUNCTION SIGNATURE)
  ┌─────────────────────────────────────────────────────────────┐
  │ def calculate_tax(amount: float, rate: float = 0.2) -> float:│
  └───────┬───────────────┬──────────────────┬──────────────┬───┘
          │               │                  │              │
          ▼               ▼                  ▼              ▼
     [ Назва ]     [ Позиційний ]      [ Значення за ] [ Тип результату]
                   [ параметр   ]      [ замовчуванням]
```

### Пастка змінних значень за замовчуванням у Python (Mutable Default Arg):
Один із найпопулярніших багів у згенерованому AI коді:
```python
# ГРУБА ПОМИЛКА:
def add_item_bad(item, cart=[]): # Створюється ОДИН спільний список на всі виклики!
    cart.append(item)
    return cart

print(add_item_bad("яблуко")) # ['яблуко']
print(add_item_bad("банан"))  # ['яблуко', 'банан'] -> Банан додався до чужого кошика!

# ПРАВИЛЬНИЙ ПАТЕРН:
def add_item_good(item, cart=None):
    if cart is None:
        cart = []
    cart.append(item)
    return cart
```

## 2. Області видимості змінних (Scope): Правило LEGB

Коли інтерпретатор шукає змінну за назвою, він рухається від внутрішнього шару до зовнішнього:

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. LOCAL (L)     : Всередині поточної функції               │
  │   ▲                                                         │
  │ 2. ENCLOSING (E) : У зовнішній функції (для замикань)       │
  │   ▲                                                         │
  │ 3. GLOBAL (G)    : На рівні поточного файлу модуля          │
  │   ▲                                                         │
  │ 4. BUILT-IN (B)  : Вбудовані імена (`len`, `range`, `print`) │
  └─────────────────────────────────────────────────────────────┘
```

## 3. Чисті функції (Pure Functions) vs Побічні ефекти (Side Effects)

```
+───────────────────────────────────────────────────────────────────────────+
|                        ЧИСТА ФУНКЦІЯ (PURE FUNCTION)                      |
+───────────────────────────────────────────────────────────────────────────+
| 1. ДЕТЕРМІНОВАНІСТЬ: Для однакових аргументів ЗАВЖДИ повертає однаковий   |
|    результат (`add(2, 2)` завжди = `4`).                                  |
|                                                                           |
| 2. ВІДСУТНІСТЬ ПОБІЧНИХ ЕФЕКТІВ (No Side Effects): Не змінює глобальні   |
|    змінні, не пише у файл, не відправляє мережеві запити, не мутує вхідні|
|    аргументи.                                                             |
|                                                                           |
| Чому це золото для AI-розробника?                                         |
| Чисті функції ідеально тестуються юніт-тестами, легко кешуються           |
| (мемоізація) та безпечно запускаються у паралельних потоках.              |
+───────────────────────────────────────────────────────────────────────────+
```

## 4. Замикання (Closures) та фабрики функцій

Замикання — це функція, яка запам'ятовує змінні зі свого лексичного оточення (Enclosing Scope) навіть після того, як зовнішня функція завершила роботу:

```python
def make_discount_calculator(discount_rate):
    # Змінна discount_rate "замикається" всередині вкладеної функції
    def calculate(price):
        return price * (1 - discount_rate)
    return calculate

black_friday = make_discount_calculator(0.3) # 30% знижка
vip_client   = make_discount_calculator(0.1) # 10% знижка

print(black_friday(1000)) # 700.0
print(vip_client(1000))   # 900.0
```

## 5. Рекурсія та Call Stack

**Рекурсія** — це коли функція викликає саму себе для розв'язання підзадачі меншого розміру.

```
                  СТЕК ВИКЛИКІВ ДЛЯ ФАКТОРІАЛА `factorial(3)`
                  
  [ factorial(1) -> повертає 1 ]  ▲
  [ factorial(2) -> 2 * fact(1) ] │ Згортання стека (Повернення результатів)
  [ factorial(3) -> 3 * fact(2) ] │
```

> **Обов'язкове правило рекурсії:**  
> Кожна рекурсивна функція повинна мати **Базовий випадок (Base Case)** для виходу. Без нього виникає аварійне переповнення стека (`RecursionError: maximum recursion depth exceeded`).

## Резюме уроку

1. Функція — це фундаментальна одиниця декомпозиції, яка ізолює складність та слідує принципу **Single Responsibility**.
2. Уникайте мутабельних значень за замовчуванням (`arg=[]`); використовуйте ідіому **`arg=None`**.
3. Прагніть писати **чисті функції (Pure Functions)** без побічних ефектів для надійності та легкості тестування.
4. Будь-яка рекурсія вимагає **базового випадку** зупинки для запобігання переповненню стека викликів.
