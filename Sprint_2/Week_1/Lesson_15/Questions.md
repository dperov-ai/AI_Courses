# Контрольні питання: AI для роботи з кодом — Cursor, Claude, GitHub Copilot

1. Що означає поняття **AI для роботи з кодом**?

2. Які типові задачі програміста можуть виконувати або спрощувати AI-інструменти?

3. Чому AI для програмування — це вже не просто автодоповнення кількох рядків коду?

4. У чому полягає основна ідея **Cursor** як інструмента для програмування?

5. Чим робота з AI всередині Cursor відрізняється від звичайного копіювання коду в окремий чат?

6. Які задачі зручно виконувати в Cursor, коли потрібно працювати одразу з кількома файлами проєкту?

7. Як **Claude** можна використовувати не лише для генерації коду, а й для аналізу технічних задач?

8. Чому іноді корисно попросити Claude спочатку запропонувати план змін, а не одразу писати код?

9. У чому полягає роль **GitHub Copilot** під час повсякденного написання коду?

10. Чому GitHub Copilot не варто сприймати лише як інструмент автодоповнення?

11. У чому практична різниця між Cursor, Claude та GitHub Copilot?

12. Чому не варто жорстко запам'ятовувати правило на кшталт «Cursor — тільки для одного, Claude — для другого, Copilot — для третього»?

13. Чому контекст особливо важливий, коли AI працює з кодом?

14. Чим запит «Виправ помилку» гірший за детальний Prompt із описом проблеми, очікуваної поведінки та обмежень?

15. Чому корисно просити AI робити **мінімально необхідні зміни**, а не переписувати великі частини проєкту?

16. Чому код, згенерований AI, може виглядати правильним і водночас містити помилки?

17. Чому факт того, що програма запускається без помилок, ще не означає, що AI правильно виконав задачу?

18. Які ризики можуть виникнути, якщо приймати AI-generated code без перевірки?

19. Як AI може допомогти новому співробітнику швидше зрозуміти незнайомий кодовий проєкт?

20. Як використовувати AI для навчання програмуванню так, щоб не перетворити його на інструмент простого копіювання готових рішень?

21. Чому тести, які згенерував AI, також потрібно перевіряти людиною?

22. Які правила конфіденційності та безпеки потрібно враховувати перед передачею робочого коду в AI-сервіс?

23. Що таке **AI Agent** у контексті програмування і чим він відрізняється від звичайної AI-підказки?

24. Який принцип найкраще описує ефективну роботу з coding AI: що потрібно зробити людині до, під час і після того, як AI запропонував рішення?
