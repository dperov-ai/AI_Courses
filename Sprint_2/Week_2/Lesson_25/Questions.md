2. Які існують основні формати структурування виводу для людей (Human-Readable) і для машин (Machine-Readable)?

3. У яких аналітичних задачах використання Markdown-таблиць є найбільш ефективним способом подачі інформації?

4. Чому популярний формат JSON є стандартом для обміну даними між AI та бекенд-системами (CRM, бази даних)?

8. Що таке механізм **Structured Outputs (Constrained Decoding)** у сучасних API (OpenAI, Anthropic, Gemini)?

9. У чому полягає перевага використання **XML-подібних тегів** (наприклад, `<thought>`, `<data>`) у відповідях?

14. Складіть комбінований промпт із використанням XML-тегів для аналізу фінансового звіту, де є блок міркувань `<analysis>` та блок JSON `<metrics>`.
