# Запитання для перевірки знань: контекст та його важливість

1. Що таке **контекст** у роботі з AI?

2. Чому запит «Напиши відповідь клієнту» часто дає слабкий або занадто загальний результат?

3. Яку інформацію варто додати до prompt, щоб AI краще зрозумів ситуацію?

4. Чому важливо вказувати, для якої аудиторії створюється відповідь?

5. Як мета задачі впливає на те, яку інформацію AI вважатиме найважливішою?

6. Чому контекст про попередні події може бути важливим у листуванні або роботі з клієнтами?

7. У чому різниця між **корисним** і **зайвим** контекстом?

8. Чому надто великий обсяг нерелевантної інформації може погіршити результат?

9. Як документи, таблиці, листи або transcript можуть ставати частиною контексту для AI?

10. Що таке **Context Window** і чому важливо пам'ятати, що контекст у довгій розмові не є безмежним?

11. Чому критично важливі вимоги краще повторювати безпосередньо перед виконанням важливої задачі?

12. Як недостатній контекст може збільшувати ризик **Hallucination**?

13. Що варто попросити AI зробити, якщо в наданих даних недостатньо інформації для точної відповіді?

14. Чому корисно просити AI відокремлювати підтверджені факти від припущень або гіпотез?

15. Як потрібно діяти, якщо в різних документах міститься суперечлива інформація?

16. Чому не варто передавати AI зайві конфіденційні дані, паролі, API keys або персональну інформацію лише заради більшого контексту?

17. Покращіть prompt **«Проаналізуй цей звіт»**, додавши контекст про ситуацію, мету, аудиторію, вихідні дані та обмеження.

18. Уявіть, що клієнт незадоволений затримкою проєкту. Складіть prompt для AI за структурою: **ситуація + мета + аудиторія + важливі факти + обмеження + задача**.
