# Практичні завдання до Уроку 175: JSON

## Завдання 1: Створення та компіляція валідаційної схеми JSON Schema для DTO

**Мета:** Опанувати написання JSON Schema специфікації та валідацію вхідних даних.

**Вхідний контекст та бізнес-сценарій:**
Розробіть JSON Schema для реєстрації нового інженера в AI платформі. Об'єкт містить ім'я, email, рівень досвіду (enum), масив технологій та об'єкт налаштувань сповіщень.

**Покроковий алгоритм виконання:**
1. Опишіть схему за стандартом Draft 2020-12 із зазначенням обов'язкових полів.
2. Додайте регулярний вираз для валідації формату корпоративної пошти та обмеження довжини імені.
3. Складіть два зразки payload: один повністю валідний, другий — із 3 різними помилками валідації.

**Рекомендований системний AI-промпт:**
```text
Створи детальну JSON Schema специфікацію за стандартом Draft 2020-12 для реєстрації користувача. Включи перевірку полів email, password (довжина 8-64), role (ADMIN, DEV, QA) та preferences (вкладений об'єкт). Надай приклади валідного та невалідного JSON.
```

**Очікуваний результат:**
Валідний JSON Schema файл та два приклади корисного навантаження з поясненням помилок.

**Критерії самоперевірки та оцінювання:**
- [ ] Коректний синтаксис JSON Schema Draft 2020-12
- [ ] Наявність обмежень 'additionalProperties: false'
- [ ] Чітко виділені обов'язкові та опціональні поля

## Завдання 2: Аналіз та трансформація складних JSON даних через утиліту jq

**Мета:** Навчитися маніпулювати складними масивами та вкладеними структурами JSON у командному рядку.

**Вхідний контекст та бізнес-сценарій:**
Вам надано експорт 100 замовлень користувачів у вигляді великого JSON файлу. Необхідно за допомогою фільтрів відібрати лише активні замовлення з сумою понад $500.

**Покроковий алгоритм виконання:**
1. Сформуйте команду jq для фільтрації масиву об'єктів за полем `status == 'COMPLETED'`.
2. Використовуючи пайплайни jq, відсортуйте результат за датою та залиште лише поля id, customerEmail та totalAmount.
3. Збережіть трансформований результат у новий мінімізований JSON файл.

**Рекомендований системний AI-промпт:**
```text
Склади покроковий туторіал з використання утиліти jq для фільтрації складного JSON масиву замовлень. Наведи 3 практичні команди: фільтрація за умовою, витягування унікальних категорій та підрахунок загальної суми.
```

**Очікуваний результат:**
Практичний посібник із готовими командами jq та зразками вхідних/вихідних JSON структур.

**Критерії самоперевірки та оцінювання:**
- [ ] Синтаксично валідні вирази jq
- [ ] Правильне використання фільтрів select, map та group_by
- [ ] Описано практичну користь для бекенд-інженера
