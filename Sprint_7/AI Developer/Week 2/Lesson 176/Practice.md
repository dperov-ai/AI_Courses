# Практичні завдання до Уроку 176: Створення та використання API

Практичний блок розроблено для закріплення навичок роботи з AI-інструментами, аналізу реальних виробничих кейсів та створення професійних артефактів.

## Завдання 1: Створення REST API сервісу на базі Express/FastAPI

**Мета:** Розробити повноцінний CRUD API сервіс із валідацією, обробкою помилок та налаштуванням CORS.

**Вхідний контекст та бізнес-сценарій:**
Створіть API для керування навчальними завданнями (Tasks). Сервіс повинен підтримувати створення завдання, отримання списку з фільтром за статусом та видалення.

**Покроковий алгоритм виконання:**
1. Ініціалізуйте проект та налаштуйте парсер JSON та безпечні заголовки CORS.
2. Реалізуйте ендпоінти GET /api/v1/tasks, POST /api/v1/tasks та DELETE /api/v1/tasks/:id.
3. Додайте валідацію обов'язкових полів (назва завдання, дедлайн) із поверненням 422 статусу при помилках.

**Рекомендований системний AI-промпт:**
```text
Напиши виробничий код REST API на Node.js/Express (або Python/FastAPI) для системи задач. Реалізуй CRUD ендпоінти, валідацію вхідних даних, налаштування CORS та повернення статусів 200, 201, 204, 404, 422.
```

**Очікуваний результат:**
Повний працездатний вихідний код API контролера з обробниками помилок.

**Критерії самоперевірки та оцінювання:**
- [ ] Коректне використання HTTP-статусів
- [ ] Наявність перевірки обов'язкових полів
- [ ] Правильне налаштування middleware для CORS

## Завдання 2: Інтеграція клієнтського HTTP-модуля з перехоплювачами токенів

**Мета:** Налаштувати надійний клієнтський сервіс взаємодії з API на базі Axios або Fetch з автоматичним додаванням токенів.

**Вхідний контекст та бізнес-сценарій:**
Створіть ізольований клієнтський модуль, який автоматично підставляє Bearer токен у заголовки та обробляє помилки 401 через перенаправлення на сторінку логіну.

**Покроковий алгоритм виконання:**
1. Створіть екземпляр Axios зі встановленим базовим baseURL та тайм-аутом.
2. Налаштуйте request interceptor для додавання токена з localStorage або пам'яті.
3. Налаштуйте response interceptor для глобального логування помилок 5xx та обробки 401.

**Рекомендований системний AI-промпт:**
```text
Створи модуль apiClient на TypeScript з використанням Axios. Додай request interceptor для підстановки Bearer токена та response interceptor для перехоплення 401/403/500 помилок з механізмом повторної спроби (Retry).
```

**Очікуваний результат:**
Готовий до використання клієнтський файл apiClient.ts з перехоплювачами.

**Критерії самоперевірки та оцінювання:**
- [ ] Типізація за допомогою TypeScript
- [ ] Коректна робота з заголовком Authorization
- [ ] Безпечна обробка помилок мережі
