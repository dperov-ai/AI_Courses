# Контрольні запитання до Уроку 180: Основи HTTP, REST та API для AI QA Operator

Даний блок містить перелік запитань для самоконтролю, перевірки глибини засвоєння матеріалу та самостійної підготовки.

1. Чому тестування API вважається більш ефективним та надійним, ніж тестування виключно через UI?

7. Як тестувальник перевіряє ідемпотентність методу DELETE?
