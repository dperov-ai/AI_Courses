# Практичні завдання до Уроку 184: Генерація запитів і перевірок

Практичний блок розроблено для закріплення навичок роботи з AI-інструментами, аналізу реальних виробничих кейсів та створення професійних артефактів.

---

## Завдання 1: Генерація повного тестового сьюту для ендпоінта авторизації через AI

**Мета:** Опанувати написання технічного промпту для автоматичної генерації перевірок у Postman.

**Вхідний контекст та бізнес-сценарій:**
Спроектуйте та згенеруйте набір тестів для ендпоінта входу POST /api/v1/auth/login.

**Покроковий алгоритм виконання:**
1. Складіть детальний інженерний промпт із зазначенням схеми вхідних та вихідних даних.
2. Згенеруйте 4 обов'язкові тести (статус 200, наявність токена, перевірка часу відгуку, відсутність пароля у відповіді).
3. Додайте збереження отриманого токена у змінну середовища `authToken`.

**Рекомендований системний AI-промпт:**
```text
Склади набір тестів Chai.js для вкладки 'Tests' у Postman для ендпоінта POST /auth/login. Перевір статус 200, час відгуку < 350мс, наявність непустого рядка access_token, валідність поля expiresIn (число > 0) та збережи токен у pm.environment.
```

**Очікуваний результат:**
Готовий код JavaScript для вставки в Postman із коментарями до кожного асерта.

**Критерії самоперевірки та оцінювання:**
- [ ] Покриття всіх 4 рівнів асертів
- [ ] Коректне збереження змінної оточення
- [ ] Відсутність синтаксичних помилок

## Завдання 2: Створення генератора тестових даних та негативних перевірок

**Мета:** Навчитися генерувати динамічні тестові набори для виявлення дефектів валідації.

**Вхідний контекст та бізнес-сценарій:**
Створіть скрипт для вкладки Pre-request Script у Postman, який генерує випадкові валідні та екстремальні дані для реєстрації нового клієнта.

**Покроковий алгоритм виконання:**
1. Згенеруйте унікальний email через `pm.variables.replaceIn('{{$randomEmail}}')`.
2. Згенеруйте випадковий пароль, що задовольняє вимогам складності (великі літери, цифри, спецсимволи).
3. Сформуйте тіло запиту з динамічними змінними та надішліть його на тестовий сервер.

**Рекомендований системний AI-промпт:**
```text
Напиши код для вкладки 'Pre-request Script' у Postman, який формує складне тіло запиту для реєстрації користувача з динамічним email, телефоном у форматі +380XXXXXXXXX та безпечним паролем.
```

**Очікуваний результат:**
JavaScript код попереднього скрипта з генерацією реалістичних тестових даних.

**Критерії самоперевірки та оцінювання:**
- [ ] Використання динамічних змінних Postman
- [ ] Коректний формат телефонного номера
- [ ] Безпечна передача згенерованих даних у тіло запиту
