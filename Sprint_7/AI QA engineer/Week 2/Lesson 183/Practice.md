## Завдання 1: Складання запитів JSONPath для фільтрації складного каталогу товарів

**Мета:** Опанувати синтаксис виразів JSONPath для швидкої екстракції даних у тестах.

**Вхідний контекст та бізнес-сценарій:**
Вам надано JSON-відповідь каталогу інтернет-магазину на 50 товарів із різними категоріями, знижками та статусами наявності.

**Покроковий алгоритм виконання:**
1. Складіть JSONPath вираз для отримання назв усіх товарів з ціною > 500.
2. Складіть вираз для витягування ID першого доступного на складі товару.
3. Складіть вираз для отримання списку всіх унікальних тегів у каталозі.

**Рекомендований системний AI-промпт:**
```text
Склади набір із 5 практичних JSONPath виразів для аналізу наданого JSON каталогу електроніки: фільтр за ціною, пошук товарів зі знижкою, витягування ID останнього замовлення та підрахунок загальної кількості відгуків.
```

**Очікуваний результат:**
Перелік валідних виразів JSONPath із поясненням логіки кожного фільтра.

**Критерії самоперевірки та оцінювання:**
- [ ] Коректне використання фільтрів $[?(...)]
- [ ] Правильний синтаксис витягування вкладених полів
- [ ] Описано практичне застосування в тестах Postman

## Завдання 2: Створення автоматизованої перевірки схеми JSON Schema в тестах Postman

**Мета:** Написати скрипт повної контрактної перевірки структури даних у середовищі Postman за допомогою Ajv/tv4.

**Вхідний контекст та бізнес-сценарій:**
Налаштуйте автоматичний тест для ендпоінта профілю користувача GET /api/v1/users/me.

**Покроковий алгоритм виконання:**
1. Створіть об'єкт схеми з обов'язковими полями id (uuid), email, role, createdAt.
2. Додайте перевірку за допомогою бібліотеки tv4 або Ajv у вкладці Tests.
3. Забезпечте виведення зрозумілого повідомлення про помилку у разі невідповідності типу будь-якого поля.

**Рекомендований системний AI-промпт:**
```text
Напиши JavaScript-код для вкладки 'Tests' у Postman, який валідує відповідь сервера за допомогою JSON Schema. Схема повинна перевіряти типи id (рядок), age (число від 18 до 100) та friends (масив рядків).
```

**Очікуваний результат:**
Готовий до використання перевірочний скрипт Postman із обробкою помилок валідації.

**Критерії самоперевірки та оцінювання:**
- [ ] Використання pm.test та бібліотеки валідації схем
- [ ] Вичерпний опис структури об'єкта
- [ ] Інформативний вивід помилки при падінні тесту
