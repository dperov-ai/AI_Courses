# Практичні завдання до Уроку 186: Основи HTTP та REST

Практичний блок розроблено для закріплення навичок роботи з AI-інструментами, аналізу реальних виробничих кейсів та створення професійних артефактів.

---

## Завдання 1: Ініціалізація та конфігурація Playwright API тестового середовища

**Мета:** Налаштувати виробничий конфігураційний файл playwright.config.ts та виділений API-клієнт.

**Вхідний контекст та бізнес-сценарій:**
Створіть каркас проекту автоматизації API з підтримкою змінних оточення (dotenv), базового URL, логування та налаштування таймаутів.

**Покроковий алгоритм виконання:**
1. Створіть конфігураційний файл playwright.config.ts із зазначенням use: { baseURL, extraHTTPHeaders }.
2. Створіть допоміжну функцію створення контексту з підтримкою передачі кастомних токенів.
3. Напишіть базовий перевірочний тест доступності ендпоінта Health Check (GET /health -> 200 OK).

**Рекомендований системний AI-промпт:**
```text
Напиши повний конфігураційний файл playwright.config.ts для тестування REST API на TypeScript. Включи підтримку baseURL з process.env, тайм-аут 10 секунд, генерацію HTML та Allure звітів та ігнорування HTTPS помилок. Додай зразок тесту Health Check.
```

**Очікуваний результат:**
Файли playwright.config.ts та health.spec.ts із повною типізацією.

**Критерії самоперевірки та оцінювання:**
- [ ] Коректний експорт конфігурації PlaywrightTestConfig
- [ ] Налаштування глобальних заголовків за замовчуванням
- [ ] Працездатний тест перевірки статусу 200

## Завдання 2: Створення Service Client обгортки над REST API ресурсом

**Мета:** Реалізувати патерн Service Object для інкапсуляції мережевих викликів.

**Вхідний контекст та бізнес-сценарій:**
Розробіть клас UsersService, який приховує прямі HTTP-виклики та надає чисті методи для створення, пошуку та видалення користувачів у тестах.

**Покроковий алгоритм виконання:**
1. Створіть клас UsersService, що приймає APIRequestContext у конструкторі.
2. Реалізуйте методи createUser(dto), getUserById(id) та deleteUser(id).
3. Використайте створений сервіс в ізольованому автоматизованому тесті.

**Рекомендований системний AI-промпт:**
```text
Створи клас UsersService на TypeScript для Playwright, який реалізує методи роботи з ресурсом /api/v1/users (CRUD). Додай типізацію параметрів та повернення APIResponse. Напиши зразок тесту з використанням цього класу.
```

**Очікуваний результат:**
Клас UsersService.ts та файл тесту users.spec.ts.

**Критерії самоперевірки та оцінювання:**
- [ ] Чітке розділення мережевої логіки та асертів
- [ ] Використання TypeScript інтерфейсів для DTO
- [ ] Повна автономність тесту
