# Практичні завдання до Уроку 187: HTTP methods та status codes

Практичний блок розроблено для закріплення навичок роботи з AI-інструментами, аналізу реальних виробничих кейсів та створення професійних артефактів.

## Завдання 1: Створення параметризованого сьюту перевірки статусів та заборонених методів

**Мета:** Розробити автоматизований тест на Playwright для комплексної перевірки матриці HTTP-методів.

**Вхідний контекст та бізнес-сценарій:**
Реалізуйте тест для ресурсу /api/v1/articles. Ендпоінт підтримує GET (200) та POST (201). Спроби виклику PUT, DELETE, PATCH повинні повертати статус 405.

**Покроковий алгоритм виконання:**
1. Створіть тестовий файл articles-methods.spec.ts.
2. Напишіть позитивні тести для GET та POST.
3. Реалізуйте параметризований цикл для перевірки методів PUT, DELETE, PATCH з асертом на статус 405 та наявність заголовка Allow.

**Рекомендований системний AI-промпт:**
```text
Напиши параметризований тестовий сьют на TypeScript для Playwright, що тестує допустимі та недопустимі HTTP методи для ендпоінта /api/v1/articles. Забезпеч перевірку статусів 200, 201, 405 та валідацію заголовка 'Allow'.
```

**Очікуваний результат:**
Повний TypeScript файл articles-methods.spec.ts.

**Критерії самоперевірки та оцінювання:**
- [ ] Використання параметризованого циклу for..of
- [ ] Перевірка статус-коду 405 для заборонених методів
- [ ] Асерт наявності заголовка Allow

## Завдання 2: Реалізація автотесту перевірки ідемпотентності видалення сутності

**Мета:** Побудувати надійний багатокроковий автотест, що перевіряє семантику видалення ресурсу.

**Вхідний контекст та бізнес-сценарій:**
Протестуйте повний цикл життя ресурсу: створення -> перше видалення (204/200) -> повторне видалення (404) -> перевірка відсутності в базі (404).

**Покроковий алгоритм виконання:**
1. Створіть унікальну сутність через POST-запит та отримайте її ID.
2. Надішліть DELETE-запит та перевірте успішний статус (204 або 200).
3. Надішліть повторний DELETE-запит на цей же ID та перевірте отримання 404 Not Found.
4. Виконайте GET-запит на цей ID і підтвердіть статус 404.

**Рекомендований системний AI-промпт:**
```text
Створи E2E тест на Playwright TypeScript для перевірки ідемпотентності операції DELETE для ресурсу /api/v1/products/:id. Протестуй створення, перше видалення, повторне видалення та спробу отримання видаленого продукту.
```

**Очікуваний результат:**
Працездатний тест delete-idempotency.spec.ts.

**Критерії самоперевірки та оцінювання:**
- [ ] Динамічне створення тестового продукту
- [ ] Асерт статусу 204/200 на першому видаленні
- [ ] Асерт статусу 404 на повторному видаленні та читанні
