# Запитання для перевірки знань: Робота з PDF-документами

1. Чому формат PDF спочатку створювався для друку, а не для машинного аналізу структури тексту?

2. У чому полягає технічна різниця між текстовим (Digital-native) та сканованим (Image-based) PDF-файлом?

3. Чому під час зчитування багатоколонкових статей (наприклад, наукових журналів) звичайні парсери зливають текст по горизонталі?

4. Як наявність верхніх і нижніх колонтитулів (номери сторінок, колонтитули) спотворює розуміння контексту мовною моделлю?

5. Що таке технологія **OCR (Optical Character Recognition)** і коли вона стає необхідною при роботі з документами?

6. Як мультимодальні Vision-моделі (GPT-4o, Claude Sonnet, Gemini Flash) вирішують проблему розпізнавання складних PDF-таблиць?

7. Що таке підхід **Map-Reduce** під час аналізу багатосторінкового PDF-звіту на 300 сторінок?

8. Як технологія **RAG (Retrieval-Augmented Generation)** дозволяє знаходити точні відповіді у великих архівах PDF без перевитрати контексту?

9. Чому вимога вказувати номер сторінки та цитувати пункт договору є критичною для перевірки аналізу юридичних документів?

10. Які типи графічних елементів (діаграми, схеми, водяні знаки) у PDF найчастіше викликають помилки розпізнавання?

11. Складіть промпт для вилучення фінансових показників (виторг, чистий прибуток, EBITDA) з PDF-звіту компанії.

12. Складіть інструкцію для співробітників щодо підготовки PDF-документів до завантаження в AI-системи для досягнення максимальної якості розпізнавання.
