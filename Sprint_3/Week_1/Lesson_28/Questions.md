# Запитання для перевірки знань: Як перевіряти результати роботи AI

1. Що таке **Automation Bias (упередження на користь автоматизації)** і чому люди схильні довіряти неперевіреним відповідям AI?

2. Чому переконливий і впевнений тон мовної моделі не є гарантією достовірності згенерованої інформації?

3. Що означає концепція **Human-in-the-Loop (HITL)** у контексті використання генеративного штучного інтелекту?

4. Опишіть 4 рівні комплексної верифікації результатів генерації AI.

5. Як здійснюється структурний та синтаксичний аудит відповіді моделі?

6. Які категорії даних (дати, посилання, закони, суми) мають найвищий ризик галюцинацій та помилок?

7. Чому великі мовні моделі часто припускаються арифметичних помилок у простих розрахунках?

8. Як інструменти виконання коду (наприклад, Python Code Interpreter) підвищують точність математичних обчислень моделі?

9. Чому мовні моделі часто генерують «биті» або неіснуючі гіперпосилання (URL)?

10. У чому полягає метод **зворотного тестування (Reverse Verification)** за допомогою ролі незалежного аудитора?

11. Які небезпеки виникають, якщо юридичний або медичний документ, згенерований AI, використовується без експертної верифікації людиною?

12. Складіть чек-лист із 5 пунктів для обов'язкової перевірки фінансового звіту, згенерованого мовною моделлю.

13. Складіть промпт для ревізії статті, який змушує модель знайти та виділити всі непідтверджені першоджерелами твердження.

14. Як організувати процес контролю якості контенту в команді, яка щодня використовує AI для підготовки матеріалів?
