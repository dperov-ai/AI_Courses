# Перевірка фактів та джерел: повний посібник із боротьби з фантомними посиланнями та галюцинаціями

Одна з найбільш парадоксальних особливостей великих мовних моделей полягає в їхній здатності генерувати так звані **фантомні джерела (Phantom Citations / Hallucinated References)**.

Якщо ви попросите стандартну мовну модель навести перелік наукових досліджень, юридичних прецедентів або корпоративних звітів на підтвердження певної тези, вона згенерує список, який візуально виглядає бездоганно. Там будуть зазначені реальні відомі вчені з Оксфорду чи Стенфорду, авторитетні назви міжнародних журналів на кшталт *Nature*, *Harvard Business Review* або *IEEE Transactions*, правильні роки публікацій і навіть згенеровані рядки DOI (цифрові ідентифікатори об'єктів).

Проте якщо спробувати знайти ці статті в міжнародних базах даних (Scopus, Web of Science, PubMed, Google Scholar), виявиться, що **жодної з них ніколи не існувало в реальності**.

У цьому фундаментальному посібнику ми розглянемо:

* чому мовні моделі органічно схильні до вигадування джерел і як працює цей механізм;
* відмінності між автономними моделями та моделями з пошуковим заземленням (Search Grounding);
* архітектуру систем RAG (Retrieval-Augmented Generation) та їхні обмеження;
* журналістську методику тріангуляції фактів у роботі з AI;
* техніку примусового цитування (Source-Grounded Prompting);
* покроковий алгоритм фактчекінгу наукових, юридичних та бізнес-матеріалів.

---

## 1. Механіка виникнення фантомних цитат

Щоб зрозуміти, чому модель вигадує літературу, потрібно поглянути на те, як вона бачить світ.

У моделі немає вбудованої бібліотеки PDF-файлів або реєстру видань. Вона оперує статистичними закономірностями розподілу слів.

```
+───────────────────────────────────────────────────────────────────────────+
|               ЯК МОДЕЛЬ СТВОРЮЄ ФАНТОМНЕ НАУКОВЕ ДЖЕРЕЛО                  |
+───────────────────────────────────────────────────────────────────────────+
| 1. Патерн у пам'яті: "Наукове посилання = Автор + Журнал + Рік + Тема"    |
|                                                                           |
| 2. Крок 1: Модель обирає автора, який часто пише на тему нейробіології    |
|    ──► Наприклад: "Andrew Huberman" або "Matthew Walker".                 |
|                                                                           |
| 3. Крок 2: Обирає авторитетний журнал у цій темі                          |
|    ──► Наприклад: "Journal of Neuroscience".                              |
|                                                                           |
| 4. Крок 3: Синтезує науково звучну назву на задану тему                   |
|    ──► "Impact of Circadian Disruption on Cognitive Function in Adults".  |
|                                                                           |
| 5. Крок 4: Формує псевдо-ідентифікатор DOI за стандартним шаблоном        |
|    ──► "10.1016/j.jneuro.2021.05.014".                                    |
|                                                                           |
| РЕЗУЛЬТАТ: Посилання виглядає на 100% справжнім, але є чистою вигадкою!   |
+───────────────────────────────────────────────────────────────────────────+
```

Для нейромережі згенероване посилання є статистично ідеальним продовженням тексту. Вона не знає концепції «існує / не існує в матеріальному світі» — для неї існує лише математична ймовірність послідовності літер.

## 2. Заземлення на веб-пошук (Search Grounding) та системи RAG

Щоб подолати проблему фантомних джерел, розробники створили системи **пошукового заземлення (Grounding)** та **RAG (Retrieval-Augmented Generation)**:

```
                  АРХІТЕКТУРА SEARCH GROUNDING
                  
   [ Питання користувача ]
             │
             ▼
   [ Пошуковий модуль (Bing / Google / Vector DB) ]
             │
             ▼ Знаходить реальні живі веб-сторінки та документи
   [ Витягнуті фрагменти тексту з реальними URL ]
             │
             ▼ Передаються у вікно контексту
   [ LLM синтезує відповідь, спираючись ВИКЛЮЧНО на знайдені цитати ]
             │
             ▼
   [ Відповідь із перевіреними клікабельними посиланнями ]
```

### Порівняння підходів:

| Параметр | Закрита модель (Без вебу) | Модель із веб-пошуком (ChatGPT Search, Perplexity) | Корпоративний RAG (Власна база) |
| :--- | :--- | :--- | :--- |
| **Джерело фактів** | Заморожені ваги нейромережі | Відкритий інтернет у реальному часі | Закриті корпоративні документи компанії |
| **Ризик фантомних цитат** | **ДУЖЕ ВИСОКИЙ (до 70%)** | Низький (посилання реальні, але можливі помилки інтерпретації) | Практично нульовий (при правильному налаштуванні) |
| **Актуальність даних** | Обмежена датою тренування | Актуальна на сьогоднішню секунду | Актуальна відповідно до оновлення файлів бази |

## 3. Журналістський метод тріангуляції фактів

У розслідувальній журналістиці та фінансовому аудиті діє непорушне правило:

> **Жодне неочевидне твердження, статистичний показник, сума угоди чи цитата не вважаються достовірними, доки вони не підтверджені з 2–3 взаємно незалежних джерел.**

```
                                [ ТВЕРДЖЕННЯ / ЦИФРА ]
                                          ▲
                         ┌────────────────┼────────────────┐
                         │                │                │
                 [ ДЖЕРЕЛО 1 ]      [ ДЖЕРЕЛО 2 ]    [ ДЖЕРЕЛО 3 ]
                 Офіційний звіт     Академічне       Провідне ділове
                 компанії (10-K)    дослідження      видання (Bloomberg)
```

### Критерії авторитетності джерел (Піраміда довіри):
1. **Рівень 1 (Найвищий):** Офіційні державні реєстри, нормативно-правові акти на сайтах парламентів, фінансова звітність компаній, завірена аудиторами (Big Four), рецензовані статті в базах Scopus/PubMed.
2. **Рівень 2 (Високий):** Провідні світові інформаційні агентства (Reuters, Bloomberg, AP), офіційні прес-релізи виробників, технічна документація вендорів.
3. **Рівень 3 (Середній/Низький):** Новинні сайти загальної тематики, корпоративні блоги, пости в соціальних мережах, форуми (Reddit, Quora).

## 4. Техніка Source-Grounded Prompting (Примусове заземлення)

Якщо вам необхідно отримати від моделі аналітичний документ, який гарантовано не містить вигадок, використовуйте промпт із примусовим обмеженням базою наданого тексту.

### Професійний шаблон Source-Grounded промпту:
```markdown
Ти — провідний аналітик та фактчекер.
Твоя задача — відповісти на поставлені запитання, спираючись ВИКЛЮЧНО на наданий нижче фрагмент офіційного звіту.

СУВОРІ ПРАВИЛА ВЕРИФІКАЦІЇ:
1. Заборонено використовувати будь-які зовнішні знання, які не містяться в тексті документа.
2. Кожне твоє твердження або цифра повинні супроводжуватися прямою дослівною цитатою з тексту в лапках [«...»] із зазначенням номера сторінки чи абзацу.
3. Якщо документ не містить прямої відповіді на будь-яке з питань — ти ЗОБОВ'ЯЗАНИЙ написати: «У наданому тексті інформація з цього приводу відсутня». Будь-які домисли чи припущення категорично заборонені.

ТЕКСТ ПЕРШОДЖЕРЕЛА:
"""
[Вставте офіційний документ або витяг]
"""

ЗАПИТАННЯ ДЛЯ АНАЛІЗУ:
[Ваші запитання]
```

## 5. Практичний чек-лист фактчекера

Перед публікацією або використанням аналітики виконайте такі кроки:

- [ ] **Перевірка URL-адрес:** Чи відкривається кожне посилання, чи немає помилки 404?
- [ ] **Звірка з першоджерелом:** Чи відповідає знайдена стаття тому, що про неї написав AI, чи модель перекрутила висновок вчених?
- [ ] **Пошук первинного автора:** Чи не цитує стаття переказ іншого переказу?
- [ ] **Перевірка дати дослідження:** Чи не застаріли дані (особливо в галузі технологій, маркетингу та медицини)?
- [ ] **Аудит числових даних:** Чи співпадає порядок величин із галузевими стандартами?

---

## Резюме уроку

1. **Фантомні посилання** виникають через те, що нейромережі статистично моделюють структуру бібліографії, а не звертаються до реального каталогу.
2. Для роботи з актуальними фактами використовуйте інструменти з **Search Grounding (ChatGPT Search, Perplexity)** або корпоративні **RAG-системи**.
3. Завжди застосовуйте **метод тріангуляції** — перевіряйте критичні дані щонайменше за двома незалежними джерелами високого рівня довіри.
4. Техніка **Source-Grounded Prompting** із вимогою обов'язкового прямого цитування блокує галюцинації моделі.
