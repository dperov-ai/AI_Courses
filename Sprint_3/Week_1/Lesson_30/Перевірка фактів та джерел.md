# Перевірка фактів та джерел: боротьба з фантомними посиланнями

Одна з найбільш дивовижних і водночас небезпечних властивостей великих мовних моделей — їхня здатність генерувати **фантомні джерела (Phantom Citations)**.

Якщо ви попросите модель:

> «Наведи 5 наукових статей про вплив кофеїну на сон із посиланнями на авторів, назву журналу, рік та DOI».

модель з високою ймовірністю поверне список статей, які виглядають абсолютно реальними. У них будуть вказані справжні прізвища професорів із Гарварду, авторитетні назви журналів на кшталт *Nature* або *The Lancet*, правдоподібні назви досліджень і навіть згенеровані рядки DOI. Проте, якщо ви спробуєте знайти ці статті в базах даних, виявиться, що **жодної з них ніколи не існувало в природі**.

У цьому уроці ми розберемо:

* чому мовні моделі вигадують книги, статті, закони та біографії;
* як влаштовані моделі з підтримкою веб-пошуку та заземлення (Grounding / Perplexity / ChatGPT Search);
* метод тріангуляції фактів для перевірки інформації;
* техніку примусового заземлення на наданий контекст (Source Grounding);
* чек-лист перевірки першоджерел перед публікацією аналітичних матеріалів.

---

## Чому виникають фантомні цитати

Мовні моделі не мають доступу до бази даних у класичному розумінні. Вони оперують статистичними асоціаціями між словами.

```
+-------------------------------------------------------------------+
|               МЕХАНІЗМ СТВОРЕННЯ ФАНТОМНОГО ДЖЕРЕЛА               |
+-------------------------------------------------------------------+
| 1. Модель "знає", що наукова стаття складається з:                |
|    [Автор] + [Назва журналу] + [Рік] + [Тема] + [Посилання/DOI]  |
|                                                                   |
| 2. Модель бере відомого автора в цій темі (наприклад, Сміт).      |
| 3. Бере відомий журнал (наприклад, Journal of Neuroscience).      |
| 4. Синтезує правдоподібну назву статті на задану тему.            |
| 5. Генерує формальний рядок DOI: 10.1016/j.jneuro.2021.04.012     |
|                                                                   |
| РЕЗУЛЬТАТ: Ідеально виглядаюча фейкова стаття!                     |
+-------------------------------------------------------------------+
```

Якщо модель навчалася без доступу до живого пошукового індексу, вона не вміє перевіряти існування сторінки — вона лише генерує найбільш правдоподібний текст бібліографічного посилання.

## Веб-пошук та заземлення (Search Grounding)

Для вирішення проблеми фантомних цитат сучасні системи використовують технологію **заземлення (Grounding) та RAG (Retrieval-Augmented Generation)**:

```
[ Запит користувача ] ──► [ Пошуковий рушій (Bing / Google) ] ──► [ Топ-5 знайдених сторінок ]
                                                                             │
                                                                             ▼
[ Перевірена відповідь із живими посиланнями ] ◄── [ LLM синтезує відповідь за джерелами ]
```

### Відмінність інструментів:
* **Звичайна модель (без вебу):** Спирається лише на заморожені ваги (високий ризик фантомних цитат).
* **Пошукові моделі (ChatGPT Search, Perplexity AI, Gemini Grounding):** Спочатку роблять запит в інтернет, витягують актуальні фрагменти тексту і лише потім пишуть відповідь, додаючи клікабельні посилання на реальні сайти.

> **Важливо:** Навіть моделі з веб-пошуком можуть помилятися в інтерпретації знайденої статті. Завжди переходьте за посиланням і перевіряйте першоджерело особисто.

## Метод тріангуляції фактів

У журналістиці розслідувань та професійній аналітиці діє «золоте правило тріангуляції»:

> **Жоден неочевидний факт, цифра чи цитата не вважаються достовірними, доки вони не підтверджені щонайменше з 2–3 незалежних авторитетних джерел.**

```
                           [ ФАКТ / ТВЕРДЖЕННЯ ]
                                     ▲
                    ┌────────────────┼────────────────┐
                    │                │                │
            [ Офіційний звіт / ] [ Академічне ] [ Провідне світове ]
            [  Держреєстр      ] [ дослідження] [ видання (Reuters)]
```

### Критерії надійності джерела:
1. **Первинність:** Офіційний звіт компанії (10-K report) або стаття на сайті регулятора завжди надійніші за переказ у чиємусь блозі.
2. **Дата публікації:** Перевірте, чи не змінилися норми або закони після публікації джерела.
3. **Репутація домену:** Домени урядових організацій (`.gov`), освітніх закладів (`.edu`) або провідних інформагентств мають найвищий рівень довіри.

## Техніка Source-Grounded Prompting (Примусове заземлення)

Якщо вам потрібно отримати 100% точний аналіз без вигадок, не дозволяйте моделі спиратися на загальну пам'ять. Завантажуйте текст безпосередньо в запит або контекстне вікно.

### Промпт для суворого заземлення:
```markdown
Ти — фактчекер. Твоя задача — відповісти на запитання, спираючись ВИКЛЮЧНО на наданий нижче фрагмент документа.

ПРАВИЛА:
1. Використовуй лише ті факти, які прямо написані в тексті.
2. Для кожного твердження наводь точну цитату в лапках [«...»] та номер абзацу.
3. Якщо інформації про щось немає в тексті — напиши: «У наданому тексті немає даних з цього приводу». Категорично заборонено додумувати або залучати зовнішні знання.

ТЕКСТ ДОКУМЕНТА:
"""
[Вставте ваш текст або витяг з договору]
"""

ЗАПИТАННЯ:
[Ваше запитання]
```

## Резюме уроку

1. **Фантомні цитати** — це правдоподібно вигадані моделлю назви книг, наукових статей, DOI та законів.
2. Для перевірки актуальних фактів завжди використовуйте моделі з підтримкою **Search Grounding** (Perplexity, ChatGPT Search, Gemini).
3. Застосовуйте **метод тріангуляції** — звіряйте критичні цифри щонайменше за двома незалежними першоджерелами.
4. Техніка **Source-Grounded Prompting** з обов'язковим прямим цитуванням тексту мінімізує ризик галюцинацій до нуля.
