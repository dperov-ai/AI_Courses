# Основи n8n: платформа візуальної оркестрації та AI-автоматизацій

Коли виникає потреба поєднати штучний інтелект із базою даних, Telegram-ботом, CRM-системою, платіжним шлюзом та електронною поштою, перед компанією постає вибір: писати сотні рядків власного коду з нуля або скористатися платформою візуальної автоматизації.

Світовим лідером серед таких платформ для AI-інтеграцій є **n8n** — потужне середовище з відкритим вихідним кодом (Open-Source), яке дозволяє створювати найскладніші AI-пайплайни у зручному візуальному редакторі.

У цьому уроці ми розберемо:

* що таке n8n і чому він перевершує Zapier та Make для AI-проектів;
* базові концепції n8n: Вузли (Nodes), Тригери (Triggers), З'єднання та Data Flow;
* як n8n працює з даними у форматі JSON;
* вбудовані AI-компоненти n8n (AI Agent, LLM Chains, Chat Memory, Vector Stores);
* покроковий процес створення першого працюючого AI-сценарію.

```
+-------------------------------------------------------------------+
```

## Базова архітектура n8n: як це працює

```
                                СЦЕНАРІЙ n8n (WORKFLOW)
                                
  ┌───────────────┐        ┌───────────────┐        ┌───────────────┐
  │ TRIGGER NODE  │───────►│  CODE / LOGIC │───────►│    AI NODE    │
  │ (Telegram-бот)│ $json  │ (Фільтр даних)│ $json  │(OpenAI/Claude)│
  └───────────────┘        └───────────────┘        └───────┬───────┘
                                                            │ $json
                                                            ▼
                                                    ┌───────────────┐
                                                    │  ACTION NODE  │
                                                    │(Google Sheets)│
                                                    └───────────────┘
```

### Ключові поняття:
1. **Node (Вузол):** Окремий блок, який виконує конкретну функцію (наприклад, надсилає лист, робить запит до OpenAI, читає рядок із таблиці).
2. **Trigger (Тригер):** Вузол, який починає виконання сценарію (наприклад, вхідний вебхук `Webhook`, повідомлення в месенджер `Telegram Trigger` або щоденний таймер `Schedule Trigger`).
3. **Data Flow ($json):** Кожен вузол отримує дані від попереднього вузла у вигляді масиву JSON-об'єктів, модифікує їх і передає далі.
4. **Credentials (Облікові дані):** Безпечне сховище API-ключів, логінів і паролів, які один раз налаштовуються і підключаються до відповідних вузлів.

## Спеціалізовані AI-вузли в n8n

n8n має окрему категорію вузлів **Advanced AI**, побудовану на базі фреймворку LangChain:

* **AI Agent Node:** Головний мозок, який керує процесом, вирішує, які інструменти використовувати, та веде діалог.
* **Model Nodes (LLMs):** Підключення моделей від OpenAI (GPT-4o), Anthropic (Claude), Google (Gemini), Groq, Ollama (локальні моделі).
* **Memory Nodes:** Забезпечують пам'ять діалогу (Window Buffer Memory, Redis Memory), щоб бот пам'ятав попередні репліки користувача.
* **Tools Nodes:** Інструменти, які агент може викликати (Google Search, Calculator, Custom Webhook, Code Execution).
* **Vector Store Nodes:** Підключення векторних баз знань (Pinecone, Qdrant, Supabase Vector) для створення корпоративного RAG.

## Покроковий план: створення Telegram AI-Асистента в n8n

```
Крок 1: Додаємо вузол "Telegram Trigger" (підключаємо токен вашого бота).
Крок 2: Додаємо вузол "AI Agent".
Крок 3: До блоку Model підключаємо "OpenAI Chat Model" (обираємо gpt-4o-mini).
Крок 4: До блоку Memory підключаємо "Window Buffer Memory" (зберігає 10 останніх повідомлень).
Крок 5: До блоку Tools підключаємо "Google Sheets Tool" (для пошуку цін на товари).
Крок 6: Додаємо вузол "Telegram Send Message" для відправки відповіді клієнту.
```

Після активації сценарію ви отримуєте повноцінного автономного асистента підтримки, який пам'ятає контекст клієнта та самостійно перевіряє наявність товарів у таблиці!

## Резюме уроку

1. **n8n** — провідна платформа з відкритим кодом для створення складних автоматизацій та інтеграції AI в бізнес-процеси.
2. Головні переваги n8n: **можливість Self-hosted розгортання, відсутність плати за кількість операцій та глибока інтеграція з LangChain**.
3. Усі дані в n8n передаються між вузлами у стандартизованому форматі **JSON**.
4. Завдяки візуальним вузлам **AI Agent, Memory, Vector Store та Tools** в n8n можна за 15 хвилин зібрати корпоративного чат-бота з доступом до внутрішніх баз даних.
