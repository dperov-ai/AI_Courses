# Основи n8n: повний посібник з візуальної оркестрації, LangChain та AI-автоматизацій

Коли перед компанією постає завдання інтегрувати штучний інтелект у реальні робочі процеси — з'єднати мовну модель із Telegram-ботом, CRM-системою (HubSpot, Pipedrive), базою даних PostgreSQL, платіжним шлюзом Stripe та електронною поштою Gmail — виникає дилема: писати тисячі рядків власного коду з нуля чи скористатися платформою візуальної оркестрації.

Світовим лідером та промисловим стандартом серед таких систем став **n8n** — потужне середовище автоматизації з відкритим вихідним кодом (Open-Source / Fair-Code), яке поєднує зручність no-code інтерфейсу з необмеженою гнучкістю повноцінного програмування на JavaScript/Python та глибокою вбудованою інтеграцією з фреймворком **LangChain**.

У цьому фундаментальному посібнику ми розберемо:

* чому n8n виграє у пропрієтарних платформ (Make, Zapier) для побудови AI-систем;
* архітектуру та базову термінологію n8n: Вузли (Nodes), Тригери (Triggers), З'єднання (Connections) та Data Flow;
* механіку передачі даних між вузлами через JSON-об'єкти (`$json`);
* спеціалізовані AI-вузли n8n: AI Agent, LLM Models, Memory, Tools, Document Loaders та Vector Stores;
* покроковий процес створення та тестування вашого першого AI-сценарію.

## 2. Базова архітектура n8n: як влаштований Data Flow

```
                                  ТИПОВИЙ СЦЕНАРІЙ n8n
                                  
  ┌─────────────────┐        ┌─────────────────┐        ┌─────────────────┐
  │  TRIGGER NODE   │───────►│    CODE NODE    │───────►│     AI NODE     │
  │(Webhook/Telegram)│ $json  │ (Фільтр даних)  │ $json  │ (OpenAI/Claude) │
  └─────────────────┘        └─────────────────┘        └────────┬────────┘
                                                                 │ $json
                                                                 ▼
                                                        ┌─────────────────┐
                                                        │   ACTION NODE   │
                                                        │ (Google Sheets) │
                                                        └─────────────────┘
```

### Ключові поняття платформи:
1. **Workflow (Сценарій):** Візуальне полотно (Canvas), на якому розташовані з'єднані між собою блоки.
2. **Node (Вузол):** Окремий будівельний блок. Бувають:
   * **Trigger Nodes:** Починають виконання за подією (наприклад, `Webhook`, `Telegram Trigger`, `Schedule Trigger`).
   * **Regular / Action Nodes:** Виконують дію (наприклад, `HTTP Request`, `Google Sheets`, `Slack`).
   * **AI Sub-Nodes:** Спеціальні дочірні блоки (моделі, пам'ять, інструменти), що підключаються до AI Agent.
3. **Data Flow ($json):** Кожен вузол приймає на вхід масив JSON-об'єктів і передає модифікований масив далі. Звернутися до даних будь-якого попереднього вузла можна через вираз `{{ $json.client_name }}`.
4. **Credentials (Облікові дані):** Централізоване безпечне сховище API-ключів (OpenAI API Key, токен бота Telegram, доступи до баз даних).

## 3. Спеціалізовані AI-вузли (Advanced AI Suite)

В n8n вбудована ціла екосистема компонентів для побудови складних систем штучного інтелекту:

```
+───────────────────────────────────────────────────────────────────────────+
|                       ЕКОСИСТЕМА ADVANCED AI В n8n                        |
+───────────────────────────────────────────────────────────────────────────+
| 1. AI AGENT NODE                                                          |
|    - Центральний мозок сценарію. Приймає запит користувача, аналізує мету,|
|      викликає підключені інструменти (Tools) та генерує фінальну відповідь.|
|                                                                           |
| 2. MODEL NODES (Моделі)                                                   |
|    - Підключення OpenAI (GPT-4o), Anthropic (Claude Sonnet), Google       |
|      (Gemini), Groq (надшвидкі Llama-моделі), Ollama (локальні моделі).   |
|                                                                           |
| 3. MEMORY NODES (Пам'ять)                                                 |
|    - Window Buffer Memory: пам'ятає останні N повідомлень користувача.    |
|    - Redis / Postgres Memory: зберігає історію спілкування місяцями.      |
|                                                                           |
| 4. TOOL NODES (Інструменти агента)                                        |
|    - Google Search, Calculator, Custom Webhook Tool, Code Execution Tool, |
|      Database Reader (дозволяють моделі самостійно брати дані ззовні).    |
|                                                                           |
| 5. VECTOR STORE & EMBEDDINGS (Корпоративні бази знань / RAG)               |
|    - Pinecone, Qdrant, Supabase Vector, In-Memory Vector Store.           |
+───────────────────────────────────────────────────────────────────────────+
```

## 4. Покрокова збірка першого AI-бота підтримки в n8n

```
                               АРХІТЕКТУРА БОТА ПІДТРИМКИ
                               
                               ┌───────────────────────────┐
                               │  OpenAI Chat Model (LLM)  │
                               └─────────────┬─────────────┘
                                             │
  ┌───────────────────┐        ┌─────────────▼─────────────┐        ┌───────────────────┐
  │ Telegram Trigger  │───────►│       AI AGENT NODE       │───────►│ Telegram Send Msg │
  │(Вхідне повідомл.) │        │ (Оркестратор діалогу)     │        │(Відповідь клієнту)│
  └───────────────────┘        └──────┬──────────────┬─────┘        └───────────────────┘
                                      │              │
                    ┌─────────────────▼──┐        ┌──▼────────────────┐
                    │ Window Buffer Mem  │        │ Google Sheets Tool│
                    │(Пам'ять діалогу)   │        │(База цін на товари│
                    └────────────────────┘        └───────────────────┘
```

### Покроковий алгоритм налаштування:
1. **Крок 1:** Створіть новий Workflow і додайте вузол `Telegram Trigger`. Підключіть токен вашого Telegram-бота.
2. **Крок 2:** Додайте вузол `AI Agent`. З'єднайте його з тригером.
3. **Крок 3:** До порту **Model** вузла AI Agent підключіть блок `OpenAI Chat Model`, обравши модель `gpt-4o-mini` та ввівши API-ключ.
4. **Крок 4:** До порту **Memory** підключіть `Window Buffer Memory` і встановіть ліміт у 10 останніх повідомлень.
5. **Крок 5:** До порту **Tools** підключіть інструмент `Google Sheets Tool`, обравши вашу корпоративну таблицю цін із описом: *«Використовуй цей інструмент, щоб знайти актуальну ціну та наявність товару на складі»*.
6. **Крок 6:** Додайте фінальний вузол `Telegram Send Message`, який відправляє текст `{{ $json.output }}` назад у чат клієнту.

## Резюме уроку

1. **n8n** — світовий стандарт візуальної оркестрації завдяки **можливості безкоштовного Self-hosted розгортання, повній приватності даних та відсутності плати за операції**.
2. Усі дані в n8n циркулюють між вузлами у стандартизованому форматі **JSON-об'єктів (`$json`)**.
3. Завдяки нативній інтеграції з **LangChain**, n8n дозволяє візуально збирати складні мультиагентні системи та корпоративні RAG-пайплайни.
4. Поєднання тригерів, пам'яті, інструментів (Tools) та мовних моделей дає змогу за лічені хвилини створювати повноцінних автономних бізнес-асистентів.
