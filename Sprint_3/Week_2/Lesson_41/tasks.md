# Практичні завдання: Основи n8n

Мета цих завдань — познайомитися з інтерфейсом платформи візуальної оркестрації n8n, навчитися підключати тригери, моделі через LangChain-вузли та створити свій перший працюючий AI-сценарій.

---

### Завдання 1. Створення першого базового AI-сценарію в n8n (Webhook -> LLM -> Telegram)

**Мета:** Зібрати та протестувати працюючий воркфлоу в середовищі n8n (хмарному або локальному).

**Інструкція для студента:**
1. Відкрийте n8n (створіть безкоштовний тестовий акаунт на n8n.cloud або запустіть локально через `npx n8n` чи Docker).
2. Створіть новий Workflow:
   * Додайте вузол **Webhook Trigger** (метод POST, шлях `/test-ai`).
   * Додайте вузол **OpenAI** (або Anthropic / Groq / Ollama) з дією *Generate text / Chat*.
   * Налаштуйте промпт: візьміть текст із вебхука `{{ $json.body.message }}` і попросіть модель перекласти його діловою англійською мовою.
   * Додайте вузол **Telegram** (або Respond to Webhook) для повернення перекладеного тексту.
3. Протестуйте сценарій через інструмент Postman або вбудований тестовий запуск у n8n.

**Очікуваний результат:** Експортований JSON-файл сценарію з n8n або скріншот успішного виконання (Execution).

### Завдання 2. Налаштування AI Agent Node з пам'яттю (Memory) в n8n

**Мета:** Створити сценарій бота, який пам'ятає попередній контекст діалогу.

**Інструкція для студента:**
1. Додайте на полотно n8n вузол **AI Agent**.
2. Підключіть до нього:
   * До порту Model: **OpenAI Chat Model** (`gpt-4o-mini`).
   * До порту Memory: **Window Buffer Memory** (встановіть ліміт 10 повідомлень).
3. Протестуйте діалог у режимі чату:
   * Повідомлення 1: *«Мене звати Дмитро, я займаюся логістикою»*.
   * Повідомлення 2: *«Як мене звати і в якій сфері я працюю?»*.
4. Переконайтеся, що агент зберіг контекст першого повідомлення та відповів вірно.

**Очікуваний результат:** Скріншот чату тестування агента з демонстрацією збереженої пам'яті.
