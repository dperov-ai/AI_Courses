# Запитання для перевірки знань: Автоматизація повсякденних задач

1. Які ключові інженерні критерії відрізняють аматорський скрипт від промислового (Production-Ready) AI-конвеєра?

2. Опишіть покрокову архітектуру системи **Smart Inbox (Розумна пошта)** від отримання листа до створення чернетки відповіді.

3. Як автоматизований конвеєр **Market Radar** забезпечує щоденний конкурентний моніторинг без участі аналітика?

4. Опишіть наскрізний процес оцифрування та обробки рахунків-фактур (Invoice to CRM) за допомогою Vision AI та n8n.

5. Що таке **Content Repurposing (Перепакування контенту)** і як один подкаст автоматично перетворюється на серію постів для різних соцмереж?

6. Чому будь-який виробничий воркфлоу повинен мати спеціалізований вузол перехоплення помилок (**Error Trigger**)?

7. Як функція **Retry Logic (повторні спроби з паузою)** рятує автоматизацію від короткочасних збоїв та тайм-аутів інтернет-з'єднання?

8. Що таке концепція **Fallback Defaults (резервні значення)** і чому важливо направляти нерозпізнані дані на ручний огляд?

9. Чому для операцій списання коштів, підписання договорів або масових розсилок принцип **Human-in-the-Loop** є обов'язковим?

10. Як захистити корпоративний бюджет від неконтрольованих витрат на API (Rate Limits, Hard Budget Caps)?

11. Що таке **Audit Logging (журналювання транзакцій)** і яку роль воно відіграє при розслідуванні помилок у бізнес-процесах?

12. Як правильно обрати модель для воркфлоу (наприклад, швидку легку модель для первинного сортування і важку модель для фінального аналізу)?

13. Складіть технічний проект сценарію в n8n для автоматичної щотижневої генерації фінансового звіту з бази даних PostgreSQL.

14. Складіть схему екстреного сповіщення команди підтримки при падінні сайту або критичній скарзі VIP-клієнта.

15. Опишіть регламент аудиту та регулярного оновлення системних промптів у працюючих бізнес-сценаріях.

16. Складіть фінальний чек-лист перевірки готовності AI-автоматизації до передачі замовнику або керівництву компанії.
