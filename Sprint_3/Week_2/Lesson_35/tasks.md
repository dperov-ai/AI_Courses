# Практичні завдання: Робота з Excel і табличними даними

Мета цих завдань — опанувати роботу з таблицями через Code Interpreter (Python Pandas), навчитися генерувати складні формули (XLOOKUP, SUMIFS) та автоматизувати рутину через скрипти Google Apps Script.

---

### Завдання 1. Аналіз масиву транзакцій через Code Interpreter (Python)

**Мета:** Навчитися проводити глибокий аналіз даних із 100% математичною точністю.

**Інструкція для студента:**
1. Створіть у Google Таблицях або Excel простий тестовий файл `sales_data.csv` (або згенеруйте 100 рядків за допомогою AI), що містить стовпці:
   * `Order_ID` (номер замовлення)
   * `Date` (дата від 2024-01-01 до 2024-06-30)
   * `Category` (Електроніка, Одяг, Книги, Продукти)
   * `Amount` (сума замовлення від 100 до 5000 грн)
   * `Status` (Виконано, Повернення, Скасовано)
2. Завантажте цей CSV-файл в інтерфейс із підтримкою Code Interpreter (ChatGPT Plus / Advanced Data Analysis або Claude з аналізом коду).
3. Поставте комплексне аналітичне завдання:
   ```markdown
   Використовуючи мову Python (бібліотеку Pandas), проаналізуй завантажений файл `sales_data.csv`:
   1. Розрахуй загальний чистий виторг (тільки для замовлень зі статусом "Виконано").
   2. Знайди категорію з найвищим середнім чеком.
   3. Побудуй графік динаміки виторгу по місяцях (Matplotlib/Seaborn) і збережи його як зображення.
   4. Склади таблицю топ-3 найприбутковіших категорій.
   ```
4. Перевірте код на Python, який написала модель: чи правильно застосовано фільтрацію за статусом?

**Очікуваний результат:** Аналітичний звіт із точними цифрами та згенерованим графіком динаміки продажів.

### Завдання 2. Генерація формули XLOOKUP / SUMIFS для розрахунку комісійних

**Мета:** Отримати готову робочу формулу для таблиць без знання синтаксису.

**Інструкція для студента:**
1. Опишіть мовною моделлю логіку складної бізнес-формули:
   > «У мене є два аркуші в Excel. На аркуші "Продажі" є колонка A з прізвищем менеджера і колонка B із сумою угоди. На аркуші "Бонуси" є таблиця: колонка A — прізвище менеджера, колонка B — відсоток його індивідуального бонусу (наприклад, 5%, 7%, 10%). Напиши формулу для аркуша "Продажі" в колонці C, яка знаходить бонус для відповідного менеджера через функцію XLOOKUP і множить його на суму угоди. Якщо менеджера немає в списку бонусів — повертай 0».
2. Вставте згенеровану формулу у свій файл Excel і перевірте її працездатність на тестових даних.

**Очікуваний результат:** Працююча формула в Excel та скріншот результату розрахунку.

### Завдання 3. Написання Google Apps Script для автоматизації таблиці

**Мета:** Створити власний макрос для автоматичного сортування або надсилання даних.

**Інструкція для студента:**
1. Попросіть AI:
   > «Напиши скрипт Google Apps Script, який щодня перевіряє колонку "Дедлайн" (Колонка C) на аркуші "Завдання". Якщо дедлайн спливає сьогодні, а статус у колонці D не дорівнює "Готово", скрипт виділяє цей рядок червоним кольором і відправляє лист-нагадування на пошту менеджера».
2. Відкрийте в Google Таблицях меню `Розширення -> Apps Script`, вставте згенерований код і запустіть тестове виконання.

**Очікуваний результат:** Скрипт у редакторі Apps Script та успішний запуск без помилок.
