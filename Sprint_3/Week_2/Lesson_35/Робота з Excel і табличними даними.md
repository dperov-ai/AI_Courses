# Робота з Excel і табличними даними: аналітика, формули та автоматизація

Електронні таблиці (**Microsoft Excel, Google Sheets, CSV**) — це головне робоче середовище для фінансистів, маркетологів, менеджерів з продажу та аналітиків. Проте ручна обробка тисяч рядків, написання заплутаних формул і пошук помилок у розрахунках забирають години дорогоцінного часу.

Штучний інтелект кардинально змінює роботу з таблицями: він може не просто підказати формулу, а самостійно **написати скрипт на Python, завантажити ваш файл у пісочницю (Code Interpreter / Advanced Data Analysis), очистити дані, провести когортний аналіз та намалювати графіки**.

У цьому уроці ми розглянемо:

* два способи роботи AI з таблицями (через токени vs через виконання Python-коду);
* генерацію формул будь-якої складності (XLOOKUP, INDEX/MATCH, ARRAYFORMULA);
* автоматичне створення макросів VBA та скриптів Google Apps Script;
* очищення «брудних» даних (Data Cleaning) за лічені секунди;
* практичні кейси фінансового аналізу та сегментації клієнтів.

## Два підходи: Текстовий промпт vs Code Interpreter

```
+-------------------------------------------------------------------+
|                  ЯК МОДЕЛЬ ПРАЦЮЄ З ТАБЛИЦЯМИ                     |
+-------------------------------------------------------------------+
| 1. ЧЕРЕЗ ТЕКСТОВИЙ КОНТЕКСТ (CSV / Markdown)                      |
|    - Таблиця передається як текст у вікно промпту                 |
|    - Підходить: для невеликих таблиць (до 100-200 рядків)         |
|    - Ризик: модель може збитися в рахунку або галюцинувати суми   |
|                                                                   |
| 2. ЧЕРЕЗ CODE INTERPRETER (Advanced Data Analysis / Python)        |
|    - Файл (.xlsx / .csv) завантажується в ізольоване середовище   |
|    - Модель пише реальний код на бібліотеці Pandas і виконує його |
|    - Точність: 100% математична точність                          |
|    - Підходить: для файлів на десятки й сотні тисяч рядків        |
+-------------------------------------------------------------------+
```

> **Золоте правило аналітика:**  
> Якщо у вашій таблиці більше 100 рядків або потрібні точні математичні операції — завжди використовуйте інтерфейси з підтримкою **Code Interpreter (Advanced Data Analysis)**, де розрахунки робить Python, а не статистична мовна модель.

## Генерація формул та скриптів автоматизації

### 1. Складні формули Excel та Google Sheets
Замість того щоб годинами гуглити правильний синтаксис комбінацій функцій, опишіть логіку людською мовою:

> «Мені потрібна формула для Excel.  
> У колонці A — дата покупки, у колонці B — категорія товару, у колонці C — сума.  
> Напиши формулу, яка порахує суму витрат за категорією "Маркетинг" за червень 2024 року».

**Відповідь AI:**
```excel
=SUMIFS(C:C, B:B, "Маркетинг", A:A, ">=2024-06-01", A:A, "<=2024-06-30")
```

### 2. Скрипти автоматизації (Google Apps Script / VBA)
AI вміє писати повноцінні скрипти, які автоматизують рутинні операції всередині таблиць:

```markdown
Напиши скрипт Google Apps Script, який виконує такі дії:
1. Проходить по колонці "Статус замовлення" (Колонка D).
2. Якщо статус дорівнює "Оплачено", копіює весь рядок на лист "Архів".
3. Видаляє перенесений рядок з поточного листа.
4. Додай коментарі до кожної строчки коду.
```

## Очищення даних (Data Cleaning): найшвидша суперсила AI

Часто вихідні вивантаження з CRM чи банківських виписок містять повний хаос: номери телефонів у різних форматах, змішані регістри імен, пропущені комірки, дублікати.

### Задачі очищення, які AI вирішує миттєво:
1. **Нормалізація телефонів:** Приведення до єдиного міжнародного стандарту `+380...`
2. **Розбиття ПІБ:** Розділення одного стовпця «Іванов Іван Іванович» на три окремі стовпці: [Прізвище], [Ім'я], [По батькові].
3. **Видалення зайвих символів:** Очищення цін від значків валют, пробілів та ком для перетворення на чисті числа.

## Резюме уроку

1. Для гарантованої точності аналізу великих таблиць завжди завантажуйте файли у середовище з **Code Interpreter (Python Pandas)**.
2. Використовуйте AI як персонального інженера формул: формулюйте бізнес-логіку словами, отримуючи готові **XLOOKUP, SUMIFS або макроси**.
3. **Очищення даних (Data Cleaning)** за допомогою AI економить до 80% часу під час підготовки аналітичних звітів.
4. Завжди перевіряйте фінальні зведені показники (Total Sum) після застосування автоматизованих скриптів.
