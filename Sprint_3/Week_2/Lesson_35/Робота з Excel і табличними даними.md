# Робота з Excel і табличними даними: повний посібник з аналітики, формул, макросів та Code Interpreter

Електронні таблиці (**Microsoft Excel, Google Sheets, CSV**) залишаються головним операційним ядром світового бізнесу. У таблицях ведуться бюджети, розраховуються зарплати, аналізуються продажі, будуються когорти та зберігаються клієнтські бази.

Проте щоденна рутина аналітика пов'язана з величезними часовими втратами: ручне написання складних формул, виправлення збитих діапазонів, очищення кривих вивантажень із CRM та боротьба з повільною роботою важких файлів.

Штучний інтелект здійснює революцію в роботі з таблицями. Сьогодні AI здатний не просто підказати формулу, а самостійно **написати та виконати код на Python, завантажити файл у пісочницю (Code Interpreter / Advanced Data Analysis), знайти аномалії, побудувати візуалізації та видати готові бізнес-висновки із 100% математичною точністю**.

У цьому фундаментальному посібнику ми розглянемо:

* два принципово різні підходи: аналіз таблиць через текст промпту vs виконання Python-коду в пісочниці;
* генерацію передових формул Excel / Google Sheets (XLOOKUP, INDEX/MATCH, ARRAYFORMULA, REGEXEXTRACT);
* автоматизацію процесів через скрипти VBA (Excel) та Google Apps Script;
* поглиблене очищення та стандартизацію «брудних» масивів даних (Data Cleaning);
* практичні кейси фінансового аналізу, когортного аналізу (RFM) та прогнозування продажів.

## 1. Два підходи до роботи з таблицями: Текст vs Code Interpreter

Головна помилка багатьох початківців — копіювати велику таблицю у вікно чату у вигляді тексту або CSV і просити модель «Порахуй загальну суму або середній чек».

```
+───────────────────────────────────────────────────────────────────────────+
|                 ТЕКСТОВИЙ ПРОМПТ vs CODE INTERPRETER                      |
+───────────────────────────────────────────────────────────────────────────+
| ПІДХІД 1: ТЕКСТОВИЙ КОНТЕКСТ (CSV / Markdown)                             |
| - Таблиця зчитується як звичайний текст.                                  |
| - Розрахунки робить статистична мовна модель (LLM).                       |
| - ТОЧНІСТЬ: НИЗЬКА (Модель часто галюцинує в сумах та відсотках).         |
| - ОБСЯГ: Обмежений (до 100-200 рядків).                                   |
|                                                                           |
| ПІДХІД 2: CODE INTERPRETER / ADVANCED DATA ANALYSIS                       |
| - Файл (.xlsx, .csv) завантажується в ізольовану віртуальну машину.       |
| - Модель пише реальний код на Python (бібліотеки Pandas, NumPy, Scipy).   |
| - ТОЧНІСТЬ: 100% МАТЕМАТИЧНА ТОЧНІСТЬ (Рахує мова Python, а не LLM).      |
| - ОБСЯГ: Мільйони рядків даних, миттєва побудова графіків Matplotlib.     |
+───────────────────────────────────────────────────────────────────────────+
```

> **Золотий стандарт аналітика:**  
> Якщо ваша таблиця містить більше 50 рядків або вимагає точних фінансових розрахунків — завжди використовуйте інтерфейси з підтримкою **Code Interpreter (Advanced Data Analysis)**.

## 2. Генерація формул будь-якої складності

Більше немає потреби тримати в голові складний синтаксис комбінацій функцій. Достатньо описати логіку людською мовою:

```
                                [ ВАША ЗАДАЧА СЛОВАМИ ]
                                           │
                                           ▼
+───────────────────────────────────────────────────────────────────────────+
| ЗАПИТ: "Мені потрібна формула для Google Sheets. У колонці A — дати,      |
| у колонці B — категорія, у колонці C — статус, у колонці D — сума.        |
| Порахуй суму тільки для категорії 'Маркетинг' зі статусом 'Оплачено'     |
| за 3-й квартал 2024 року".                                                |
+───────────────────────────────────────────────────────────────────────────+
                                           │
                                           ▼
+───────────────────────────────────────────────────────────────────────────+
| ФОРМУЛА ВІД AI:                                                           |
| =SUMIFS(D:D, B:B, "Маркетинг", C:C, "Оплачено",                           |
|         A:A, ">=2024-07-01", A:A, "<=2024-09-30")                         |
+───────────────────────────────────────────────────────────────────────────+
```

### Топ-5 формул, які AI допомагає генерувати за секунди:
1. **XLOOKUP:** Сучасна заміна VLOOKUP, яка шукає в будь-якому напрямку і не ламається при додаванні нових колонок.
2. **INDEX + MATCH:** Класична надійна комбінація для динамічного пошуку за двома координатами (рядок і стовпець).
3. **ARRAYFORMULA:** Автоматичне застосування формули до всього стовпця без необхідності протягувати її вниз.
4. **REGEXEXTRACT:** Вилучення номерів телефонів, email або кодів із неструктурованого тексту всередині комірки.
5. **QUERY (Google Sheets):** Повноцінні SQL-подібні запити прямо всередині таблиці (`=QUERY(A:E, "select B, sum(D) where C = 'Paid' group by B")`).

## 3. Автоматизація через скрипти: Google Apps Script та VBA

Якщо ви регулярно робите однакові дії в таблицях — створюєте копії аркушів, відправляєте сповіщення на пошту або архівуєте рядки — AI напише для вас повноцінний макрос.

### Приклад: Автоматичне архівування рядків у Google Sheets

```javascript
/**
 * Скрипт Google Apps Script, згенерований AI.
 * Переносить замовлення зі статусом "Виконано" на архівний лист.
 */
function archiveCompletedOrders() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sourceSheet = ss.getSheetByName("Поточні замовлення");
  const targetSheet = ss.getSheetByName("Архів");
  
  const data = sourceSheet.getDataRange().getValues();
  const rowsToDelete = [];
  
  // Проходимо по рядках починаючи з 2-го (пропускаємо заголовок)
  for (let i = 1; i < data.length; i++) {
    const status = data[i][3]; // Колонка D (індекс 3)
    if (status === "Виконано") {
      targetSheet.appendRow(data[i]);
      rowsToDelete.push(i + 1);
    }
  }
  
  // Видаляємо рядки з кінця, щоб не збивати індекси
  for (let j = rowsToDelete.length - 1; j >= 0; j--) {
    sourceSheet.deleteRow(rowsToDelete[j]);
  }
}
```

## 5. Практичний кейс: комплексний когортний RFM-аналіз клієнтів

**RFM-аналіз** класифікує клієнтів за трьома параметрами:
* **Recency (Давність):** Скільки днів пройшло з останньої покупки.
* **Frequency (Частота):** Скільки всього замовлень зробив клієнт.
* **Monetary (Гроші):** Загальна сума виторгу від клієнта.

### Промпт для Code Interpreter:
```markdown
Ти — провідний Data Scientist та аналітик електронної комерції.
Я завантажив файл `orders.csv` із транзакціями за останні 2 роки.

Виконай покроковий аналіз мовою Python:
1. Очисти дані від тестових замовлень та повернень.
2. Розрахуй RFM-показники для кожного унікального клієнта.
3. Розбий клієнтів на 4 сегменти:
   - "VIP / Чемпіони" (купують часто, нещодавно і на великі суми);
   - "Постійні / Лояльні";
   - "Зона ризику" (купували багато, але давно не поверталися);
   - "Втрачені".
4. Склади зведену таблицю сегментів із відсотком від загального виторгу.
5. Намалюй графік розподілу клієнтів (Seaborn / Matplotlib).
```
