# Створення звітів, резюме та підсумків: поглиблений посібник зі стиснення знань та техніки Chain of Density

У сучасному бізнесі головна цінність інформації полягає не в її обсязі, а в її **концентрації та доступності**. Керівники вищої ланки, інвестори та партнери не мають можливості читати 50-сторінкові технічні звіти чи переглядати 3-годинні записи нарад. Їм потрібна квінтесенція: **що сталося, який вплив на бізнес, які ризики виявлено і які конкретні рішення необхідно прийняти негайно**.

Саммаризація (Summarization) за допомогою штучного інтелекту — це не просто механічне скорочення слів. Це складний аналітичний процес синтезу фактів, виявлення причинно-наслідкових зв'язків та структурування інсайтів.

У цьому поглибленому посібнику ми розглянемо:

* наукові основи саммаризації: екстрактивний vs абстрактивний підхід;
* формати бізнес-підсумків: Executive Summary, Bullet Digest, Analytical Deep-Dive;
* передову техніку **Chain of Density (CoD / Ланцюжок щільності)** для створення максимально насичених текстів;
* концепцію **BLUF (Bottom Line Up Front)** у підготовці звітів для топ-менеджменту;
* повні шаблони та стандарти аналітичних звітів з метриками та рекомендаціями.

---

## 1. Екстрактивна vs Абстрактивна саммаризація

У науці про комп'ютерну лінгвістику існує два фундаментальні підходи до створення підсумків:

```
+───────────────────────────────────────────────────────────────────────────+
|                        ПІДХОДИ ДО САММАРИЗАЦІЇ                            |
+───────────────────────────────────────────────────────────────────────────+
| 1. ЕКСТРАКТИВНА САММАРИЗАЦІЯ (Extractive Summarization)                   |
|    - Алгоритм вибирає найважливіші оригінальні речення з тексту і копіює їх.|
|    - ПЕРЕВАГА: 100% збереження точних слів автора (нульовий ризик вигадки).|
|    - НЕДОЛІК: Текст часто виходить уривчастим, без плавних логічних переходів.|
|                                                                           |
| 2. АБСТРАКТИВНА САММАРИЗАЦІЯ (Abstractive Summarization)                  |
|    - Модель повністю переосмислює зміст і генерує НОВІ речення, які       |
|      лаконічно передають суть великого документа.                         |
|    - ПЕРЕВАГА: Висока щільність думок, бездоганна зв'язність і стиль.     |
|    - НЕДОЛІК: Потребує фактчекінгу, оскільки модель може згладити деталі. |
+───────────────────────────────────────────────────────────────────────────+
```

Сучасні моделі використовують **гібридний підхід**: вони синтезують новий лаконічний текст, але строго заземлюють кожну цифру на першоджерело.

## 2. Концепція BLUF (Bottom Line Up Front)

У корпоративній культурі провідних міжнародних компаній діє принцип **BLUF**:

> **Найголовніший висновок, підсумкова цифра або рішення завжди розміщуються в найпершому реченні документа.**

Зайнятий керівник повинен за 5 секунд зрозуміти суть. Усі подальші розділи документа (методологія, деталі розрахунків, історія переговорів) є лише доказами першої тези.

```
                  СТРУКТУРА ЗВІТУ ЗА ПРИНЦИПОМ BLUF
                  
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. BLUF (Головний висновок + фінансовий результат за 5 сек) │
  └──────────────────────────────┬──────────────────────────────┘
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ 2. КЛЮЧОВІ МЕТРИКИ ТА ФАКТИ (Таблиця з 3-4 головними цифрами)│
  └──────────────────────────────┬──────────────────────────────┘
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ 3. АНАЛІЗ РИЗИКІВ ТА ПРИЧИН (Чому це сталося)               │
  └──────────────────────────────┬──────────────────────────────┘
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ 4. РЕКОМЕНДОВАНІ НАСТУПНІ КРОКИ (Next Steps: Хто? Що? Коли?) │
  └─────────────────────────────────────────────────────────────┘
```

## 3. Техніка Chain of Density (CoD): ідеальна концентрація фактів

Класична проблема звичайного промпту «Зроби коротке резюме» полягає в тому, що модель видає водянистий текст, заповнений загальними фразами.

Дослідники розробили техніку **Chain of Density (Ланцюжок щільності)**, яка змушує модель поетапно ущільнювати інформацію:

```
[ Початковий текст на 10 сторінок ]
                │
                ▼
[ ІТЕРАЦІЯ 1 ]: Базове резюме на 100 слів (багато води, мало сутностей).
                │
                ▼
[ ІТЕРАЦІЯ 2 ]: Модель знаходить 3 пропущені важливі сутності (дати, назви, цифри),
                видаляє 30% води і вставляє факти, ЗБЕРІГАЮЧИ ліміт у 100 слів.
                │
                ▼
[ ІТЕРАЦІЯ 3 ]: Ще більше ущільнення формулювань (максимальна концентрація сенсу).
```

### Готовий промпт для запуску Chain of Density:

```markdown
Ти — провідний аналітик. Твоя задача — створити максимально щільне та інформативне резюме наданого звіту методом Chain of Density.

Виконай роботу за 3 послідовні кроки:
- Крок 1: Напиши початкове резюме обсягом рівно 80-100 слів.
- Крок 2: Визнач 3 важливі пропущені сутності (факти, цифри, компанії). Перепиши резюме, інтегрувавши їх та скоротивши зайві слова (обсяг залишається до 100 слів).
- Крок 3: Додай ще 2 критичні деталі, зробивши формулювання максимально щільними та лаконічними (до 100 слів).

Покажи фінальний варіант Кроку 3.
```

## 4. Повний шаблон професійного Executive Summary для топ-менеджменту

```markdown
# [Назва проекту / Звіту] — Виконавче резюме (Executive Summary)

## 1. Головний результат (BLUF)
Одним-двома реченнями: що сталося, яка головна цифра та яке фінальне стратегічне рішення прийнято.

## 2. Ключові показники ефективності (KPIs)
* Виторг: [$150,000] (Зростання: [+18% до минулого кварталу])
* Вартість залучення клієнта (CAC): [$42] (Зниження: [-12%])
* Рентабельність інвестицій (ROI): [240%]

## 3. Зони критичного ризику та блокери
* Ризик 1: Затримка постачання обладнання на 2 тижні -> Потенційний штраф $5,000.
* Ризик 2: Дефіцит старших розробників на ринку -> Ризик перенесення релізу.

## 4. План дій та відповідальні особи (Next Action Items)
| Завдання | Відповідальна особа | Дедлайн | Необхідний бюджет |
| :--- | :--- | :--- | :--- |
| Затвердити договір з резервним постачальником | Олексій (Head of Procurement) | 15.09.2024 | $0 |
| Запустити найм 2 розробників через агенцію | Анна (HR Lead) | 20.09.2024 | $3,500 |
```

## Резюме уроку

1. Якісна саммаризація — це **структурована квінтесенція фактів, метрик та конкретних бізнес-рішень**.
2. Завжди використовуйте принцип **BLUF (Bottom Line Up Front)**: розміщуйте головний висновок у першому рядку.
3. Застосовуйте техніку **Chain of Density (CoD)** для створення максимально інформативних вичавок без води.
4. Обов'язково завершуйте кожен аналітичний документ **таблицею наступних дій (Action Items)** із зазначенням відповідальних та дедлайнів.
