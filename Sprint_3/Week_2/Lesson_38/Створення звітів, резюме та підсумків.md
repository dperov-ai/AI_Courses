# Створення звітів, резюме та підсумків: мистецтво щільного саммарі

У світі інформаційного перевантаження вміння виділити головне — це найцінніша навичка. Керівники, клієнти та колеги не мають часу читати 40-сторінкові звіти чи багатогодинні стенограми нарад. Їм потрібен **точний, щільний та структурований висновок із ключовими інсайтами та наступними кроками**.

Штучний інтелект є неперевершеним інструментом для саммаризації (Summarization), але якщо просто написати «Зроби скорочення цього тексту», ви отримаєте водянистий переказ без конкретики.

У цьому уроці ми розберемо:

* два види саммаризації (екстрактивна vs абстрактивна);
* формати бізнес-підсумків: Executive Summary, Bullet-Point Digest, Analytical Report;
* техніку **Chain of Density (Ланцюжок щільності)** для створення максимально інформативних вичавок;
* як боротися з втратою важливих деталей під час скорочення;
* універсальну структуру професійного аналітичного звіту.

---

## Два види саммаризації: Екстрактивна vs Абстрактивна

```
+-------------------------------------------------------------------+
|                        ВИДИ САММАРИЗАЦІЇ                          |
+-------------------------------------------------------------------+
| 1. ЕКСТРАКТИВНА (Extractive)                                      |
|    - Модель просто копіює найважливіші оригінальні речення        |
|    - Плюс: 100% збереження формулювань автора                     |
|    - Мінус: текст може вийти уривчастим та незв'язним             |
|                                                                   |
| 2. АБСТРАКТИВНА (Abstractive)                                     |
|    - Модель переосмислює зміст і пише новий зв'язний текст        |
|    - Плюс: лаконічність, плавний стиль, висока щільність думок    |
|    - Мінус: ризик перекручування тонких нюансів (потрібен контроль)|
+-------------------------------------------------------------------+
```

## Формати підсумків для різних рівнів аудиторії

```
   ┌─────────────────────────────────────────────────────────────┐
   │ 1. EXECUTIVE SUMMARY (Для топ-менеджменту / 1 сторінка)     │
   │    - Тільки цифри, вплив на бізнес та прийняті рішення     │
   └──────────────────────────────┬──────────────────────────────┘
                                  ▼
   ┌─────────────────────────────────────────────────────────────┐
   │ 2. BULLET-POINT DIGEST (Для робочих чатів / 5-7 пунктів)    │
   │    - Швидкий огляд ключових новин тижня або зустрічі        │
   └──────────────────────────────┬──────────────────────────────┘
                                  ▼
   ┌─────────────────────────────────────────────────────────────┐
   │ 3. ANALYTICAL REPORT (Глибокий звіт із рекомендаціями)      │
   │    - Графіки, кореляції, ризики та стратегічні кроки        │
   └─────────────────────────────────────────────────────────────┘
```

## Техніка Chain of Density (Ланцюжок щільності)

Метод **Chain of Density (CoD)** був розроблений дослідниками для створення ідеального балансу між стислістю тексту та кількістю корисних фактів.

### Як працює алгоритм CoD:
1. **Ітерація 1:** Модель пише перше базове резюме на 100 слів (воно містить багато зайвих слів).
2. **Ітерація 2:** Модель знаходить 2–3 ключові сутності (імена, цифри, терміни), які пропустила, скорочує воду і вставляє ці сутності, **зберігаючи той самий ліміт у 100 слів**.
3. **Ітерації 3–5:** Процес повторюється, доки кожне речення не буде максимально насичене фактами без втрати читабельності.

### Промпт для запуску Chain of Density:
```markdown
Ти — аналітик даних. Твоя задача — створити максимально інформативне та щільне саммарі наданого тексту методом Chain of Density.

Виконай 3 послідовні ітерації:
- Ітерація 1: Напиши початкове резюме обсягом рівно 80-100 слів.
- Ітерація 2: Визнач 3 важливі пропущені сутності (факти, цифри, компанії). Перепиши резюме, інтегрувавши їх, скоротивши зайві слова (обсяг залишається до 100 слів).
- Ітерація 3: Додай ще 2 критичні деталі, зробивши формулювання максимально щільними та лаконічними (до 100 слів).

Покажи фінальний варіант Ітерації 3.
```

## Універсальний шаблон Executive Summary для керівництва

```markdown
# [Назва проекту / Звіту] — Виконавче резюме

## 1. Головний результат (Bottom Line Up Front / BLUF)
Одним-двома реченнями: що сталося, яка головна цифра та який фінальний висновок.

## 2. Ключові метрики та факти
* Метрика 1: [Показник] (Зміна: +X%)
* Метрика 2: [Показник] (Зміна: -Y%)
* Метрика 3: [Показник]

## 3. Головні ризики та виклики
* Ризик 1: [Опис та потенційний вплив на бюджет/строки]
* Ризик 2: [Опис]

## 4. Рекомендовані наступні кроки (Next Steps)
1. [Дія 1] — Відповідальний: [Хто], Строк: [Коли]
2. [Дія 2] — Відповідальний: [Хто], Строк: [Коли]
```

## Резюме уроку

1. Хороше саммарі — це не просто «скорочений текст», а **структурована квінтесенція фактів, метрик та висновків**.
2. Обирайте формат відповідно до читача: **Executive Summary** для керівників, **Bullet-Points** для команди.
3. Використовуйте техніку **Chain of Density**, щоб підвищити концентрацію корисних сутностей на кожні 100 слів тексту.
4. Завжди завершуйте будь-який аналітичний звіт **блоком конкретних дій та наступних кроків (Next Steps)**.
