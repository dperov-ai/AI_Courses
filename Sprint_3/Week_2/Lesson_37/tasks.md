# Практичні завдання: Аналіз інформації та витягування даних

Мета цих завдань — опанувати технології Information Extraction (IE), навчитися вилучати іменовані сутності (NER), визначати намір клієнта (Intent) та отримувати 100% валідний JSON для інтеграції з CRM.

---

### Завдання 1. Екстракція даних із неструктурованого чату в JSON-схему

**Мета:** Перетворити хаотичне листування клієнта на стандартизований об'єкт бази даних.

**Інструкція для студента:**
1. Візьміть сире повідомлення від покупця:
   > «Добрий вечір! Мене звати Ірина, компанія "Світ Ласощів", Львів. Ми хочемо замовити у вас партію пакувальних коробок: 500 штук розміру М і 200 штук розміру L. Потрібно отримати товар до 20 вересня на відділення Нової Пошти №15 у Львові. Мій телефон для зв'язку 093-111-22-33. Чи можна оплатити за безготівковим розрахунком з ПДВ?»
2. Надішліть це повідомлення в AI із суворим промптом вилучення даних:
   ```markdown
   Ти — бекенд-парсер замовлень. 
   Витягни з повідомлення всі дані та поверни ТІЛЬКИ валідний JSON за схемою:
   {
     "client_name": string,
     "company": string or null,
     "city": string,
     "phone_normalized": string (у форматі +380...),
     "items": [
       {"size": string, "quantity": integer}
     ],
     "delivery": {
       "carrier": string,
       "branch": string,
       "deadline_date": string or null
     },
     "payment_type": "vat_invoice" | "card" | "cash",
     "intent": "order_creation"
   }
   ```
3. Скопіюйте отриманий результат і перевірте його на валідність на безкоштовному сервісі **jsonlint.com**.

**Очікуваний результат:** Валідний JSON-об'єкт без синтаксичних помилок із нормалізованим телефоном `+380931112233`.

---

### Завдання 2. Побудова класифікатора намірів та тональності звернень (Triage)

**Мета:** Налаштувати автоматичне сортування тікетів підтримки за пріоритетом.

**Інструкція для студента:**
1. Підготуйте 3 різних тестових повідомлення:
   * Повідомлення 1 (Скарга / Аварія): *«Ваш сервіс лежить уже 2 години, ми втрачаємо гроші! Негайно поверніть оплату!»*
   * Повідомлення 2 (Питання): *«Підкажіть, будь ласка, чи є у вас інтеграція з 1С?»*
   * Повідомлення 3 (Позитивний відгук): *«Дякую за швидку доставку, все чудово підійшло!»*
2. Складіть промпт, який класифікує масив цих повідомлень за схемою:
   `[Категорія: Bug / Question / Review] | [Тональність: 1-5] | [Терміновість: P1 / P2 / P3] | [Маршрут: Dev / Sales / Support]`.

**Очікуваний результат:** Зведена таблиця автоматичної маршрутизації для всіх трьох звернень.
