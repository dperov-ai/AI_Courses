# Контрольні запитання: Піраміда тестування

1. Що таке Піраміда тестування (Test Pyramid) та які проблеми інженерного процесу вона вирішує?
2. Опишіть характеристики та призначення Модульних тестів (Unit Tests).
3. Чим Інтеграційні тести (Integration Tests) відрізняються від ізольованих модульних тестів?
4. Яке місце в піраміді займає тестування API (REST / GraphQL) і які його ключові переваги над UI-тестами?
5. Що таке наскрізні тести (End-to-End / E2E) і чому їхня частка в піраміді не повинна перевищувати 5-10%?
6. Поясніть сутність та небезпеку антипатерну «Ріжок морозива» (Ice Cream Cone / Inverted Pyramid).
7. Що таке антипатерн «Пісочний годинник» (Hourglass) у структурі автотестів і чому він виникає?
8. Що таке об'єкти-заглушки (Mocks, Stubs, Spies, Fakes) і на якому рівні піраміди вони використовуються?
9. Поясніть концепцію «Тестового кубка» (Testing Trophy) Кента Доддса для сучасних React/Vue додатків.
10. Чому модульні тести мають швидкість виконання 1-5 мілісекунд, а UI E2E тести тривають десятки секунд?
11. Як перенесення перевірки валідації полів із рівня браузера на рівень Unit/API прискорює CI/CD конвеєр?
12. Що таке контрактне тестування (Contract Testing) і як воно замінює складні інтеграційні стенди?
13. Як за допомогою AI автоматизувати написання юніт-тестів для legacy-коду з покриттям 90%+?
14. Складіть промпт для декомпозиції важкого 5-хвилинного UI E2E сценарію на швидкі API та Unit-тести.
15. Що таке метрика покриття коду тестами (Code Coverage) і чому 100% покриття не гарантує відсутність багів?
16. Складіть архітектурний план розподілу 100 тест-кейсів інтернет-магазину за рівнями піраміди тестування.
17. Як використовувати контейнеризацію (Testcontainers / Docker) для ізольованого запуску інтеграційних тестів?
18. Чому падіння Unit-тесту миттєво вказує на точний рядок помилки, а падіння E2E тесту вимагає довгого розслідування?
19. Опишіть порядок дій QA Lead при рефакторингу інвертованої піраміди автотестів у проекті.
20. Складіть чек-лист аудиту структури та балансу автотестів для інженерної команди.
