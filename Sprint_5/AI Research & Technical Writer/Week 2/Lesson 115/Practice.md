# Практичні завдання до Уроку 115: Цитування та посилання

## Мета заняття
Опанувати стандарти оформлення інженерних та наукових цитат (IEEE, BibTeX, Markdown Footnotes) та навчитися валідувати постійні посилання за допомогою AI.

---

### Завдання 1. Форматування сирих даних у стиль IEEE та BibTeX (Базовий рівень)

#### Вхідні дані:
Стаття: «Attention Is All You Need», автори: Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Lukasz Kaiser, Illia Polosukhin. Опубліковано в Advances in Neural Information Processing Systems (NeurIPS), 2017, сторінки 5998–6008.

#### Завдання:
За допомогою AI сформуйте:
1. Запис у стилі IEEE.
2. Повний блок запису BibTeX (`@inproceedings`).
3. Виноску у форматі GitHub Markdown (`[^1]`).

---

### Завдання 2. Налаштування CI/CD чекера посилань (Прикладний рівень)

#### Завдання:
Створіть конфігураційний файл для GitHub Action Workflow (`.github/workflows/link-checker.yml`), який при кожному Pull Request автоматично запускає `lychee` або `markdown-link-check` для перевірки всіх посилань у папці `docs/`.

---

### Завдання 3. Аудит AI-згенерованого списку джерел на фантомні посилання (Робота з AI)

#### Завдання:
Отримайте від LLM список із 5 статей на тему квантових обчислень. Проведіть ручний або API-пошук у Google Scholar / Semantic Scholar для кожного пункту та переконайтеся, що всі 5 статей реально існують і мають валідні DOI.

---

## Чекліст самоперевірки
- [ ] Оформлено коректні записи за стандартами IEEE та BibTeX.
- [ ] Сформовано робочий пайплайн перевірки посилань у Markdown.
- [ ] Перевірено достовірність та реальність бібліографічних джерел.
