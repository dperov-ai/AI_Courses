# Контрольні запитання до Уроку 115: Цитування та посилання

1. **Яка головна мета використання стандартизованих посилань у технічній статті?**
   - A) Заповнити порожнє місце на останній сторінці.
   - B) Забезпечити відтворюваність та можливість швидкої перевірки первинних фактів читачем, а також визнати авторство розробників. [Правильна]
   - C) Це вимога друкарень для продажу паперу.
   - D) Збільшити розмір шрифту тексту.
   *Пояснення: Посилання забезпечують прозорість та наукову доброчесність документа.*

2. **Який стиль цитування є стандартом де-факто в галузі комп'ютерних наук та програмної інженерії?**
   - A) Кулінарний стиль.
   - B) IEEE Style (Institute of Electrical and Electronics Engineers). [Правильна]
   - C) Стиль коміксів.
   - D) Довільний стиль без правил.
   *Пояснення: IEEE є загальноприйнятим стандартом в інженерії та IT.*

3. **Що таке DOI (Digital Object Identifier)?**
   - A) Номер паспорта автора.
   - B) Унікальний постійний цифровий ідентифікатор наукового чи технічного документа в інтернеті, що гарантує доступ до нього навіть при зміні адреси сайту. [Правильна]
   - C) Назва комп'ютерного вірусу.
   - D) Тип файлу в Windows.
   *Пояснення: DOI запобігає «вимиранню посилань» (Link Rot) в академічному середовищі.*

4. **Як оформити посилання на виноску в стандартному GitHub Flavored Markdown?**
   - A) `(посилання тут)`
   - B) Текст з маркером `[^1]`, а внизу сторінки `[^1]: Опис першоджерела та URL`. [Правильна]
   - C) `<<клікніть сюди>>`
   - D) За допомогою тегу `<blink>`.
   *Пояснення: Markdown Footnotes `[^1]` елегантно рендеряться у виноски внизу документа.*

5. **Що таке BibTeX у науковому середовищі?**
   - A) Інтернет-магазин книг.
   - B) Текстовий формат файлів для зберігання структурованих бібліографічних баз даних у системі підготовки наукових публікацій LaTeX. [Правильна]
   - C) Програма для редагування аудіо.
   - D) Бібліотека для 3D графіки.
   *Пояснення: BibTeX є стандартом автоматичного менеджменту бібліографії в науці.*

6. **Як AI допомагає досліднику в роботі зі списком літератури?**
   - A) AI вигадує неіснуючих вчених.
   - B) Автоматично витягує метадані з PDF-статей та конвертує їх у потрібний стиль (APA, IEEE, Chicago, Harvard, BibTeX). [Правильна]
   - C) AI забороняє посилатися на книги.
   - D) AI видаляє список джерел.
   *Пояснення: AI скорочує години механічної рутини форматування цитат.*

7. **Чому пряме посилання на репозиторій GitHub повинно містити конкретний Commit SHA або Git Tag?**
   - A) Щоб посилання виглядало довшим.
   - B) Код у гілці `main` постійно змінюється, і посилання на конкретний коміт гарантує, що читач побачить саме той стан файлу, про який писав автор. [Правильна]
   - C) Без коміту GitHub заблокує користувача.
   - D) Це не має значення.
   *Пояснення: Фіксація стану коду (Permalink to commit) забезпечує точну відтворюваність.*

8. **Що таке «Вторинне цитування» (Citing a Secondary Source) і чому його слід уникати?**
   - A) Цитування статті вдруге за день.
   - B) Посилання на автора А через переказ у книзі автора Б («А, як процитовано у Б»); це ризиковано, оскільки Б міг вирвати цитату з контексту або спотворити суть. [Правильна]
   - C) Цитування іноземною мовою.
   - D) Цитування безкоштовних статей.
   *Пояснення: Завжди слід намагатися знайти та перевірити первинне джерело.*

9. **Як сформулювати промпт до Claude для перетворення списку сирих посилань у IEEE формат?**
   - A) «Зроби посилання».
   - B) «Ось список сирих посилань та назв статей: [Список]. Сформуй з них нумерований список джерел у суворій відповідності до стандарту IEEE. Відсортуй за порядком згадування в тексті». [Правильна]
   - C) «Перетвори на PDF».
   - D) «Видали старі посилання».
   *Пояснення: Чіткий запит гарантує відповідність інженерним вимогам оформлення.*

10. **Що таке Wayback Machine (Internet Archive) у роботі технічного автора?**
    - A) Машина часу для подорожей у майбутнє.
    - B) Цифровий архів інтернету, який зберігає історичні знімки веб-сторінок і дозволяє посилатися на збережену копію, якщо оригінальний сайт перестав працювати. [Правильна]
    - C) Програма для відновлення видалених файлів.
    - D) Антивірусна утиліта.
    *Пояснення: Архівація посилань гарантує вічний доступ до джерел.*

11. **Чому використання вигаданих або неіснуючих посилань від AI є грубим порушенням професійної етики?**
    - A) Це призводить до блокування облікового запису OpenAI.
    - B) Це вводить читачів та аудиторів в оману, руйнує довіру до всієї роботи та є формою наукової фальсифікації (Academic Fraud). [Правильна]
    - C) Посилання не мають значення для етики.
    - D) Це викликає синій екран Windows.
    *Пояснення: Фантомні посилання — неприпустимий дефект генеративного контенту.*

12. **Що означає скорочення «et al.» у бібліографічних посиланнях?**
    - A) «Електронна пошта».
    - B) Латинський вираз «et alii» («та інші»), що використовується для скорочення довгого списку співавторів публікації (наприклад, «Smith et al., 2024»). [Правильна]
    - C) «Кінець статті».
    - D) «Помилка друку».
    *Пояснення: Скорочення спрощує цитування праць з десятками співавторів.*

13. **Як правильно цитувати офіційні специфікації IETF RFC?**
    - A) «Якийсь документ в інтернеті».
    - B) Вказувати номер RFC, назву стандарту, авторів/редакторів, статус (Internet Standard / Best Current Practice) та постійний URL з rfc-editor.org. [Правильна]
    - C) Лише номером телефону автора.
    - D) RFC заборонено цитувати.
    *Пояснення: Офіційні RFC є фундаментальними стандартами інтернет-технологій.*

14. **Яка різниця між списком літератури (References) та бібліографією (Bibliography)?**
    - A) Вони відрізняються лише розміром літер.
    - B) References містить виключно ті джерела, які були прямо процитовані в тексті статті; Bibliography може включати додаткові матеріали для розширеного читання за темою. [Правильна]
    - C) References пишуть українською, а Bibliography англійською.
    - D) Bibliography використовується тільки в школі.
    *Пояснення: References є точним переліком фактичних доказів статті.*

15. **Як перевірити дійсність посилання перед публікацією документації?**
    - A) Клікнути на одне випадкове посилання.
    - B) Запустити автоматизований Link Checker (наприклад, `markdown-link-check` або GitHub Action), який перевірить HTTP статус-коди (200 OK) для всіх URL у репозиторії. [Правильна]
    - C) Вимкнути інтернет.
    - D) Перевірити колір посилання.
    *Пояснення: Автоматичні чекери посилань у CI/CD гарантують відсутність битих лінків.*

16. **Що таке «Самоцитування» (Self-citation) і коли воно є виправданим?**
    - A) Розмова з самим собою в дзеркалі.
    - B) Посилання автора на свої попередні публікації; виправдане, якщо нова робота прямо спирається на розроблену раніше методологію або вихідний код. [Правильна]
    - C) Це завжди суворо заборонено законом.
    - D) Це спосіб підвищити ціну статті.
    *Пояснення: Самоцитування нормальне, якщо воно обґрунтоване спадкоємністю дослідження.*

17. **Як AI допомагає виявити дублікати джерел у великій бібліографічній базі?**
    - A) AI видаляє всю базу.
    - B) Зіставляє заголовки, авторів та DOI навіть при різному форматуванні записів та пропонує об'єднати дублікати в один унікальний запис. [Правильна]
    - C) AI створює ще більше дублікатів.
    - D) AI блокує базу паролем.
    *Пояснення: Дедуплікація підтримує чистоту бібліографічної колекції.*

18. **Яке головне правило оформлення цитат прямої мови (Direct Quote)?**
    - A) Змінити всі слова на власні.
    - B) Брати текст у лапки, зберігати точне оригінальне формулювання та обов'язково вказувати точну сторінку або абзац джерела. [Правильна]
    - C) Видалити лапки.
    - D) Перекласти текст на латину.
    *Пояснення: Пряма цитата вимагає абсолютної точності та вказівки джерела.*
