### Завдання 1. Аудит безпеки за допомогою Bandit та усунення вразливостей (Базовий рівень)

#### Вхідний небезпечний фрагмент коду:
```python
import os
import requests
import json

def fetch_and_save_report(token, endpoint, output_path):
    # Вразливість: verify=False та конкатенація системних команд
    response = requests.get(f"https://api.internal/{endpoint}", headers={"Authorization": f"Bearer {token}"}, verify=False)
    data = response.json()
    
    with open(output_path, "w") as f:
        json.dump(data, f)
        
    os.system(f"chmod 777 {output_path}")  # Критична вразливість
```

#### Завдання:
1. Виявіть 3 проблеми безпеки за допомогою AI та інструменту Bandit.
2. Перепишіть функцію безпечно: безпечні права доступу, валідація SSL, виключення викликів `os.system`.
