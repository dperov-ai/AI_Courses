# Практичні завдання до Уроку 111: Узагальнення результатів досліджень за допомогою AI

## Мета заняття
Навчитися формувати фінальний Executive Summary UX-дослідження, пріоритизувати беклог змін за шкалою RICE та трансформувати інсайти в User Stories для команди розробки.

---

### Завдання 1. Пріоритизація за моделлю RICE за допомогою AI (Базовий рівень)

#### Вхідний список із 4 функцій для додатку фітнес-трекінгу:
1. Автоматичне розпізнавання вправ через камеру смартфона з комп'ютерним зором.
2. Експорт тренувань у формат CSV/Excel.
3. Додавання віджету швидкого запуску таймера на екран блокування (Lock Screen Widget).
4. Інтеграція зі смарт-годинниками Garmin/Apple Watch.

#### Завдання:
Попросіть AI розрахувати орієнтовний RICE Score для кожної фічі (обґрунтуйте оцінки Reach, Impact, Confidence, Effort) та сформуйте відсортований беклог.

---

### Завдання 2. Генерація дизайн-брифінгу та User Stories у форматі Gherkin (Прикладний рівень)

#### Контекст:
Редизайн процесу вибору часу доставки в інтернет-супермаркеті через масові скарги на запізнення кур'єрів.

#### Завдання:
Сформулюйте за допомогою AI:
1. Опис проблеми та мета редизайну (Design Brief).
2. 2 User Stories з критеріями приймання у синтаксисі Given-When-Then.

---

### Завдання 3. Підготовка односторінкового Executive Summary для керівництва (Робота з AI)

#### Завдання:
Створіть стислий 1-сторінковий документ для генерального директора (CEO), який пояснює необхідність інвестицій у редизайн мобільного онбордингу, спираючись на очікуване зростання метрик LTV та Retention.

---

## Чекліст самоперевірки
- [ ] Розраховано та обґрунтовано RICE оцінки для списку функцій.
- [ ] Створено валідні User Stories з Acceptance Criteria (Gherkin).
- [ ] Оформлено лаконічне резюме для менеджменту (Executive Summary).
