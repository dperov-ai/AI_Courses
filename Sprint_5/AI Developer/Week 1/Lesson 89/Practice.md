### Завдання 1. Реалізація валідатора паролів методом Test-Driven Prompting (Базовий рівень)

#### Опис завдання:
1. За допомогою AI згенеруйте набір тестів на Pytest для валідатора паролів `validate_password_strength(password: str) -> tuple[bool, list[str]]`.
   - Вимоги до пароля: мінімум 8 символів, наявність великої літери, цифри, спецсимвола (`!@#$%^&*`), заборона пробілів.
2. Потім згенеруйте функцію, яка проходить 100% тестів.

#### Зразок коду реалізації:
```python
import re

def validate_password_strength(password: str) -> tuple[bool, list[str]]:
    """Валідує надійність пароля за корпоративними стандартами безпеки.
    
    Повертає:
        (is_valid, list_of_errors)
    """
    errors: list[str] = []
    
    if len(password) < 8:
        errors.append("Пароль повинен містити щонайменше 8 символів")
    if not re.search(r"[A-Z]", password):
        errors.append("Пароль повинен містити хоча б одну велику літеру")
    if not re.search(r"[a-z]", password):
        errors.append("Пароль повинен містити хоча б одну малу літеру")
    if not re.search(r"\d", password):
        errors.append("Пароль повинен містити хоча б одну цифру")
    if not re.search(r"[!@#$%^&*(),.?":{}|<>]", password):
        errors.append("Пароль повинен містити хоча б один спеціальний символ (!@#$%^&*)")
    if " " in password:
        errors.append("Пароль не повинен містити пробілів")
        
    return (len(errors) == 0, errors)
```
