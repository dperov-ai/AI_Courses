### Завдання 1. Складання ТЗ за фреймворком RTCCO для сервісу генерації PDF-звітів (Базовий рівень)

#### Опис завдання:
Складіть структуроване технічне завдання для генерації асинхронного мікросервісу на Python, який приймає JSON із фінансовими транзакціями та формує PDF-звіт за шаблоном Jinja2 + WeasyPrint.

#### Зразок ТЗ (RTCCO):
```markdown
### Role:
Senior Python Backend Engineer & Document Generation Specialist.

### Task:
Створити асинхронний сервіс `InvoiceReportService` для генерації PDF-інвойсів.

### Context:
- Python 3.12, WeasyPrint, Jinja2, Pydantic v2.
- Вхідні дані: JSON об'єкт замовлення (номер, клієнт, список товарів, ПДВ 20%, фінальна сума).

### Constraints:
1. Повна типізація Pydantic v2 (схема `InvoicePayload`).
2. Безпека: екранування HTML-символів у Jinja2 для запобігання XSS / HTML Injection.
3. Асинхронний рендеринг у неблокуючому пулі потоків `asyncio.to_thread`.
4. Заборона плейсхолдерів і TODO — надати повний робочий код HTML/CSS шаблону та Python модуля.

### Output:
1. `schemas.py` — моделі даних.
2. `service.py` — логіка генерації PDF та повернення `bytes`.
```
