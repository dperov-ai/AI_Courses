### Завдання 1. Аналіз та усунення `NoneType` помилки у вкладеному JSON (Базовий рівень)

#### Опис завдання:
У продакшені впав ендпоінт обробки замовлень із помилкою:
`AttributeError: 'NoneType' object has no attribute 'get'`

#### Проблемний код:
```python
def extract_shipping_city(order_data: dict) -> str:
    # Падіння, якщо delivery або address відсутні (дорівнюють None)
    return order_data["delivery"]["address"]["city"]
```

#### Інструкція:
За допомогою AI зробіть цей код 100% безпечним до будь-яких пропущених ключів та `None` значень, використовуючи безпечну навігацію або Pydantic-валідацію.

#### Зразок виправленого коду:
```python
def extract_shipping_city(order_data: dict | None) -> str:
    """Безпечно витягує назву міста доставки зі структури замовлення."""
    if not isinstance(order_data, dict):
        return "Невідоме місто"
        
    delivery = order_data.get("delivery")
    if not isinstance(delivery, dict):
        return "Невідоме місто"
        
    address = delivery.get("address")
    if not isinstance(address, dict):
        return "Невідоме місто"
        
    city = address.get("city")
    return str(city).strip() if city else "Невідоме місто"
```
