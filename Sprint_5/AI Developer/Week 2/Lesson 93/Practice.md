### Завдання 1. Пошук та виправлення 3 критичних вразливостей у коді (Базовий рівень)

#### Вразливий код від недосвідченого AI:
```python
import sqlite3
import hashlib

def login_user(username, password):
    # Вразливість 1: Застарілий алгоритм MD5
    hashed = hashlib.md5(password.encode()).hexdigest()
    
    conn = sqlite3.connect("users.db")
    cursor = conn.cursor()
    
    # Вразливість 2: SQL Injection
    query = f"SELECT id, role FROM users WHERE username = '{username}' AND password_hash = '{hashed}'"
    cursor.execute(query)
    
    user = cursor.fetchone()
    # Вразливість 3: Відсутність закриття підключення (Connection Leak)
    return user
```

#### Інструкція:
За допомогою AI та знань безпеки перепишіть цей код:
1. Використайте параметризований SQL-запит (`?`).
2. Використайте контекстний менеджер `with` для гарантованого закриття з'єднання.
3. Замініть MD5 на сучасне хешування паролів.
