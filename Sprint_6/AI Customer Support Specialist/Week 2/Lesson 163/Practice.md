# Практичні завдання до Уроку 163: RAG basics для support

Практичний блок розроблено для закріплення навичок роботи з AI-інструментами, аналізу реальних виробничих кейсів та створення професійних артефактів.

## Завдання 1: Проєктування архітектури RAG-бота для служби підтримки необанку

**Мета:** Навчитись розробляти повноцінну інженерну схему RAG-системи з фільтрацією метаданих та Fallback-сценаріями.

**Вхідний контекст та бізнес-сценарій:**
Необанк планує впровадити AI-асистента для автоматичних відповідей у мобільному додатку на базі 300 статей з Confluence. Необхідно створити архітектурну специфікацію конвеєра з перевіркою безпеки та порогів релевантності.

**Покроковий алгоритм виконання:**
1. Опишіть етап обробки та чанкування контенту (розмір чанка, overlap, виділення метаданих: розділ, тариф, дата).
2. Спроєктуйте алгоритм пошуку: гібридний пошук (Embeddings + BM25) та переранжування.
3. Встановіть поріг впевненості (Confidence Threshold): якщо similarity < 0.72 — переводити діалог на людину.
4. Опишіть діаграму в Mermaid.js та наведіть шаблон промпту для системного агента.

**Рекомендований системний AI-промпт:**
```text
Дій як Principal AI Architect. Склади архітектурну специфікацію RAG-системи для служби підтримки клієнтів банку:
Вимоги:
1. Схема процесу в Mermaid.js (Ingestion + Query pipeline).
2. Параметри чанкування: обґрунтуй розмір чанка (300 токенів), розмір перекриття (50 токенів) та обов'язкові метадані.
3. Опиши механізм Hybrid Search (поєднання векторів OpenAI text-embedding-3-small та повнотекстового BM25).
4. Опиши логіку Fallback: що відбувається, коли схожість чанків занадто низька або виявлено конфлікт у базі знань.
5. Напиши системний промпт для LLM з суворими вимогами щодо цитування джерел.
```

**Очікуваний результат:**
Комплексний архітектурний документ із діаграмою Mermaid.js, параметрами конфігурації та системним промптом.

**Критерії самоперевірки та оцінювання:**
- [ ] Технічно точний опис усіх компонентів RAG пайплайну
- [ ] Обґрунтування параметрів чанкування та гібридного пошуку
- [ ] Наявність безпечного Fallback-механізму на живого оператора
- [ ] Коректний синтаксис діаграми Mermaid

## Завдання 2: Оцінка якості відповідей RAG за метриками Тріади Ragas

**Мета:** Опанувати проведення аналітичного аудиту тестових прогонів RAG за метриками Context Relevance, Groundedness та Answer Relevance.

**Вхідний контекст та бізнес-сценарій:**
Ви тестуєте прототип RAG бота підтримки. На питання клієнта 'Як замовити перевипуск картки після зміни прізвища?' бот надав відповідь, яка містить факти, відсутні у знайдених чанках (галюцинація про необхідність візиту у відділення, хоча банк на 100% цифровий). Потрібно формалізувати аудит.

**Покроковий алгоритм виконання:**
1. Зіставте вхідне питання, знайдені чанки та згенеровану відповідь.
2. Оцініть метрику Context Relevance (чи правильні документи знайшов ретривер).
3. Оцініть метрику Groundedness/Faithfulness (ідентифікуйте конкретне галюциноване речення).
4. Сформулюйте виправлений варіант відповіді та інструкцію для покращення системного промпту.

**Рекомендований системний AI-промпт:**
```text
Дій як QA & AI Evaluation Specialist. Проведи аудит якості згенерованої RAG-відповіді:
Вхідне питання: 'Я змінила прізвище після одруження, як оновити дані в додатку?'
Знайдений чанк бази знань: 'Для зміни прізвища завантажте скан свідоцтва про шлюб та новий паспорт у розділі Профіль -> Документи. Верифікація триває до 24 годин. Після цього цифрова картка автоматично перейменовується'.
Згенерована відповідь бота: 'Вітаємо! Для зміни прізвища зверніться з оригіналами документів у найближче відділення банку або завантажте їх у розділі Профіль. Після перевірки вам потрібно замовити нову пластикову картку за $5'.
Завдання:
1. Визнач дві явні галюцинації (помилки Groundedness), які бот вигадав самостійно.
2. Розрахуй орієнтовну оцінку Faithfulness (від 0 до 1).
3. Напиши правильну відповідь, на 100% обґрунтовану знайденим чанком.
4. Надай рекомендацію: яке правило промпту запобігло б цій помилці.
```

**Очікуваний результат:**
Аналітичний звіт аудиту RAG із фіксацією галюцинацій, розрахунком метрик та виправленим текстом.

**Критерії самоперевірки та оцінювання:**
- [ ] Точна ідентифікація вигаданих тверджень (відділення банку, платна карта $5)
- [ ] Коректне розуміння метрики Faithfulness / Groundedness
- [ ] Бездоганна еталонна відповідь, яка точно відповідає наданому документу
- [ ] Практична інженерна рекомендація щодо оновлення промпту
