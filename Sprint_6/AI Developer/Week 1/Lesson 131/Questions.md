# Контрольні запитання до Уроку 131: HTML, CSS та JavaScript — призначення і базові можливості

Даний блок містить перелік аналітичних та практичних запитань для самоконтролю, перевірки глибини засвоєння матеріалу та підготовки до технічних інтерв’ю.

---

### 1. У чому полягає фундаментальна різниця між функціями HTML, CSS та JavaScript?

**Відповідь:** HTML визначає зміст і семантичну структуру документа, CSS відповідає за його візуальне оформлення та просторове розміщення, а JavaScript додає поведінку, обробку подій та інтерактивність.

---

### 2. Чому використання семантичних тегів HTML5 важливіше, ніж звичайна верстка на <div>?

**Відповідь:** Семантичні теги надають контенту машинозчитуваного сенсу, що є критичним для доступності (екранні диктори a11y), правильного індексування пошуковими системами (SEO) та стабільного парсингу браузером.

---

### 3. Як обчислюється специфічність (Specificity) CSS селектора?

**Відповідь:** За системою пріоритетів: Inline стилі (1000) > ID селектори (100) > Класи, псевдокласи, селектори атрибутів (10) > Елементи та псевдоелементи (1).

---

### 4. Чим відрізняється Flexbox від CSS Grid з точки зору вимірності простору?

**Відповідь:** Flexbox є одновимірною системою (1D), яка працює вздовж однієї осі (рядка або колонки), тоді як CSS Grid — це двовимірна система (2D), що одночасно контролює і рядки, і стовпці.

---

### 5. Що таке CSS Custom Properties (змінні) та які їх переваги над змінними SASS/SCSS?

**Відповідь:** Змінні CSS існують у runtime-середовищі браузера, успадковуються за DOM-деревом та можуть динамічно змінюватися за допомогою JavaScript без повторної компіляції стилів.

---

### 6. Поясніть однопотокову модель виконання JavaScript. Що це означає на практиці?

**Відповідь:** Це означає наявність єдиного стеку викликів (Call Stack), де одночасно може виконуватися лише одна операція; важкі синхронні обчислення блокують інтерфейс сторінки.

---

### 7. Як Event Loop організовує черговість виконання Microtasks та Macrotasks?

**Відповідь:** Коли Call Stack звільняється, Event Loop спочатку повністю виконує ВСІ задачі з черги Microtask Queue (проміси), і лише потім бере ОДНУ задачу з черги Macrotask Queue (setTimeout).

---

### 8. Чим відрізняється атрибут script defer від async?

**Відповідь:** `async` завантажує скрипт асинхронно і виконує його негайно, блокуючи HTML-парсер, порядок виконання скриптів не гарантується. `defer` завантажує асинхронно, але виконує суворо після побудови DOM у порядку появи в документі.

---

### 9. Що таке техніка делегування подій (Event Delegation)?

**Відповідь:** Це патерн, коли один слухач події встановлюється на спільного батька багатьох елементів, використовуючи механізм спливання подій (Event Bubbling) та властивість event.target.

---

### 10. У чому полягає різниця між методами Debounce та Throttle?

**Відповідь:** Debounce відкладає виклик функції до закінчення паузи після останньої дії користувача, а Throttle обмежує частоту викликів до не більше ніж одного разу за фіксований проміжок часу.

---

### 11. Чому пряме звернення до властивостей DOM через JS є повільною операцією?

**Відповідь:** Оскільки читання геометричних параметрів (наприклад, offsetTop) примушує браузерний рушій позачергово виконувати важкий розрахунок Layout (Reflow).

---

### 12. Що таке замикання (Closure) в JavaScript?

**Відповідь:** Це здатність функції зберігати доступ до змінних зі своєї зовнішньої лексичної області видимості навіть після того, як зовнішня функція завершила своє виконання.

---

### 13. Чим оператор строгої рівності === відрізняється від == у JavaScript?

**Відповідь:** `==` виконує неявне приведення типів перед порівнянням, що призводить до неочевидних помилок, тоді як `===` порівнює і типи, і значення без жодних перетворень.

---

### 14. Яке призначення стандарту WAI-ARIA у верстці інтерфейсів?

**Відповідь:** ARIA надає додаткові атрибути (aria-expanded, role, aria-live) для опису доступності складних UI-компонентів допоміжним технологіям (Screen Readers), коли нативного HTML недостатньо.

---

### 15. Що таке Box Model у CSS і з яких частин вона складається?

**Відповідь:** Це модель коробки елемента, яка складається з контенту (Content), внутрішніх відступів (Padding), рамки (Border) та зовнішніх полів (Margin).

---

### 16. Чому рекомендується встановлювати box-sizing: border-box для всіх елементів?

**Відповідь:** Це включає padding та border у загальну задану ширину та висоту елемента, запобігаючи непередбачуваному розширенню блоків за межі сітки.

---

### 17. Як працює механізм спливання подій (Event Bubbling)?

**Відповідь:** Коли подія спрацьовує на цільовому елементі, вона послідовно передається вгору по дереву DOM до батьківських елементів аж до об'єкта window.

---

### 18. Що робить метод event.preventDefault() на відміну від event.stopPropagation()?

**Відповідь:** `preventDefault()` скасовує стандартну дію браузера (наприклад, перехід за лінком або відправку форми), а `stopPropagation()` зупиняє подальше спливання події по дереву DOM.

---

### 19. Як директива @media допомагає створювати адаптивний дизайн?

**Відповідь:** Вона дозволяє застосовувати специфічні блоки стилів CSS залежно від характеристик пристрою (ширини екрана, орієнтації, роздільної здатності).

---

### 20. У чому полягає концепція Mobile-First у верстці?

**Відповідь:** Стилі спочатку проектуються для мобільних пристроїв із вузьким екраном як базові, а потім розширюються для десктопів через медіа-запити `min-width`.

---

### 21. Яка різниця між var, let та const у JavaScript?

**Відповідь:** `var` має функціональну область видимості та піднімається (hoisting), тоді як `let` та `const` мають блокову область видимості та знаходяться у Temporal Dead Zone до ініціалізації; `const` додатково забороняє переприсвоєння.

---

### 22. Як працює прототипне наслідування в JavaScript під капотом синтаксису класів ES6?

**Відповідь:** Класи є синтаксичним цукром над функціями-конструкторами: кожен об'єкт має приховане посилання `__proto__` на об'єкт-прототип свого конструктора, через який делегуються методи.

---
