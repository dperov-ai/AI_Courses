# Практичні завдання до Уроку 131: HTML, CSS та JavaScript — призначення і базові можливості

Практичний блок розроблено для закріплення навичок роботи з AI-інструментами, аналізу реальних виробничих кейсів та створення професійних артефактів.

---

## Завдання 1: Створення семантичного доступного компонента акордеона на чистому HTML/CSS/JS

**Мета:** Розробити віджет акордеона, що повністю відповідає стандарту доступності W3C WAI-ARIA та керується з клавіатури.

**Вхідний контекст та бізнес-сценарій:**
Продуктова команда вимагає усунути сторонні важкі бібліотеки та реалізувати легкий доступний FAQ-блок.

**Покроковий алгоритм виконання:**
1. Використовуйте семантичні теги `<button>` для заголовків акордеона та `<div>` для контенту.
2. Додайте ARIA-атрибути: `aria-expanded='false'`, `aria-controls='panel-id'`, та відповідний `id` на панель.
3. Реалізуйте стилі CSS з використанням CSS Variables для кольорів та плавних переходів (`transition`).
4. Напишіть чистий JS з логікою відкриття/закриття, підтримкою закриття сусідніх вкладок та навігацією клавішами Стрілка Вгору/Вниз.

**Рекомендований системний AI-промпт:**
```text
Створи доступний (WAI-ARIA) акордеон на чистому HTML5, сучасному CSS та JavaScript. Обов'язкові вимоги: правильні атрибути aria-expanded, повна підтримка навігації клавіатурою (Tab, Enter, Space, Up/Down arrows), плавна анімація розгортання без фіксованої висоти.
```

**Очікуваний результат:**
Повний самодостатній файл з розміткою, стилями та лаконічним скриптом без сторонніх залежностей.

**Критерії самоперевірки та оцінювання:**
- [ ] Наявність коректних атрибутів aria-expanded та aria-controls
- [ ] Повна доступність з клавіатури без використання миші
- [ ] Відсутність витоків пам'яті у слухачах подій

## Завдання 2: Оптимізація продуктивності через реалізацію кастомного Debounce-пошуку

**Мета:** Створити функцію пошукового автодоповнення, яка оптимізує навантаження на браузер та мережу.

**Вхідний контекст та бізнес-сценарій:**
Поле пошуку надсилає важкі запити до сервера на кожен символ користувача, викликаючи лаги інтерфейсу та затримки введення.

**Покроковий алгоритм виконання:**
1. Реалізуйте чисту функцію вищого порядку `debounce(fn, delay)` на базі замикань (closures) та `setTimeout`.
2. Створіть HTML-поле `<input type='search'>` та контейнер для виводу списку результатів.
3. Підключіть обробник події `input` через створений debounce із затримкою 300 мс.
4. Додайте імітацію асинхронного мережевого запиту (через Promise) та скасування застарілих відповідей через `AbortController`.

**Рекомендований системний AI-промпт:**
```text
Напиши функцію debounce на чистому JavaScript з можливістю скасування попереднього виклику. Інтегруй її з input пошуку та продемонструй використання AbortController для скасування fetch запитів при швидкому введенні.
```

**Очікуваний результат:**
Вичерпний інженерний приклад коду з обробкою граничних випадків та коментарями щодо Event Loop.

**Критерії самоперевірки та оцінювання:**
- [ ] Коректне збереження контексту `this` та аргументів у функції debounce
- [ ] Запобігання гонкам станів (Race Conditions) через AbortController
- [ ] Мінімальне навантаження на Call Stack
